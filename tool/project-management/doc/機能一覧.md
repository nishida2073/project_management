# 機能一覧

本書は、モック（`mock/html`）の画面と機能の概要です。ブラウザでの全体の動作確認は、まだ済んでいません。

## 1. ログイン・権限

| 機能 | 概要 |
| --- | --- |
| ログイン | メールアドレスとパスワードでログインする。 |
| 権限による画面の制限 | 管理者は全画面を使える。一般は担当区分と業務区分の組み合わせで、使える画面を決める。 |
| パスワード変更 | 現在のパスワードを確認して、新しいパスワードに変更する。 |
| ログアウト | ログアウトする。 |

## 2. 共通の操作

| 機能 | 概要 |
|---|---|
| サイドバー | 権限に応じて、表示するメニューを絞り込む。 |
| 一覧の絞り込み | 検索条件で一覧を絞り込む。 |
| 表示の切り替え | 「表」と「カレンダー」を切り替える。 |
| 列幅の調整 | 表の列幅を調整する。 |
| 一覧の並べ替え | 列の見出しで並べ替える。 |
| 一覧のページ送り | 一覧をページ単位で表示する。 |
| 列の表示切替 | 列を表示・非表示で切り替える。 |
| 一覧の自動絞り込み | 条件を選ぶと、一覧が自動的に絞り込まれる。 |

## 3. 案件管理

| 機能 | 概要 |
| --- | --- |
| 案件一覧 | 案件を一覧で表示し、絞り込む。 |
| 案件の登録 | 案件を登録する。 |
| 案件の更新 | 登録済みの案件を変更する。 |

## 4. 案件進捗

| 機能 | 概要 |
| --- | --- |
| 案件進捗の一覧 | 案件の進捗を一覧で表示し、表とカレンダーを切り替える。 |
| 案件進捗の更新 | 作業ごとの予定日・実施日・担当者・進捗などを入力する。 |

## 5. クラス管理

| 機能 | 概要 |
| --- | --- |
| クラス一覧 | クラスを一覧で表示する。 |
| クラスの登録 | クラスを登録する。コースの推奨値を表示する。 |
| クラスの更新 | 登録済みのクラスを変更する。 |
| クラスの複製 | 既存のクラスを複製する。 |

## 6. 登壇依頼

| 機能 | 概要 |
| --- | --- |
| 登壇依頼の一覧 | クラスごとに講師の状態と予定の人数を表示する。 |
| 登壇依頼の更新 | クラスごとに講師を登録・変更する。 |
| 依頼枠の更新（ダイアログ） | クラス毎に依頼枠を変更する。 |
| 依頼枠の更新（一覧） | まとめて依頼枠を変更する。 |
| 講師ベンダーへの依頼 | 講師ベンダーに送る依頼書（Excel）を出力する。 |
| 講師ベンダーからの回答の反映 | 講師ベンダーから受け取った依頼書（Excel）を取り込み、反映する。 |

## 7. クラス進捗

| 機能 | 概要 |
| --- | --- |
| クラス進捗の一覧 | クラスの進捗を一覧で表示し、表とカレンダーを切り替える。 |
| クラス進捗の更新 | 作業ごとの予定日・実施日・担当者・進捗などを入力する。 |

## 8. マスタ管理

| 機能 | 概要 |
| --- | --- |
| 科目 | 科目を一覧で表示し、登録・更新する。 |
| コース | コースを一覧で表示し、登録・更新する。 |
| ロケーション | ロケーションを一覧で表示し、登録・更新する。 |
| 顧客 | 顧客を一覧で表示し、登録・更新する。 |
| 講師ベンダー | 講師ベンダーを一覧で表示し、登録・更新する。 |
| 実施担当ベンダー | 実施担当ベンダーを一覧で表示し、登録・更新する。 |
| 実施担当者 | 実施担当者を一覧で表示し、登録・更新する。 |
| タスク | タスクを一覧で表示し、登録・更新する。 |

## 9. ユーザー管理

| 機能 | 概要 |
| --- | --- |
| ユーザー一覧 | ユーザーを一覧で表示する。 |
| ユーザーの登録 | 権限（管理者／一般）を設定して、ユーザーを登録する。 |
| ユーザーの更新 | 登録済みのユーザーを変更する。 |
| 実施担当者との連携 | メールアドレスで実施担当者と連携し、所属・担当区分・業務区分を表示する。 |
