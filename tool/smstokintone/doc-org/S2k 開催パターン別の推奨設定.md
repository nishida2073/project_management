# 開催パターン別の推奨設定

## 概要
　開催パターンに応じた、送信先の設定・アプリの設定の推奨値をまとめたものです。設定方法自体は[操作マニュアル](<S2k 操作マニュアル.pdf>)を参照してください。

## 開催別の設定

### 個社の場合

　1社のみを対象に開催する場合の設定です。

#### kintoneアプリについて

- 設定数
  - 1つ
- 運用方法
  - 対象企業のSMSをすべてこの1つのアプリに登録します

<div class="pagebreak"></div>

#### 送信先の設定について

- 設定数
  - 1つ
- 基本の設定
  - 送信先の振り分け
    - キーワードを1件も追加しません。送信先が1つしかないため、キーワードで振り分ける必要はありません（未設定＝デフォルトの送信先として、すべてのSMSがこの1つの送信先に登録されます）。

<div class="pagebreak"></div>

#### アプリの設定について

- 会社名の抽出
  - 会社名の自動抽出
    - 無効にしておくことを推奨します
      - 対象企業が1社のみのため、会社名を抽出する必要がありません。
- SMSの検索
  - SMS選択の対象
    - 「抽出状況が異常」を選択可能にしておくことを推奨します
      - 自動送信で問題があった場合に、検索画面から内容を確認して手動で送信できるようにするためです。
- SMSの送信
  - 自動送信の対象
    - 「抽出状況が異常」を**含める**
      - 送信先は1つのため、氏名を抽出できなかったSMSであっても送信先は確定します。そのため自動送信の対象に含めても問題ありません。

<div class="pagebreak"></div>

### 共催の場合

　複数社が合同で参加する開催の場合の設定です。

#### kintoneアプリについて

- 設定数
  - 1つ
- 運用方法
  - 複数の参加企業のSMSをまとめてこの1つのアプリに登録します

<div class="pagebreak"></div>

#### 送信先の設定について

- 設定数
  - 1つ
- 基本の設定
  - 送信先の振り分け
    - キーワードを追加することで、会社ごとにSMSを振り分けることが可能です。キーワード未設定のSMSはデフォルト送信先として扱われます。

<div class="pagebreak"></div>

#### アプリの設定について

- 会社名の抽出
  - 会社名の自動抽出
    - 有効にしておくことを推奨します
      - 複数の参加企業があるため、SMSから会社名を抽出して判別することが重要です。
- SMSの検索
  - SMS選択の対象
    - 「抽出状況が異常」を選択可能にしておくことを推奨します
      - 自動送信で問題があった場合に、検索画面から内容を確認して手動で送信できるようにするためです。
- SMSの送信
  - 自動送信の対象
    - 「抽出状況が異常」を**含める**
      - 送信先は1つのため、会社名・氏名を抽出できなかったSMSであっても送信先は確定します。そのため自動送信の対象に含めても問題ありません。
