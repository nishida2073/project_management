# データ設計

対象: `doc\02_設計\データ設計.md`

共通の書き方は「共通ルール」、設計全体の書き方は「設計ルール」を参照してください。

## 1. 概要

本ツールが端末内に保存するデータと、利用者が設定で変更する項目を定義します。

- データの一覧
  | 通番 | データ | 保存先 | 内容 |
  |---|---|---|---|
  | 1 | アプリの設定 | 端末内の設定領域 | 表示、動作、既定値、抽出、返信、ログを設定します。 |
  | 2 | 送信先の設定 | 端末内の設定領域 | 登録先の kintone アプリと、振り分けの条件を設定します。 |
  | 3 | 引継ぎ内容 | 端末内の引継ぎ領域 | 送信元ごとの会社名と氏名を保存します。 |
  | 4 | ログ | 端末内のログ領域 | 受信、登録、返信の記録を保存します。 |
  | 5 | 端末（アプリ・送信先）の設定ファイル | 利用者が指定した場所 | 設定を JSON ファイルに書き出したものです。 |
  | 6 | SMS | 端末の SMS 領域 | 受信した SMS を取得します。アプリは変更しません。 |
  | 7 | kintone のレコード | kintone | 登録と更新を行います。 |

## 2. 各データ

### 2.1 アプリの設定

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| 表示テーマ | themeMode | 画面の表示テーマです。 | ライト |
| SMSの送信モード | sendEnabled | SMS を自動で登録するか、手動で登録するかを設定します。 | 自動 |
| 抽出失敗SMSの自動送信 | sendExtractionFailedEnabled | 抽出に失敗した SMS を、自動で登録の対象にするかを設定します。 | オフ |
| SMSの返信モード | replyEnabled | 返信を自動で送るか、手動で送るかを設定します。 | 手動 |
| 自動返信の間隔 | replyCooldownSeconds | 同じ送信元へ自動返信する間隔（秒）です。 | 10 |
| 返信メッセージ（正常） | replySuccessBody | 抽出に成功した SMS の送信元へ送る文面です。 | 既定の文面 |
| 返信メッセージ（異常） | replyFailedBody | 抽出に失敗した SMS の送信元へ送る文面です。 | 既定の文面 |
| 検索の受信日の範囲 | searchDateRangeDays | SMS の検索画面を開いたときの、受信日の範囲（日）です。 | 1 |
| 検索条件の表示 | searchFiltersVisibleByDefault | SMS の検索画面で、検索条件を表示するかを設定します。 | 表示 |
| 会社名の抽出 | extractionCompanyNameEnabled | 本文から会社名を取り出すかを設定します。 | オン |
| 会社名の自動変換 | extractionCompanyNameAutoConversionEnabled | 抽出した会社名を、自動で変換するかを設定します。 | オン |
| 会社名の固定変換 | extractionCompanyNameFixedConversions | 変換前と変換後の対応を設定します。 | 設定なし |
| AIによる抽出 | extractionAiEnabled | 端末内の AI で抽出するかを設定します。 | オフ |
| 引継ぎ | continuationEnabled | 同じ送信元の以前の情報を引き継ぐかを設定します。 | オン |
| 引継ぎの範囲 | continuationScope | 引き継ぐ範囲を、制限なしか同一日のみかで設定します。 | 制限なし |
| 引継ぎ内容の氏名表示 | continuationShowUserNameEnabled | 引継ぎ内容の一覧に氏名を表示するかを設定します。 | オン |
| ログの自動更新 | logRefreshEnabled | ログの一覧を一定の間隔で更新するかを設定します。 | オン |
| ログの更新間隔 | logRefreshIntervalSeconds | ログの自動更新の間隔（秒）です。 | 5 |
| ログの統合範囲 | logMatchToleranceSeconds | 送信ログと端末の SMS を同じとみなす時間の差（秒）です。 | 15 |
| 本文の表示文字数 | logBodyExcerptLength | ログに表示する本文の文字数です。 | 100 |

### 2.2 送信先の設定

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| 送信先名 | sendTargetName | 送信先を区別する名前です。必須です。 | なし |
| 会社名（固定値） | companyName | 会社名の抽出がオフのときに使う会社名です。 | なし |
| 振り分けキーワード | keywords | 会社名に含まれていると、この送信先に登録される文字列です。 | なし |
| 接続先（サブドメイン） | subdomain | kintone のサブドメインです。必須です。 | なし |
| ログイン名 | loginName | kintone の接続に使うログイン名です。必須です。 | なし |
| パスワード | loginPassword | kintone の接続に使うパスワードです。必須です。 | なし |
| アプリID | appId | 登録先の kintone アプリの番号です。必須です。 | なし |
| 登録種別のフィールド | fieldType | 登録種別を書き込むフィールドです。必須です。 | registration_type |
| 受信日時のフィールド | fieldDatetime | 受信日時を書き込むフィールドです。必須です。 | receive_datetime |
| 送信元のフィールド | fieldSender | 送信元を書き込むフィールドです。必須です。 | sender |
| 履歴のフィールド | fieldHistory | 本文の履歴を書き込むフィールドです。必須です。 | history |
| 会社名のフィールド | fieldCompanyName | 会社名を書き込むフィールドです。任意です。 | company_name |
| 氏名のフィールド | fieldUserName | 氏名を書き込むフィールドです。任意です。 | user_name |
| 本文のフィールド | fieldBody | 本文を書き込むフィールドです。任意です。 | body |
| 統合条件 | updateToleranceMode | 既存のレコードに追記する範囲を、同一日付か時間かで設定します。 | 同一日付 |
| 統合範囲（時間） | updateToleranceHours | 統合条件が時間のときの、前後の時間です。 | 5 |

- 新しい送信先の接続先（サブドメイン）には、置き換えが必要な仮の値が入ります。`既定値`の欄のフィールド名は、kintone のフィールドコードの既定値です。
- 空の任意項目は、kintone に書き込みません。

### 2.3 引継ぎ内容

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| 送信元 | senderAddress | 引き継ぐ相手の電話番号です。 | なし |
| 会社名 | companyName | 引き継ぐ会社名です。会社名の抽出がオンのときに必須です。 | なし |
| 氏名 | userName | 引き継ぐ氏名です。必須です。 | なし |
| 受信日時 | timestampMillis | 最後に記録した日時です。 | なし |

### 2.4 ログ

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| 種別 | － | 受信完了、送信開始、送信完了、返信完了のいずれかです。 | なし |
| 記録日時 | － | ログを記録した日時です。 | なし |
| 送信元 | － | SMS の発信元の電話番号です。 | なし |
| 本文 | － | SMS の本文の全文です。 | なし |
| 成否 | － | 成功か失敗かです。 | なし |
| メッセージ | － | 結果の説明です。 | なし |
| 送信先名 | － | 登録先の送信先の名前です。 | なし |
| 抽出結果 | － | 会社名、氏名、本文、抽出の方法です。 | なし |
| 引継ぎの有無 | － | 引継ぎで登録したかどうかです。 | なし |

### 2.5 端末（アプリ・送信先）の設定ファイル

設定のインポート・エクスポートで作る JSON ファイルです。保存先は利用者が選びます。

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| アプリの設定 | appConfig | アプリの設定のすべての項目です。 | 書き出し時点の値 |
| 送信先の設定 | sendTargetConfig | すべての送信先です。ログイン名とパスワード、接続先、アプリID、フィールドの対応、振り分けキーワード、会社名、統合条件を含みます。 | 書き出し時点の値 |
| 引継ぎ内容 | continuationInfoConfig | 送信元ごとの会社名、氏名、受信日時です。 | 書き出し時点の値 |

- 書き出さないもの: 送信先の内部の番号、SMS のログ、AI の抽出結果、端末の SMS です。
- 送信先の内部の番号は、読み込み時に新しく付け直します。
- 読み込みは、既存の設定に統合します。名前が同じ送信先は更新し、ない送信先は追加します。引継ぎ内容は、送信元が同じものを更新し、ない送信元は追加します。

## 3. 注意事項

- 送信先のログイン名とパスワードは、端末内に平文で保存されます。
- 端末（アプリ・送信先）の設定ファイルには、ログイン名とパスワードが平文で含まれます。
- ログには SMS の本文の全文が保存され、件数に上限はありません。手動で削除するまで残ります。
- 引継ぎ内容は、ログを削除しても残ります。
