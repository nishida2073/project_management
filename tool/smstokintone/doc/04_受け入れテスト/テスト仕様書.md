# テスト仕様書（受け入れテスト）

## 1. 概要

本書は、本ツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: 端末が受信した SMS を kintone に登録する本ツール
- 実施環境: Android の端末、別の端末、テスト用の kintone 環境
- 注意事項
  - テスト中、本ツールが使うファイルを別のアプリで開かない
  - テストで作成・登録したものは kintone に残るため、テスト用の環境で実行する
  - テストで送った返信は相手に届くため、テスト用の電話番号にだけ送る
  - AI による抽出は端末に依存するため、本書では扱わない

## 2. 用語

| 用語 | 意味 |
|---|---|
| 本ツール | 端末が受信した SMS を、kintone に登録するツールです。 |
| 送信先 | SMS を登録する kintone アプリの設定です。振り分けキーワードを持ちます。 |
| 振り分けキーワード | 会社名に含まれると、その送信先に登録される文字列です。 |
| デフォルトの送信先 | 振り分けキーワードが一つもない送信先です。どのキーワードにも一致しない SMS を登録します。 |
| 送信モード | SMS を自動で登録するか、手動で登録するかの設定です。 |
| 返信モード | 抽出できなかった SMS の送信元に、定型文を自動で返信するかの設定です。 |
| 抽出 | SMS の本文から会社名と氏名を取り出すことです。 |
| 引継ぎ | 同じ送信元の以前の会社名と氏名を、次の SMS に引き継ぐことです。 |
| 追記 | 既存のレコードの履歴に、新しい SMS の本文を受信日時の順に加えることです。 |
| 設定ファイル | 本ツールの設定を書き出した JSON ファイルです。 |
| 登録 | 受信した SMS を kintone のレコードとして書き込むことです。 |

## 3. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | SMS を受信すると、送信先の設定に従って kintone に自動で登録できる |
| R-02 | SMS の本文から会社名と氏名を取り出して、登録できる |
| R-03 | 同じ送信元の以前の会社名と氏名を、次の SMS に引き継いで登録できる |
| R-04 | 同じ送信元の SMS を、既存のレコードの履歴に追記できる |
| R-05 | 会社名に応じて、振り分けた送信先の kintone アプリに登録できる |
| R-06 | 抽出できなかった SMS の送信元に、定型文を自動で返信できる |
| R-07 | 受信した SMS を検索で選び、手動で kintone に登録できる |
| R-08 | 受信、登録、返信の記録を確認し、不要になった記録を削除できる |
| R-09 | 設定を書き出し、読み込んで反映できる |

## 4. テスト

### 4.1 R-01

#### 利用資材

- 送信先：「テスト用の送信先」
  - kintone の接続先と認証情報が、テスト用の kintone 環境の値で保存されている
  - 登録先の kintone アプリが、テスト用の kintone 環境にある
- 送信元：「テスト用の送信元」（別の端末の電話番号）

#### 合格基準

- SMS を受信すると、送信先の設定に従って、kintone にレコードが登録される。
- 送信モードが手動のときは、SMS を受信しても、kintone にレコードは登録されない。

#### テストケース

| 通番 | 概要 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|---|
| 1 | SMSを受信すると、kintone に自動で登録される | 利用資材と同じ | 別の端末から、送信元「テスト用の送信元」で、本文「テスト会社」「テスト太郎」の SMS を受信します。 | kintoneのレコード：「テスト会社」「テスト太郎」の内容で登録される |  |
| 2 | 送信モードが手動のときにSMSを受信すると、登録されない | 利用資材と同じ | 「SMSの送信モード」を「手動」にしたあと、別の端末から、送信元「テスト用の送信元」で、本文「テスト会社」「テスト太郎」の SMS を受信します。 | kintoneのレコード：登録されない |  |

#### テスト後の復元

- 「SMSの送信モード」を「自動」に戻す。

### 4.6 R-06

#### 利用資材

### 4.7 R-07
