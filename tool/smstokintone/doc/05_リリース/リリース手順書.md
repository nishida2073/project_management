# リリース手順書

## 1. はじめに

　本ツールは、端末が受信した SMS を kintone に登録する Android アプリです。<br>
　本書は、担当者の Android 端末に本ツールを導入し、運用を始められる状態にするための手順を説明します。

## 2. 用意するもの

- Android 8.0 以上の端末と、SMS を受信できる SIM（電話番号）があること。
- 端末に「Google メッセージ」アプリが入っていて、既定の SMS アプリになっていること。
- 配布された s2k.apk を、端末に保存できること。
- 次の情報が、ツールの管理者から渡されていること。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード、SMS を登録するアプリの ID。

## 3. 導入の手順

### 「Google メッセージ」のインストールと設定

1. 端末に「Google メッセージ」アプリが入っていることを確認します。
   - 入っていない場合は、Play ストアで「Google メッセージ」を検索して入れます。
2. 「設定」→「アプリ」→「既定のアプリ」→「SMS アプリ」を開き、「Google メッセージ」を選びます。

### 配布物の展開

1. 配布された s2k.apk を、端末のダウンロードフォルダに保存します。
   - 保存したフォルダを「ダウンロードのフォルダ」と呼びます。

- ダウンロードのフォルダ

```
ダウンロード\
└─ s2k.apk
```

2. 端末で s2k.apk を開き、インストールします。
   - 端末で不明なアプリのインストールが許可されていない場合は、許可の画面に従って許可してからインストールします。

### 初期設定

1. 本ツールを起動します。
2. 「アプリの設定」を開き、「許可する（SMSの読み取り）」「許可する（SMSの受信）」「許可する（SMSの送信）」を押して、端末の許可を与えます。
   - 許可されていない権限があると、その権限を使う機能は動きません。
3. 「送信先の設定」を開き、「設定を追加」を押して、用意した値で送信先を作ります。
4. 「設定を保存」を押します。
   - 送信先は、「設定を保存」を押すまで保存されません。
5. 「アプリの設定」で、「SMSの送信モード」と「SMSの返信モード」を、運用に合わせて選びます。

### 導入の確認（GUI）

1. 「送信先の設定」で、作った送信先の「テスト送信」を押し、テスト用の本文を入力して「送信」を押します。
   - テスト送信は、実際に kintone へ登録されます。テスト用のアプリを使ってください。
2. 「テスト結果」のダイアログに、登録の結果と抽出の結果が表示されることを確認します。
3. kintone のアプリで、テスト送信で登録されたレコードが作られていることを確認します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
- 設定のエクスポートで書き出したファイルには、パスワードが平文で含まれます。ファイルの扱いに注意してください。
- テスト送信は、実際に kintone へ登録されます。本番のアプリでは実行しないでください。
