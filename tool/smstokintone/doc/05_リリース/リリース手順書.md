# リリース手順書

## 1. 目的と対象

- 対象: 端末が受信した SMS を kintone に登録する本ツール（Android アプリ）。
- 担当者の Android 端末に本ツールを導入し、SMS を kintone に登録できる状態にします。

## 2. 用意するもの

- Android 8.0 以上の端末と、SMS を受信できる SIM（電話番号）があること。
- 端末に「Google メッセージ」アプリが入っていて、既定の SMS アプリになっていること。
- 配布された s2k.apk を、端末に保存できること。
- 次の情報が、ツールの管理者から渡されていること。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。
  - SMS を登録するアプリの ID。

## 3. 導入の手順

### 配布物の展開

1. 配布された s2k.apk を、端末のダウンロードフォルダに保存します。
   - 保存したフォルダを「ダウンロードのフォルダ」と呼びます。

- ダウンロードのフォルダ

```
ダウンロード\
└─ s2k.apk
```

2. 端末で s2k.apk を開き、インストールします。
   - 端末で不明なアプリのインストールが許可されていない場合は、許可の画面に従って許可してからインストールします。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

3. 本ツールを起動します。
4. 「アプリの設定」を開き、「許可する（SMSの読み取り）」「許可する（SMSの受信）」「許可する（SMSの送信）」を押して、端末の許可を与えます。
   - 許可されていない権限があると、その権限を使う機能は動きません。
5. 「送信先の設定」を開き、「設定を追加」を押して、用意した値で送信先を作ります。
6. 「設定を保存」を押します。
   - 送信先は、「設定を保存」を押すまで保存されません。
7. 「アプリの設定」で、「SMSの送信モード」と「SMSの返信モード」を、運用に合わせて選びます。

### 導入の確認（GUI）

8. 「送信先の設定」で、作った送信先の「テスト送信」を押し、テスト用の本文を入力して「送信」を押します。
   - テスト送信は、実際に kintone へ登録されます。テスト用のアプリを使ってください。
9. 「テスト結果」のダイアログに、登録の結果と抽出の結果が表示されることを確認します。
10. kintone のアプリで、テスト送信で登録されたレコードが作られていることを確認します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
- 設定のエクスポートで書き出したファイルには、パスワードが平文で含まれます。ファイルの扱いに注意してください。
- テスト送信は、実際に kintone へ登録されます。本番のアプリでは実行しないでください。
