# 用語

本ツールで使う用語の意味をまとめます。文書の書き方は「共通ルール」を参照してください。

| 用語 | 意味 |
|---|---|
| 本ツール | このアプリ（S2k）のことです。 |
| 送信先 | 受信した SMS を登録する kintone アプリの設定です。送信先ごとに、接続先、認証情報、連絡用のアプリ、フィールドの対応、振り分けキーワード、統合条件を持ちます。 |
| 会社名（基本の設定） | 会社名の抽出がオフのときに、その送信先に登録する固定の会社名です。送信先の設定の「基本の設定」にあります。 |
| 振り分け | 会社名に振り分けキーワードが含まれるかで、登録先の送信先を決めることです。会社名の抽出がオンのときに行います。 |
| 振り分けキーワード | 送信先の設定で「含む文字列」として入力する文字列です。会社名に含まれていると、その送信先に登録されます。 |
| デフォルトの送信先 | 振り分けキーワードが一つもない送信先です。どの送信先のキーワードにも一致しなかった SMS の登録先になります。 |
| フィールドコード | kintone の各フィールドを識別する名前です。送信先の設定の「フィールドコード」で入力し、書き込み先のフィールドを決めます。 |
| フィールドの対応 | 送信先の項目（送信元、履歴など）と、kintone の書き込み先のフィールドの組み合わせです。フィールドコードで設定します。 |
| 統合条件 | 同じ送信元の既存のレコードに、新しい SMS を追記する範囲の決め方です。「同一日付」と「時間」の 2 種類があります。 |
| 統合範囲（時間） | 送信先の統合条件が「時間」のときの範囲です。受信日時の前後、指定した時間（±時間）以内の既存のレコードを探します。既定は 5 時間です。 |
| 登録 | 受信した SMS を kintone のレコードとして書き込むことです。本ツールの「送信」は、この登録を指します。 |
| 登録種別 | 登録のレコードに書き込む種別です。本ツールは「外部ツール」として登録します。 |
| 受信日時 | SMS を受信した日時です。 |
| 送信元 | SMS の発信元の電話番号です。 |
| 履歴 | 同じ送信元の SMS の本文を、受信日時の見出しを付けて、受信日時の順に連ねた欄です。 |
| 追記 | 既存のレコードの履歴に、新しい SMS の本文を受信日時の順に加えることです。 |
| 重複 | 同じ送信元の既存のレコードと最終受信日時が分単位で一致し、本文も履歴にすでにある SMS です。この場合は更新をスキップします。 |
| 送信モード | 受信した SMS を自動で登録するか、手動で登録するかの設定です。トップ画面では「SMSの送信モード」と表示します。 |
| 自動送信 | 送信モードが「自動」のとき、受信した SMS を kintone へ自動で登録することです。 |
| 自動送信の対象（抽出状況が異常） | 送信モードが「自動」のときに操作できる設定です。抽出状況が異常な SMS も自動送信の対象に含めます。既定はオフです。 |
| 送信キュー | 手動で選んだ SMS を、1 件ずつ順番に登録するための待ち行列です。 |
| 送信状況 | ログをもとに、SMS が kintone へ登録済みかを表す状態です。未送信（⬜ 未）、済（自動）（✅）、済（手動）（☑️）があります。 |
| 再試行 | 通信エラー、または kintone の一時的なエラー（HTTP 5xx・429）のとき、間隔を少しずつ長くして登録をやり直すことです。最初の実行を含めて最大 5 回までです。 |
| テスト送信 | 送信先の設定を確かめるための、テスト用の登録です。実際に kintone へ登録されます。 |
| テスト結果 | テスト送信の登録の結果と、抽出した会社名、氏名、本文を示すダイアログです。 |
| 返信モード | 返信を自動で送るか、手動で送るかの設定です。 |
| 自動返信 | 返信モードが「自動」のとき、抽出状況が異常な SMS の送信元に、返信メッセージを自動で送ることです。 |
| 手動返信 | SMS の検索画面で SMS を長押しして、標準の SMS アプリで返信を開くことです。返信メッセージ（自動入力）が入ります。 |
| 自動返信の間隔 | 同じ送信元へ自動返信する間隔（秒）です。この時間が経つまで、同じ送信元へ自動返信を再送信しません。既定は 10 秒です。 |
| 返信メッセージ（自動入力） | 返信で送る定型文です。「正しく抽出できた場合」と「正しく抽出できなかった場合」の 2 種類があります。 |
| 返信状況 | SMS に返信したかを表す状態です。📨 は自動返信が済んだことを示します。 |
| 抽出 | SMS の本文から会社名と氏名を取り出すことです。 |
| 抽出状況 | 抽出が正常か異常かを表す状態です。会社名または氏名を取り出せなかった SMS は「異常」（🆖）、取り出せた SMS は「正常」（🆗）になります。 |
| 抽出対象 | 会社名と氏名を取り出した元を示すアイコンです。💬 は SMS の本文から、💾 は引継ぎ内容から取り出したことを示します。 |
| 会社名 | SMS の本文から取り出す会社名です。会社名の抽出がオンのとき、本文の 1 行目を会社名として扱います。 |
| 氏名 | SMS の本文から取り出す氏名です。会社名の抽出がオンのときは 2 行目、オフのときは 1 行目を氏名として扱います。 |
| 会社名の抽出 | 本文から会社名と氏名を取り出すかの設定です。既定はオンです。 |
| AIによる抽出 | 端末内の AI を使って、会社名と氏名を抽出する機能です。Gemini Nano に対応した端末だけで使えます。AI の呼び出しに失敗したときは、ルールに基づく抽出を行います。 |
| 会社名の変換 | 抽出した会社名を、設定した表記に置き換えることです。会社名の抽出がオンのときに行います。自動変換と固定変換の 2 種類があります。 |
| 自動変換 | 会社名の変換のうち、英字を半角大文字、数字を半角、それ以外の文字を全角に統一する変換です。既定はオンです。 |
| 固定変換 | 会社名の変換のうち、変換前と変換後の組を利用者が設定する変換です。 |
| 引継ぎ | 同じ送信元の過去の正常な SMS から取り出した会社名と氏名を、次の SMS に引き継ぐ機能です。引き継いだ SMS は、本文から抽出しません。 |
| 引継ぎ内容 | 引継ぎに使う、送信元ごとの会社名と氏名の組です。送信元ごとに、最新の正常な SMS の 1 件を保存します。 |
| 引継ぎの範囲 | 引継ぎに使う過去の SMS の範囲です。「制限なし」か、「同一日のみ」かを設定します。「同一日のみ」では、日付が変わると引継ぎがリセットされます。 |
| 検索条件 | SMS の検索画面で、一覧を絞り込む条件です。受信日の範囲、本文に含む文字列、送信先、抽出状況、送信状況があります。 |
| 結果一覧 | SMS の検索画面で、検索条件に合う SMS を新しい順に並べた一覧です。 |
| 凡例 | ログの画面と SMS の検索画面に表示する、アイコンの意味の一覧です。 |
| SMS選択の対象 | 検索結果で SMS を選べるかの設定です。 |
| SMS選択の対象（抽出状況が異常） | 抽出状況が異常な SMS を、検索結果で選べるようにする設定です。既定はオフです。 |
| 表示テーマ | 画面の表示を、「ライト」か「ダーク」かで選ぶ設定です。 |
| 初期化 | アプリの設定を既定値に戻すボタンです。送信先、ログ、引継ぎ内容は消えません。 |
| 設定のインポート・エクスポート | アプリの設定と送信先、引継ぎ内容を、JSON ファイルに書き出したり読み込んだりする機能です。 |
| ログ | 受信、登録、返信の記録です。 |
| ログの種別 | ログが記録する出来事の種類です。受信完了、送信開始、送信完了、返信完了があります。 |
| 統合範囲（秒） | ログの画面で、送信ログと端末の SMS を同じ SMS とみなす、時刻のずれの許容範囲（±秒）です。既定は 15 秒です。 |
