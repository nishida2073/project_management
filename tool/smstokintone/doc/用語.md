# 用語

本ツールで使う用語の意味をまとめます。文書の書き方は「共通ルール」を参照してください。

| 用語 | 意味 |
|---|---|
| 本ツール | このアプリ（S2k）のことです。 |
| 送信先 | 受信した SMS を登録する kintone アプリの設定です。送信先ごとに、接続先、認証情報、アプリ、フィールドの対応、振り分けキーワード、統合条件を持ちます。 |
| デフォルトの送信先 | 振り分けキーワードがない送信先です。どの送信先のキーワードにも一致しなかった SMS の登録先になります。 |
| 振り分け | 会社名に振り分けキーワードが含まれるかで、登録先の送信先を決めることです。 |
| 振り分けキーワード | 会社名に含まれていると、その送信先に登録される文字列です。 |
| 送信元 | SMS の発信元の電話番号です。 |
| 受信日時 | SMS を受信した日時です。 |
| 抽出 | SMS の本文から会社名と氏名を取り出すことです。 |
| 抽出状況 | 抽出が正常か異常かの状態です。抽出できなかった SMS は「異常」になります。 |
| 会社名の変換 | 抽出した会社名を、設定した表記に置き換えることです。自動変換と固定変換の 2 種類があります。 |
| 自動変換 | 会社名の変換のうち、本ツールが自動で表記をそろえる変換です。 |
| 固定変換 | 会社名の変換のうち、変換前と変換後の対応を利用者が設定する変換です。 |
| AI抽出 | 端末内の AI を使って、会社名と氏名を抽出する機能です。Gemini Nano に対応した端末だけで使えます。 |
| 引継ぎ | 同じ送信元から以前に抽出した会社名と氏名を、次の SMS に引き継ぐ機能です。 |
| 引継ぎ内容 | 引継ぎに使う、送信元ごとの会社名と氏名の組です。 |
| 引継ぎの範囲 | 引継ぎで使う以前の情報の範囲です。制限なしか、同一日のみかを設定します。 |
| 登録 | 受信した SMS を kintone のレコードとして書き込むことです。本ツールの「送信」は、この登録を指します。 |
| 登録種別 | 登録のレコードに書き込む種別です。本ツールは「外部ツール」として登録します。 |
| フィールドコード | kintone の各フィールドを識別する名前です。送信先の設定で、書き込み先のフィールドを決めます。 |
| フィールドの対応 | 送信先の項目と、kintone の書き込み先のフィールドの組み合わせです。 |
| 履歴 | 同じ送信元の SMS の本文を、受信日時の順に連ねた欄です。 |
| 追記 | 既存のレコードの履歴に、新しい SMS の本文を加えることです。 |
| 重複 | 同じ送信元、同じ時刻、同じ本文の SMS が、すでに登録されている状態です。重複の場合は登録しません。 |
| 統合条件 | 同じ送信元の既存レコードに、新しい SMS を追記する範囲の決め方です。同一日付と時間の 2 種類があります。 |
| 統合範囲（時間） | 送信先の統合条件が「時間」のときに、既存レコードを探す前後の時間です。 |
| 統合範囲（秒） | ログの統合範囲です。送信ログと端末の SMS を、同じものとみなす時間の差です。 |
| 送信モード | 受信した SMS を自動で登録するか、手動で登録するかの設定です。 |
| 自動送信 | 送信モードが自動のとき、受信した SMS を自動で登録することです。 |
| 返信モード | 返信を自動で送るか、手動で送るかの設定です。 |
| 返信の文面 | 返信で送る定型文です。正常時と異常時の 2 種類があります。 |
| 返信の間隔 | 同じ送信元へ自動返信する間隔です。 |
| 自動返信 | 抽出が失敗した SMS の送信元に、定型文を自動で送ることです。 |
| 手動返信 | SMS の検索画面から、標準の SMS アプリで返信を開くことです。 |
| 再試行 | 通信エラーや一時的なエラーのとき、一定の間隔をあけて登録をやり直すことです。最初の実行を含めて最大 5 回までです。 |
| 検索条件 | SMS の検索画面で、一覧を絞り込む条件です。受信日の範囲、本文の文字列、送信先、抽出状況、送信状況があります。 |
| SMS 選択の対象 | 抽出に失敗した SMS を、検索画面で選べるかの設定です。 |
| 送信キュー | 手動で選んだ SMS を、1 件ずつ順番に登録するための待ち行列です。 |
| 送信状況 | ログをもとに、SMS が登録済みかを表す状態です。未送信、済（自動）、済（手動）があります。 |
| ログ | 受信、登録、返信の記録です。 |
| ログの種別 | ログが記録する出来事の種類です。受信完了、送信開始、送信完了、返信完了があります。 |
| テスト送信 | 送信先の設定を確かめるための、テスト用の登録です。実際に kintone へ登録されます。 |
| テスト結果 | テスト送信の登録結果と抽出結果を示すダイアログです。 |
| 設定のインポート・エクスポート | アプリの設定と送信先、引継ぎ内容を、JSON ファイルに書き出したり読み込んだりする機能です。 |
