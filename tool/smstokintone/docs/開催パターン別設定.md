# 開催パターン別の推奨設定

開催パターンに応じた、送信先の設定・アプリの設定の推奨値をまとめたものです。設定方法自体は[操作マニュアル](マニュアル.md)を参照してください。

## 個社の場合

1社のみを対象に開催する場合の設定です。

- kintoneアプリ：1つ
- 送信先の設定：1つ
  - 送信先の振り分け：空欄のままにします。送信先が1つしかないため、キーワードで振り分ける必要はありません（空欄＝デフォルトの送信先として、すべてのSMSがこの1つの送信先に登録されます）。
- SMSの送信
  - 自動送信の対象「形式が異常」を**含める**
    - 対象企業が1社のみのため、会社名・氏名を抽出できなかったSMSであっても送信元は必ずその1社に確定します。そのため自動送信の対象に含めても問題ありません。
- SMSの検索（SMS選択の対象）
  - 「形式が異常」を選択可能にしておくことを推奨します。自動送信で問題があった場合に、検索画面から内容を確認して手動で送信できるようにするためです。
- SMSの返信（形式が異常な場合の文言）
  - 会社名の記載を求める必要はありません（例：「本文の形式をご確認のうえ、お手数ですが再度ご連絡ください」）。

## 共催の場合

複数社が合同で参加する開催の場合の設定です。

- kintoneアプリ：1つ
- 送信先の設定：1つ
  - 送信先の振り分け：空欄のままにします。個社開催と同様、送信先が1つしかないためキーワードでの振り分けは不要です（会社ごとに送信先を分けたい場合は、この構成の対象外です）。
- SMSの送信
  - 自動送信の対象「形式が異常」を**含めない**
    - 会社名・氏名を抽出できなかったSMSは、どの参加企業からのものか判別できません。自動送信の対象から外し、[SMSの検索画面](マニュアル.md#SMSの検索画面)で内容を確認してから手動で送信先を判断してください。
- SMSの検索（SMS選択の対象）
  - 「形式が異常」を選択可能にしておきます。自動送信から除外したSMSを、内容を確認したうえで手動送信するための受け皿になります。
- SMSの返信（形式が異常な場合の文言）
  - 返信文言に会社名の記載を促す一文を含めることを推奨します（例：「本文に会社名を明記のうえ、お手数ですが再度ご連絡ください」）。送信元に会社名を書き添えてもらうことで、次回以降のSMSが正常な形式として処理されやすくなります。

## 複数開催をまとめて運用する場合

複数の開催（会社）を1つのアプリで並行して管理する場合の設定です。個社・共催と異なり、開催（会社）ごとに送信先を分けて自動で振り分けます。

- kintoneアプリ：開催ごとに1つ、またはすべて共通の1つ（要件に応じて選択。共通の1つにする場合も、送信先ごとにフィールドコードや統合範囲などの設定は独立して持てます）
- 送信先の設定：開催（会社）の数だけ用意します
  - 送信先の振り分け：各送信先に、その開催の会社名をキーワードとして設定します（送信先の比較対象は「会社名」のまま）。抽出した会社名がキーワードに一致した送信先へ自動的に振り分けられます。
  - 送信先名に開催名を入れておくと、ログや送信元情報の編集画面で見分けやすくなります。
- SMSの送信
  - 自動送信の対象「形式が異常」を**含めない**
    - 会社名を抽出できないSMSは、どの開催のものか判別できずどの送信先にも振り分けられません（送信先未設定として扱われます）。自動送信の対象から外し、手動で内容を確認してください。
- SMSの検索（SMS選択の対象）
  - 「送信先がなし」「形式が異常」の両方を選択可能にしておくことを推奨します。会社名の抽出に失敗した場合だけでなく、キーワードに一致しない（未登録の会社名の）SMSも「送信先がなし」として扱われるため、どちらも手動で拾えるようにしておく必要があります。
- SMSの返信（形式が異常な場合の文言）
  - 共催の場合と同様、返信文言に会社名の記載を促す一文を含めることを推奨します。
