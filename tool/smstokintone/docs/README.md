# PDFマニュアル生成バッチ（`build_pdf-*.bat`）について

## 使い方

`build_pdf-<原稿名>.bat` をダブルクリックすると、同じ階層の `<原稿名>.md` を
`<原稿名>.pdf` に変換します（ファイル名は自分自身の名前から自動的に決まるので、
中身を書き換える必要はありません）。

新しい原稿を追加する場合は、既存の `.bat` をコピーしてファイル名だけ
`build_pdf-<新しい原稿名>.bat` に変更すれば、そのまま使えます。

実体は `..\..\md2png\build_pdf.js` で、`.bat` はこれをオプション付きで呼び出しているだけです。

```bat
node "..\..\md2png\build_pdf.js" "<原稿名>.md" "<原稿名>.pdf" [オプション...]
```

## オプション一覧

| オプション | 説明 | 既定値 |
| --- | --- | --- |
| `--title-page` | 表紙ページを付ける | なし |
| `--narrow-margins` | 余白を狭くする | 通常の余白 |
| `--img-width=N` | `width` 未指定の`<img>`にNpxの幅を補う | 補わない |
| `--toc` | 目次ページを付ける | 目次なし |
| `--toc-depth=N` | 目次に含める見出しの深さ（後述） | `3` |
| `--bookmark-depth=N` | PDFのしおり（アウトライン）に含める見出しの深さ（後述） | `3` |
| `--anchor-levels=2,3,5` | ページ内リンクの対象にする見出しレベル（後述） | `2,3,5` |
| `--extra-css=path` | 共通の`style.css`に追加するCSSファイル | なし |
| `--page-numbers` | ページ番号を付ける | なし |
| `--header` | 表紙・目次を除く各ページ上部にタイトルを表示する | なし |

## 見出しレベルと目次・しおり・リンクの関係

Markdown原稿の見出し（`##`〜`#####`）は、そのままだと目次・しおり・
ページ内リンクの対象にはなりません。対象にするには次の2つを両方満たす必要があります。

1. その見出しレベルが `--anchor-levels` に含まれている（＝そもそもID・リンク先が作られる）
2. その見出しレベルが `--toc-depth` / `--bookmark-depth` 以下である（＝目次・しおりに表示される）

`--anchor-levels` に含まれない見出しレベルは、depthをいくつにしても目次・しおりに出ません。

例えば「S2k 操作マニュアル.md」では、`####`（`機能一覧`／`機能の詳細`という
同じ文言が画面ごとに繰り返し出てくるだけの区切り見出し）をあえて対象外にし、
実際にリンクしたい項目は `#####` の見出しにして `--anchor-levels=2,3,5`（既定値）で
対象にしています。一方「開催パターン別の設定例.md」は `####` が
画面ごとに内容の異なる実質的な見出しなので、`--anchor-levels=2,3,4` を指定して
`####` も対象に含めています。

新しい原稿を作るときは、
- 見出しごとに内容が変わるなら普通に `##`〜`#####` を使う
- 同じ文言が繰り返される単なる区切りラベルなら、目次・しおりに含めたくない
  レベル（既定では`4`）のままにしておく

と考えれば迷いません。

## 見出しの重複とID

見出しの文字列がドキュメント内で重複する場合（例：異なる画面にそれぞれ
「設定の保存」という見出しがある）、自動生成されるID（＝見出しの文字列そのもの）が
衝突し、リンク先が正しく解決できません。この場合は見出しの末尾に
`{#任意のID}` を付けて、IDだけを別にできます。

```md
##### 設定の保存 {#設定の保存-送信先の設定画面}
```

表示される見出しテキストは `設定の保存` のまま、IDだけ
`設定の保存-送信先の設定画面` になります。他の場所からこの見出しへリンクするときは
`[設定の保存](#設定の保存-送信先の設定画面)` のようにIDの方を指定します。

## 独自CSSの追加（`--extra-css`）

その原稿だけ見た目を変えたい場合、共通の `style.css` を直接編集する代わりに、
上書き用のCSSファイルを別に作って `--extra-css=<path>` で渡せます。
指定したファイルの内容は共通CSSの後ろに追記されるため、同じセレクタを
書けば上書きできます。
