# 開催パターン別の推奨設定

## 概要
　開催パターンに応じた、送信先の設定・アプリの設定の推奨値をまとめたものです。設定方法自体は[操作マニュアル](<S2k 操作マニュアル.pdf>)を参照してください。

## 開催別の設定

### 個社の場合

　1社のみを対象に開催する場合の設定です。

#### kintoneアプリについて

- 設定数
  - 1つ
- 運用方法
  - 対象企業のSMSをすべてこの1つのアプリに登録します

#### 送信先の設定について

- 設定数
  - 1つ
- 基本の設定
  - 送信先の振り分け
    - キーワードを1件も追加しません。送信先が1つしかないため、キーワードで振り分ける必要はありません（未設定＝デフォルトの送信先として、すべてのSMSがこの1つの送信先に登録されます）。

#### アプリの設定について

- SMSの検索
  - SMS選択の対象
    - 「抽出状況が異常」を選択可能にしておくことを推奨します
      - 自動送信で問題があった場合に、検索画面から内容を確認して手動で送信できるようにするためです。
- SMSの送信
  - 自動送信の対象
    - 「抽出状況が異常」を**含める**
      - 対象企業が1社のみのため、会社名・氏名を抽出できなかったSMSであっても送信元は必ずその1社に確定します。そのため自動送信の対象に含めても問題ありません。
- SMSの引き継ぎ
  - 引き継ぎ
    - 送信先は常に1つのため、有効・無効は送信先の振り分けには影響しません。会社名・氏名を単体で抽出できないSMSでもkintoneへの登録内容を補えるよう、有効にしておくことを推奨します。

### 共催の場合

　複数社が合同で参加する開催の場合の設定です。

#### kintoneアプリについて

- 設定数
  - 1つ
- 運用方法
  - 複数の参加企業のSMSをまとめてこの1つのアプリに登録します

#### 送信先の設定について

- 設定数
  - 1つ
- 基本の設定
  - 送信先の振り分け
    - キーワードを1件も追加しません。送信先が1つしかないため、キーワードで振り分ける必要はありません（会社ごとに送信先を分けたい場合は、この構成の対象外です）。

#### アプリの設定について

- SMSの検索
  - SMS選択の対象
    - 「抽出状況が異常」を選択可能にしておくことを推奨します
      - 自動送信から除外したSMSを、内容を確認したうえで手動送信するための受け皿になります。
- SMSの送信
  - 自動送信の対象
    - 「抽出状況が異常」を**含めない**
      - 会社名・氏名を抽出できなかったSMSは、どの参加企業からのものか判別できません。自動送信の対象から外し、SMSの検索画面で内容を確認してから手動で送信先を判断してください。
- SMSの引き継ぎ
  - 引き継ぎ
    - こちらも送信先は常に1つのため、送信先の振り分けには影響しません。会社名・氏名を単体で抽出できないSMSでもkintoneへの登録内容を補えるよう、有効にしておくことを推奨します。

### 複数開催をまとめて運用する場合（kintoneアプリ1つ）

　複数の開催（会社）を1つのアプリで並行して管理し、開催（会社）ごとに送信先を分けて自動で振り分ける場合の設定です。全開催のSMSを1つのkintoneアプリに集約します。

#### kintoneアプリについて

- 設定数
  - 1つ
- 運用方法
  - 全開催のSMSをこの1つのアプリに集約します

#### 送信先の設定について

- 設定数
  - 開催（会社）の数だけ用意します
- 基本の設定
  - 送信先の振り分け
    - 各送信先に、その開催の会社名をキーワードとして設定します（送信先の比較対象は「会社名」のまま）。抽出した会社名がキーワードに一致した送信先へ自動的に振り分けられます。
  - 送信先名
    - 開催名を入れておくと、ログや送信元情報の編集画面で見分けやすくなります。
- kintoneの設定
  - 接続先・フィールドコードなどは、すべての送信先で同じ値を指定します。

#### アプリの設定について

- SMSの検索
  - SMS選択の対象
    - 「抽出状況が異常」を選択可能にしておくことを推奨します
      - なお、送信先が未設定（キーワードに一致しない＝未登録の会社名）のSMSは検索画面から選択・手動送信することができないため、そのようなSMSが見つかった場合は該当する送信先のキーワードを追加して解消してください。
- SMSの送信
  - 自動送信の対象
    - 「抽出状況が異常」を**含めない**
      - 会社名・氏名を抽出できないSMSは、どの開催のものか判別できずどの送信先にも振り分けられません（送信先未設定として扱われます）。自動送信の対象から外し、手動で内容を確認してください。
- SMSの引き継ぎ
  - 引き継ぎ
    - 同一の送信元から過去に一度でも会社名・氏名の抽出に成功していれば、それ以降の単体では会社名を判別できないSMSも直近の情報を引き継いで自動的に正しい送信先へ振り分けられ、「抽出状況が異常」による手動対応の件数を大きく減らせるため、有効にしておくことを強く推奨します。
  - 引き継ぎの範囲
    - 同じ電話番号が別の開催（会社）で使い回される可能性がある場合は「同一日のみ」にすることで、日をまたいだ誤った引き継ぎ（別の開催の会社名で登録されてしまうこと）を防げます。

### 複数開催をまとめて運用する場合（kintoneアプリ2つ以上）

　複数の開催（会社）を1つのアプリで並行して管理し、開催（会社）ごとに送信先を分けて自動で振り分ける場合の設定です。開催ごとに別々のkintoneアプリへSMSを登録します。

#### kintoneアプリについて

- 設定数
  - 開催ごとに1つずつ（合計2つ以上）
- 運用方法
  - 開催ごとに別々のアプリへSMSを登録します

#### 送信先の設定について

  - 送信先名
    - 開催名を入れておくと、ログや送信元情報の編集画面で見分けやすくなります。
- kintoneの設定
  - 接続先・フィールドコードなどは、各送信先ごとにその開催用のアプリを指定します。フィールド構成をアプリごとに変えることもできます。

#### アプリの設定について

  - SMS選択の対象

  - 引き継ぎ
