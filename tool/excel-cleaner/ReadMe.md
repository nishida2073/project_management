# clean

## 使い方

### 1. バッチで実行(推奨)

`clean.bat` に Excel ファイルをドラッグ＆ドロップします。

- 結果は元のファイルと同じフォルダに `名前_clean.拡張子` として保存されます。
- 元のファイルは変更されません。
- 既定では書式の削除は行いません(後述の「空セルと行・列の書式」を参照)。

### 2. PowerShell で実行

```powershell
.\clean.ps1 -Path "ブック.xlsx"
.\clean.ps1 -Path "ブック.xlsx" -Output "出力.xlsx"
.\clean.ps1 -Path "ブック.xlsx" -RowMargin 20
.\clean.ps1 -Path "ブック.xlsx" -TrimFormat
```

| パラメータ | 既定値 | 説明 |
|---|---|---|
| `-Path` | (必須) | 処理する Excel ファイル |
| `-Output` | `名前_clean.拡張子` | 出力先。元と同じ名前は指定できません |
| `-RowMargin` | `10` | 条件付き書式と入力規則の範囲を、各シートのデータ最終行 + この行数までに縮めます |
| `-TrimFormat` | オフ | 空セルの書式と、行・列の書式を削除します |

## 処理内容

1. **隠し定義名の削除**: 非表示の定義名のうち、数式や入力規則から参照されていないものを削除します。`_xlnm` で始まる名前(印刷範囲、フィルター)は残します。
2. **外部リンクの削除**: 他のブックを参照する定義名と、外部リンク本体を削除します。数式から外部リンクが参照されていない場合に限ります。
3. **`#REF!` の条件付き書式の削除**: 参照先が消えて `#REF!` になった条件付き書式のルールを削除します。
4. **条件付き書式の統合**: 書式・条件が同じで、他のルールと重ならず、参照がそのセル自身だけのルールをまとめます。
5. **範囲の縮小**: `:1048576` のような列全体の範囲を、データ最終行 + `-RowMargin` までに縮めます。条件付き書式と入力規則が対象です。
6. **空セルと行・列の書式の削除(`-TrimFormat` 指定時のみ)**: データのある範囲の外にある、値のない書式だけのセルと、行・列の書式を削除します。

## 処理結果の見方

実行すると、次のような集計が表示されます。

```
隠し定義名: 0
外部参照の定義名: 0
外部リンク: 0
参照エラーのCF: 0
CF統合(減ったルール数): 0
範囲の縮小: 0
空セルの書式: 0
行・列の書式: 0
```

| 項目 | 意味 |
|---|---|
| 隠し定義名 | 削除した非表示の定義名の数 |
| 外部参照の定義名 | 他のブックを参照していて、削除した定義名の数 |
| 外部リンク | 削除した外部リンク本体の数(0 または 1 以上の数) |
| 参照エラーのCF | 削除した `#REF!` を含む条件付き書式のルールの数 |
| CF統合(減ったルール数) | 条件付き書式を統合して減ったルールの数 |
| 範囲の縮小 | 上限行まで縮めた条件付き書式・入力規則の範囲の数 |
| 空セルの書式 | 削除した、データ範囲外の空セルの数(`-TrimFormat` 指定時のみ) |
| 行・列の書式 | 削除した、データ範囲外の行・列の書式の数(`-TrimFormat` 指定時のみ) |

### 0 が並ぶ場合

- **すでに一度処理済みのファイル**: 隠し定義名や `#REF!` のルールは残っていないので、0 になります。これは正常です。
- **空セルと行・列の書式が 0**: `-TrimFormat` を指定していないので、書式は削除されていません。書式を削除したい場合は、`-TrimFormat` を付けて実行してください。
- **条件付き書式の統合が 0**: 統合できるルールがないか、重なりや相対参照のため統合を見送ったためです。

## 注意

- 余白(`-RowMargin`)より下の行に後から入力するデータには、入力規則や条件付き書式が効きません。追加入力が多いシートでは、余白を大きくしてください。
- 統合した条件付き書式の見た目は、Excel の画面で確認してください。
- マクロ(`.xlsm`)は変更されません。ただし、マクロの動作は確認していません。
- 修復の確認が出た場合は、元のファイルを使ってください。
