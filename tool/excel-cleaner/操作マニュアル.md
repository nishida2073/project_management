# 操作マニュアル

## 1. 目的と対象

- 開くのに時間がかかる Excel を軽くします。
- 対象は、`.xlsx` と `.xlsm`(マクロ付き)です。

## 2. 使い方

1. Excel ファイルを、`clean.bat` の上にドラッグ＆ドロップします。
2. 黒い画面が開き、処理の結果が表示されます。
3. 表示が終わったら、何かキーを押すと画面が閉じます。
4. 元のファイルと同じフォルダに、`名前_clean.拡張子` という新しいファイルができます。

> 注意
> - 元のファイルは変更されません。
> - 同じファイルを続けて実行すると、前回の `_clean` ファイルは上書きされます。前回の結果を残したい場合は、名前を変えてから実行してください。

## 3. 結果の見方

処理が終わると、次の集計が表示されます。

| 表示 | 意味 |
|---|---|
| 隠し定義名 | 使われていない、非表示の名前を削除した数 |
| 外部参照の定義名 | 他のブックを参照している名前を削除した数 |
| 外部リンク | 他のブックへのリンクを削除した数 |
| 参照エラーのCF | 参照先が消えて「#REF!」になった条件付き書式を削除した数 |
| CF統合(減ったルール数) | 同じ条件の条件付き書式をまとめて減らした数 |
| 範囲の縮小 | 列全体に設定されていた範囲を、データの範囲までに縮めた数 |
| 空セルの書式 | 書式の削除は行わないので、0 のままです |
| 行・列の書式 | 書式の削除は行わないので、0 のままです |

### 0 が並ぶ場合

- **すべて 0 の場合**: 前に一度処理したファイルです。すでにきれいな状態なので、正常です。
- **「空セルの書式」と「行・列の書式」が 0 の場合**: 書式の削除は既定で行わないためです。正常です。
- **「CF統合」が 0 の場合**: 統合できるルールがなかったためです。正常です。

## 4. 処理の後に確認すること

1. 新しい `_clean` ファイルを開きます。
2. 修復の確認が出ないことを確かめます。
3. 入力されているデータ、数式、色、罫線が元のファイルと同じことを確かめます。
4. 進捗表などで、データを追加する行にプルダウンや色が付くことを確かめます。

> 注意
> - 条件付き書式や入力規則は、データの最後の行から **10 行** 先までに範囲が縮まります。それより下の行に新しく入力すると、プルダウンや色が付かないことがあります。
> - 修復の確認が出た場合は、元のファイルを使ってください。

## 5. 困ったとき

- **黒い画面がすぐに閉じる**: バッチを直接ダブルクリックせず、Excel ファイルをドラッグ＆ドロップして実行してください。
- **文字化けする**: 画面の表示が文字化けしても、処理の内容には影響しません。
- **開いたら修復の確認が出る**: 元のファイルを使ってください。その場合は、ファイルの種類と症状を開発の担当者に伝えてください。
