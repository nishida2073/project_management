# 実行一覧ファイルの書き方

GUI版（`kintoneリソース生成ツール.exe`）の「実行」タブ内、「一括実行」で読み込むExcelファイルの書き方。

## 全体構成

- 読み込むのは先頭のシートのみ
- 1行目がヘッダー、2行目以降が1行＝1回分の実行対象（0. スペース作成〜4. データチェックをまとめて実行する単位）
- 列名は以下の4つ（この通りに書く。列の順序は自由）

| スペース識別名 | スペーステンプレートID | 設定テンプレート名（基本） | 設定テンプレート名（カスタム） |
|---|---|---|---|

- この4列以外の列は自由に追加してよい（例：`No`のような管理用の列）。ツール側はこの4列を列名で参照するだけで、他の列は読み込まれても無視されるため、増やしても動作に影響しない。

## 各列の書き方

### スペース識別名

各工程の出力ファイル名（`download\<スペース識別名>_download.xlsx`など）とログファイル名に使われる名前。GUIの「実行」タブの「スペース識別名」欄にそのままセットされる。

### スペーステンプレートID

「0. スペース作成」で使うスペーステンプレートのID。GUIの「スペーステンプレートID」欄にそのままセットされる。テンプレートIDはkintoneの管理画面（テンプレートとして保存したスペースの一覧）のURLから確認できる。

### 設定テンプレート名（基本）

「2. 設定ファイルの生成」で使う基本となる設定テンプレート名（`template\base\<設定テンプレート名（基本）>.xlsx`の`<設定テンプレート名（基本）>`）。GUIの「設定テンプレート名（基本）」欄にそのままセットされる（`template\base`フォルダ内の既存ファイル名の候補に無い場合も、文字列としてそのままセットされる）。必須項目で、空の行はスキップされる。

### 設定テンプレート名（カスタム）

「2. 設定ファイルの生成」で使うカスタム用の設定テンプレート名（`template\custom\<設定テンプレート名（カスタム）>.xlsx`の`<設定テンプレート名（カスタム）>`）。GUIの「設定テンプレート名（カスタム）」欄にそのままセットされる。省略可能で、空の場合は設定テンプレート（カスタム）を使わずに実行される。

## 実行内容

1行につき、0. スペース作成 → 1. ダウンロード → 2. 設定ファイルの生成 → 3. kintoneへ反映 → 4. データチェックを順番に実行する（各工程の内容は[ツールのREADME](../README.md)を参照）。スペースIDは「0. スペース作成」の結果から自動的に決まるため、この実行一覧ファイルに含める列ではない。

## 注意点

> スペース識別名・スペーステンプレートID・設定テンプレート名（基本）のいずれかが空の行はスキップされる。実行後に表示される「一括実行 結果」には、その行が`スキップ（必須項目が空）`として記録される（設定テンプレート名（カスタム）は空でもスキップされない）。

> いずれかの行の工程が失敗した場合も、その行の結果（失敗した工程名）を記録した上で次の行の処理を続行する（一括実行全体は中断しない）。
