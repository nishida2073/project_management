# 一括実行ファイルの仕様書

## 1. 概要

　複数のスペースを、一度に作成して設定するための Excel ファイル（実行一覧ファイル）の仕様です。

## 2. 構成

　一括実行ファイルは、次のシートからなる 1 つの Excel ファイルです。

| シート名 | 役割 |
|---|---|
| 対象一覧 | 作成するスペースを 1 行ずつ定義します。 |

## 3. 各シートの詳細について

### 対象一覧

　対象一覧は、作成するスペースを 1 行ずつ定義します。

#### 項目

| 項目名 | 内容 | 利用できる値 |
|---|---|---|
| スペース識別名 | 作成するスペースを区別する名前です。空欄の行は読み飛ばします。 | 文字列 |
| スペーステンプレートID | スペースの作成に使うテンプレートの ID です。空欄の行は読み飛ばします。 | 数値（例: `2`） |
| 設定テンプレート名（基本） | 基本の設定テンプレートの名前です。 | 文字列（テンプレートの名前と一致させます） |
| 設定テンプレート名（カスタム） | カスタムの設定テンプレートの名前です。 | 文字列（テンプレートの名前と一致させます） |

> **注意**
> - 「スペース識別名」か「スペーステンプレートID」が空欄の行は、スキップします。
> - 「設定テンプレート名（基本）」と「設定テンプレート名（カスタム）」は、どちらか一方が必要です。両方が空欄の行は、スキップします。

## 4. サンプル

　次の例は、5 行の対象一覧です。1 行目は項目名です。

| スペース識別名 | スペーステンプレートID | 設定テンプレート名（基本） | 設定テンプレート名（カスタム） |
|---|---|---|---|
| L01 | `2` | `基本A` | |
| L02 | `2` | | `カスタムB` |
| | `2` | `基本A` | |
| L03 | | `基本A` | |
| L04 | `2` | | |

- 2 行目（L01）: 基本の設定テンプレート「基本A」を使います。
- 3 行目（L02）: カスタムの設定テンプレート「カスタムB」を使います。
- 4 行目: スペース識別名が空欄のため、スキップします。
- 5 行目（L03）: スペーステンプレートIDが空欄のため、スキップします。
- 6 行目（L04）: 設定テンプレート名が両方とも空欄のため、スキップします。
