# リリース手順書

## 1. 目的と対象

- 対象: kintone のスペースを作成、ダウンロード、反映するツール（kintoneリソース生成ツール）。
- 担当者の PC にツールを導入し、スペースを作成できる状態にします。

## 2. 用意するもの

- Windows の PC と、Excel があること。
- 次の情報が、ツールの管理者から渡されていること。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。

## 3. 導入の手順

### 配布物の展開

1. 配布された zip ファイルを展開します。
   - 展開したフォルダを「ツールのフォルダ」と呼びます。

- ツールのフォルダ

```
ツールのフォルダ\
├─ kintoneリソース生成ツール.exe
├─ bats\
│   ├─ common.bat
│   ├─ （処理のスクリプト一式）
│   └─ library\
└─ template\
    └─ base\
        └─ クラススペース.xlsx
```

ツールを実行すると、出力先のフォルダとログのフォルダが自動で作られます。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

2. ツールのフォルダの kintoneリソース生成ツール.exe を起動します。
3. 共通設定は、必要な場合のみ変更して保存します。
4. グループを作成し、用意した値を入力して保存します。
   - 保存すると、clients フォルダに、グループ設定ファイル（グループ名の bat ファイル）が作られます。

### 導入の確認（GUI）

5. 「一括実行」タブで、対象のグループとスペース識別名を指定して実行します。スペースが作られ、ダウンロード、設定ファイルの作成、反映、確認までが行われることを確認します。
   - この確認は kintone へ反映します。対象の kintone 環境が、正しいことを確かめてから実行してください。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
