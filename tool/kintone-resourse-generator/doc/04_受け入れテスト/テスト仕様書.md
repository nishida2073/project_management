# テスト仕様書（受け入れテスト）

## 1. 概要

本書は、kintone のスペースを作成、ダウンロード、反映するツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: kintone のスペースを作成、ダウンロード、反映するツール
- 実施環境: テスト用の kintone 環境
- 注意事項
  - テスト中、ツールが使うファイルを別のアプリで開かない
  - テストで作成・投稿したものは kintone に残るため、テスト用の環境で実行する

## 2. 用語

| 用語 | 意味 |
|---|---|
| グループ | kintone の接続情報などの設定を、まとめて管理する単位です。 |
| スペース識別名 | スペース設定ファイルなどの名前に使う識別名です。 |
| スペーステンプレート | 新しいスペースを作るときのもとになる、kintone のテンプレートです。 |
| 設定テンプレート | スペースの設定を作るときのもとになるファイルです。基本とカスタムの 2 種類があります。 |
| グループ設定ファイル | グループの接続情報などを書いた bat ファイルです。 |
| スペース設定ファイル | 設定テンプレートとダウンロード結果から作る、スペースの設定を書いた Excel ファイルです。 |
| ダウンロード結果 | 対象のスペースの現在の状態を書き出した Excel ファイルです。 |
| チェック結果 | スペース設定ファイルと kintone の現在の状態を比べた結果の Excel ファイルです。 |
| 実行一覧ファイル | 複数のスペースを行ごとに指定して、まとめて処理するための Excel ファイルです。 |
| テンプレートファイル | スペースの情報から作る Excel ファイルで、設定テンプレートのもとになります。 |
| 共通設定ファイル | 全グループ共通の設定（フォルダの場所など）を書いた bat ファイルです。 |
| スペース | kintone のスペースです。作成、ダウンロード、反映の対象になります。 |
| 接続情報 | kintone に接続するための情報です。 |
| ログ | 処理の実行結果を残した記録です。ログの画面で確認したり、削除したりします。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |

## 3. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | 対象のグループとスペース識別名を指定すると、スペースの作成から確認までを一度に行える |
| R-02 | 実行一覧ファイルに書いたスペースを、行ごとにまとめて処理できる |
| R-03 | 既存のスペースの現在の状態をダウンロードし、そこからスペース設定ファイルを作成できる |
| R-04 | スペース設定ファイルの内容を kintone のスペースに反映し、反映結果を確認できる |
| R-05 | 実行結果のログを確認し、不要になったログを削除できる |
| R-06 | 共通の設定を変更して保存できる |
| R-07 | グループの設定を変更して保存できる |
| R-08 | グループを新規作成したり、既存のグループをコピーしたりできる |
| R-09 | スペースの情報から、テンプレートファイルを作成できる |

## 4. テスト

### 4.1 R-01

#### 利用資材

- グループ：「test01」
  - 接続情報：「テスト用の値」で保存されている
  - 設定テンプレート（基本）：「クラススペース」がある
- 共通設定ファイル：「common.bat」
  - フォルダが、テスト用の値で保存されている
- スペーステンプレート：「テスト用のスペーステンプレート」
  - kintone に存在する

#### 合格基準

- 対象のグループとスペース識別名を指定して一括実行すると、スペースが作られ、ダウンロード、設定ファイルの作成、反映、確認までが行われる。
- 選ばなかった処理は実行されず、状態がスキップになる。
- 失敗した処理がある場合は、後続の処理は実行されず、状態が失敗になる。

#### テストケース

|---|---|---|---|---|
| 1 | 利用資材と同じ | 一括実行で、対象のグループ「test01」、スペース識別名「TestSpace」、スペーステンプレートID「テスト用のテンプレートID」、設定テンプレート（基本）「クラススペース」を選び、「実行」を押します。 | 状態：成功、kintone のスペース：「TestSpace」が作られる、ダウンロード結果：「TestSpace_download.xlsx」、スペース設定ファイル：「TestSpace_config.xlsx」、チェック結果：「TestSpace_check.xlsx」 |  |
| 2 | 利用資材と同じ | 一括実行で、対象のグループ「test01」、スペース識別名「TestSpace2」、スペーステンプレートID「テスト用のテンプレートID」、設定テンプレート（基本）「クラススペース」を選び、スペースの確認のチェックを外して、「実行」を押します。 | 状態（スペースの確認）：スキップ、状態：成功、チェック結果：「TestSpace2_check.xlsx」は作られない |  |
