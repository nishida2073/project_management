# 環境構築（受け入れテスト）

## 1. 目的と対象

- 対象: kintone のスペースを作成、ダウンロード、反映するツール
- テスト用の kintone 環境と、ツールの設定を準備します。

## 2. 前提

- テスト用の kintone 環境があり、スペーステンプレートとスペースを作成できること
- Excel があり、実行一覧ファイルを開けること

## 3. 構築手順

### ツールの初期化

1. ツールの bats フォルダの init-test-env.bat を実行します。common.bat、clients フォルダの test01.bat、run-list フォルダの multiple1.xlsx、multiple2.xlsx、multiple3.xlsx が、test-data の内容になります。download フォルダ、config フォルダ、checked フォルダ、logs フォルダは削除されます。

### スペーステンプレートとスペースの構築

2. テスト用の kintone 環境に、スペーステンプレート「テスト用のスペーステンプレート」を用意します。作ったテンプレートの ID を控えます。
3. テスト用の kintone 環境に、スペース「テスト用のスペース」を新しく作ります。

### 設定テンプレートの確認

4. ツールの template フォルダの base フォルダに、設定テンプレート（基本）「クラススペース」（クラススペース.xlsx）があることを確認します。

### 実行一覧ファイルの設定

5. ツールの run-list フォルダの multiple1.xlsx、multiple2.xlsx、multiple3.xlsx を開き、スペーステンプレートIDの「2」を、手順 2 で控えた ID に書き換えます。ただし、multiple2.xlsx の 2 行目（TestSpace4）は「3」のままにします。

### グループ設定ファイルの設定

6. ツールの clients フォルダの test01.bat を開き、KintoneSubdomain、KintoneLoginName、KintonePassword に、テスト用の kintone 環境の接続情報を書きます。

## 4. 利用資材との対応

| 利用資材 | 構築手順 |
|---|---|
| 共通設定ファイル「common.bat」 | 1 |
| グループ「test01」 | 6 |
| スペーステンプレート「テスト用のスペーステンプレート」 | 2、5 |
| スペース「テスト用のスペース」 | 3 |
| 設定テンプレート（基本）「クラススペース」 | 4 |
| 実行一覧ファイル（multiple1、multiple2、multiple3） | 1、5 |

## 5. 確認方法

- ツールを起動し、グループ「test01」を選べること。
- グループ設定ファイルの接続情報で、テスト用の kintone 環境に接続できること。

## 6. 注意事項

- テスト後は、手順 1 の init-test-env.bat を実行して、ツールを初期状態に戻します。
- テストで作成したスペースは、kintone から手で削除します。
