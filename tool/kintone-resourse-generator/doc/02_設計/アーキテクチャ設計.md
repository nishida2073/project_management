# kintone-resourse-generator アーキテクチャ設計

## 1. 概要

kintone-resourse-generator は、テンプレートをもとに kintone のスペースとアプリを作成し、設定を反映・確認するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（処理ごと、GUI） | 引数の解釈、対象のグループの指定 |
| 2 | ジョブ | バッチ（処理ごと） | 設定の読み込み、処理の起動、終了判定 |
| 3 | 処理本体 | PowerShell スクリプト（処理ごと） | kintone API の呼び出し、Excel の読み書き |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（処理ごとのバッチ）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
ルート/
├─ 入口のバッチ                        bats本体の呼び出し
├─ bats/                              各処理のバッチと処理本体、共通設定、GUI 本体
├─ clients/                           グループ別の設定
├─ template/                          設定テンプレート（基本、カスタム）
├─ download/                          ダウンロード結果
├─ config/                            設定ファイル
├─ checked/                           チェック結果
├─ run-list/                          複数実行の実行一覧
└─ logs/                              実行ログ
```

## 3. 処理概要

| 通番 | 処理 | 入力 | 出力 |
|---|---|---|---|
| 1 | スペース作成 | 共通設定、グループ別の設定 | kintone のスペース |
| 2 | スペースダウンロード | グループ別の設定 | ダウンロード結果 |
| 3 | 設定ファイル作成 | ダウンロード結果、設定テンプレート（基本）、設定テンプレート（カスタム） | 設定ファイル |
| 4 | スペース更新 | 設定ファイル、グループ別の設定 | kintone のスペース |
| 5 | スペース確認 | 設定ファイル、グループ別の設定 | チェック結果 |
| 6 | テンプレート作成 | グループ別の設定 | テンプレートファイル |

## 4. 入力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 共通設定 | `bats` 配下 | ダウンロード、設定テンプレート、設定ファイル、チェック結果、ログの場所を設定します。 |
| 2 | グループ別の設定 | `clients` 配下（グループごと） | kintone の接続情報を設定します。 |
| 3 | 設定テンプレート（基本） | `template\base` 配下の Excel ファイル | スペースとアプリの名前で紐づく、共通の設定を定義します。 |
| 4 | 設定テンプレート（カスタム） | `template\custom` 配下の Excel ファイル | 設定テンプレート（基本）と組み合わせて使う、追加の設定を定義します。 |
| 5 | 実行一覧 | 任意の Excel ファイル（`run-list` 配下） | 複数実行で処理する行を定義します。 |

## 5. 出力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | ダウンロード結果 | `download\<スペース識別名>_download.xlsx` | スペースの現在の状態を保存します。 |
| 2 | 設定ファイル | `config\<スペース識別名>_config.xlsx` | ダウンロード結果とテンプレートから作成した設定を保存します。 |
| 3 | チェック結果 | `checked\<スペース識別名>_check.xlsx` | 設定ファイルと kintone の現在の状態を比較した結果を保存します。 |
| 4 | テンプレートファイル | `template\custom\<グループ名>_<テンプレート名>.xlsx` | スペースの情報から作成したテンプレートを保存します。 |
| 5 | kintone のスペース | kintone（外部） | スペースとアプリの作成、設定の反映を行います。 |
| 6 | ログ | `logs\` | 実行ログを保存します。 |

## 6. 共通ライブラリ

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | kintone の REST 呼び出しと、スペースとアプリの取得・設定を行います。 |
| 2 | Excel 操作 | Excel の読み込みと書き込みを行います。 |
| 3 | ログ | 実行ログの出力を行います。 |
| 4 | GUI 部品 | GUI の共通部品を提供します。 |

## 7. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | スペースとアプリの作成、取得、設定 | ログイン名とパスワードによる認証、HTTPS |
| 2 | Excel（COM） | テンプレートと設定ファイルの読み書き | ローカルの Excel を操作 |

## 8. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、複数実行、一括実行と、処理ごとのタブ（スペース作成、スペースダウンロード、設定ファイル作成、スペース更新、スペース確認）です。
- 「環境設定」は、「共通」「グループ別」「テンプレート」のサブタブです。

## 9. エラー処理と運用上の注意

- 実行前に、対象の Excel ファイルを閉じてください。
- 設定ファイルには、グループ別の設定のパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 10. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
