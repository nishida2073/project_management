# kintone-resourse-generator アーキテクチャ設計

## 1. 概要

kintone-resourse-generator は、テンプレートをもとに kintone のスペースとアプリを作成し、設定を反映・確認するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（段階ごと、GUI） | 引数の解釈、対象のグループの指定 |
| 2 | ジョブ | バッチ（段階ごと） | 設定の読み込み、ワーカーの起動、終了判定 |
| 3 | ワーカー | PowerShell スクリプト（段階ごと） | kintone API の呼び出し、Excel の読み書き |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（段階ごとのバッチ）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
kintone-resourse-generator/
├─ create-space-from-template.bat     スペースの作成
├─ download-kintone-resources.bat     スペースのダウンロード
├─ generate-config-from-template.bat  設定ファイルの作成
├─ apply-kintone-resources.bat        スペースの更新
├─ check-kintone-resources.bat        スペースの確認
├─ create-template.bat                テンプレートの作成
├─ build-gui.bat                      GUI のビルド
├─ bats/                              各段階のバッチとワーカー、共通設定、GUI 本体
├─ clients/                           グループ別の設定
├─ template/                          テンプレート（基本、カスタム）
├─ download/                          ダウンロード結果
├─ config/                            設定ファイル
├─ checked/                           チェック結果
├─ run-list/                          複数実行の一覧ファイル
└─ logs/                              実行ログ
```

## 3. 全体処理フロー

一括実行は、次の順に各段階を呼び出します。

```
一括実行
 ├─ スペースの作成（新しいスペースを作る場合）
 ├─ スペースのダウンロード
 ├─ 設定ファイルの作成
 ├─ スペースの更新
 └─ スペースの確認
```

### 3.1 段階の扱い

- スペースの作成は、既存のスペースを使う場合は行いません。
- 各段階は、スペース識別名ごとに、設定ファイルやダウンロード結果を読み書きします。

## 4. 引数の規約

すべてのバッチは同じ形式の引数を受け取ります。

```
-名前:値
```

- 各バッチは引数を解析し、先頭の `-` を取り除いて「名前」と「値」に分けて設定します。
- GUI は同じ形式の引数を組み立てて、各段階のバッチを実行します。

## 5. 設定の層

| 通番 | 層 | ファイル | 内容の例 |
|---|---|---|---|
| 1 | 共通 | `bats\common.bat` | フォルダの場所（ダウンロード、設定ファイル、テンプレート、チェック結果、ログ） |
| 2 | グループ別 | `clients\<グループ名>.bat` | kintone の接続情報 |
| 3 | テンプレート | `template` 配下 | 設定テンプレート（基本、カスタム）の書式 |

## 6. ジョブとワーカー

| 通番 | ワーカー（段階） | 入力 | 出力 |
|---|---|---|---|
| 1 | スペースの作成 | スペーステンプレート | 新しいスペース |
| 2 | スペースのダウンロード | kintone のスペースの現在の状態 | ダウンロード結果の Excel |
| 3 | 設定ファイルの作成 | 設定テンプレートとダウンロード結果 | 設定ファイルの Excel |
| 4 | スペースの更新 | 設定ファイル | kintone への反映 |
| 5 | スペースの確認 | 設定ファイルと kintone の現在の状態 | チェック結果の Excel |
| 6 | テンプレートの作成 | kintone のスペース | テンプレートの Excel |

## 7. 共通ライブラリ（bats\library）

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | REST 呼び出し、スペースとアプリの取得と設定 |
| 2 | Excel 操作 | Excel の読み込み、書き込み |
| 3 | ログ | 実行ログの出力 |
| 4 | GUI 部品 | GUI の共通部品（4 プロジェクトで同一内容） |

## 8. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | スペースとアプリの作成、取得、設定 | ログイン名とパスワードによる認証、HTTPS |
| 2 | Excel（COM） | テンプレートと設定ファイルの読み書き | ローカルの Excel を操作 |

## 9. 入出力ファイル

| 通番 | 区分 | 場所 | 内容 |
|---|---|---|---|
| 1 | ダウンロード結果 | `download\<スペース識別名>_download.xlsx` | 段階 2 の出力、段階 3 の入力 |
| 2 | 設定ファイル | `config\<スペース識別名>_config.xlsx` | 段階 3 の出力、段階 4・5 の入力 |
| 3 | チェック結果 | `checked\<スペース識別名>_check.xlsx` | 段階 5 の出力 |
| 4 | テンプレート | `template\base` と `template\custom` | 設定テンプレート |
| 5 | ログ | `logs\` | 実行ログ |

## 10. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、複数実行、一括実行と、段階ごとのタブ（スペース作成、スペースダウンロード、設定ファイル作成、スペース更新、スペース確認）です。
- 「環境設定」は、「共通」「グループ別」「テンプレート」のサブタブです。

## 11. エラー処理と運用上の注意

- 実行前に、対象の Excel ファイルを閉じてください。
- 設定ファイルには、グループ別の設定ファイルのパスワードは平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 12. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
