# kintone-aggregator 機能一覧

## 1. 実行

- アプリデータの作成
  - アプリからデータを取得し、集計用データを作成する
    - 業務日誌
    - パルスサーベイ
- アプリデータの集計
  - 集計用データを統合する
    - 業務日誌・パルスサーベイ
- アラートの集計
  - 統合データからアラートや提出状況を検知する
    - 業務日誌・パルスサーベイ
- 集計結果の投稿
  - アラート集計の結果をスレッドに投稿する
- 一括実行
  - 上記機能を一括で実行する

## 2. ログ

- ログの確認
  - 実行ログを表示する

## 3. 環境設定

- 共通設定
  - 共通の環境ファイルを編集する
    - アプリデータ、集計データ、テンプレート、ログなどのフォルダ
    - アプリのフィールドコード
- グループ別設定
  - グループ別の環境ファイルを編集する
    - 接続先
    - 投稿先
    - 対象のアプリID
- マスターデータの設定
  - ユーザーマスターを受講生一覧に同期し、スケジュールを編集する
    - ユーザー
      - 受講生ID、氏名など
    - スケジュール
      - 科目名、開始日、終了日など
