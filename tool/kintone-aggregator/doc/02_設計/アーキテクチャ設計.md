# kintone-aggregator アーキテクチャ設計

## 1. 概要

kintone-aggregator は、kintone に登録された業務日誌とパルスサーベイのレコードを日付単位で取得し、グループ（クラス）ごとに集計してアラートを検知し、その結果を kintone のスレッドに投稿するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（起動用、全処理用、GUI） | 引数の解釈、日付の既定値、グループの列挙 |
| 2 | ジョブ | バッチ（処理ごと） | グループごとの設定読み込み、ワーカーの起動、終了判定 |
| 3 | ワーカー | PowerShell スクリプト（処理ごと） | kintone API の呼び出し、Excel / JSON の入出力、集計ロジック |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（手動実行、全処理実行）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
kintone-aggregator/
├─ all.bat                    全処理の一括実行
├─ starter-manual.bat         引数を対話入力して全処理を実行
├─ starter-auto.bat           スタートアップから全処理を実行（自動実行用）
├─ setting-starter-auto.bat   自動実行のスタートアップ登録
├─ unsetting-starter-auto.bat スタートアップ登録の解除
├─ build-gui.bat              GUI のビルド
├─ bats/
│  ├─ 共通設定                 パス、列名、出力先
│  ├─ メッセージ出力
│  ├─ Excel の後始末           起動したままの Excel プロセスを終了
│  ├─ 各ジョブのバッチ         処理ごとの起動・日付とグループの処理
│  ├─ 各ジョブのワーカー       処理ごとの集計・入出力
│  ├─ 列名マッピング           集計データと同期の列名
│  ├─ GUI 本体
│  └─ 共通ライブラリ（後述）
├─ clients/
│  ├─ template/               グループ設定の雛形
│  ├─ <グループ名>.bat        グループ別の設定（接続先、対象アプリ、投稿先など）
│  └─ <グループ名>.xlsx       グループ別のデータ（ファイル名がグループ名になる）
├─ template/                  アラート結果の出力テンプレート
├─ output/                    処理結果（後述）
└─ logs/                      実行ログ
```

## 3. 全体処理フロー

全処理の実行は、次の順に各ジョブを呼び出します。

```
全処理
 ├─ Excel の後始末、共通設定の読み込み
 ├─ アプリデータ作成
 │   ├─ 業務日誌の集計用データ作成
 │   └─ パルスサーベイの集計用データ作成
 ├─ アプリデータ集計（日付・グループごと）
 └─ アラート集計と投稿
     ├─ アラート検知と Excel / JSON 出力
     └─ 結果の投稿
```

### 3.1 日付の扱い

- 対象日を指定しない場合は前日（「now」指定で当日）を使います。
- 対象日から過去 N 日分をまとめて処理できます。日付ループを持つのは「アプリデータ作成」と「アプリデータ集計」で、「アラート集計」と「投稿」は対象日 1 日を処理します。

### 3.2 グループの扱い

- `clients` 配下の `<グループ名>.xlsx` を列挙し、グループごとに処理します。対象グループは絞り込めます（既定は全グループ）。
- グループごとの設定は `clients\<グループ名>.bat` に定義され、ジョブ側で読み込みます。

## 4. 引数の規約

すべてのバッチは同じ形式の引数を受け取ります。

```
-名前:値
```

- 各バッチは引数を解析し、先頭の `-` を取り除いて「名前」と「値」に分けて設定します。
- 親バッチは子バッチへ同じ形式で引数を渡します。
- GUI は同じ形式の引数を組み立てて、各ジョブのバッチを実行します。

## 5. 設定の層

| 通番 | 層 | ファイル | 内容の例 |
|---|---|---|---|
| 1 | 共通 | 共通設定（bats 配下） | 基準パス、入出力フォルダ、ソースタイプ名、フィールドコード |
| 2 | グループ別 | `clients\<グループ名>.bat` | kintone のサブドメイン、ログイン名、パスワード、対象アプリ ID、投稿先スペース・スレッド、メンション対象、投稿文言 |
| 3 | 処理別 | 列名マッピング（json） | 集計データと同期の列名 |
| 4 | テンプレート | `template` 配下 | アラート結果 Excel の書式 |

共通設定は基準パスを自身の場所から求めます。グループ別の設定は共通設定を前提に動くため、基準パスを再定義しないことが前提です。

## 6. ジョブとワーカー

### 6.1 ジョブ（バッチ）の責務

各ジョブのバッチは次を行います。

1. 共通設定とメッセージ出力を読み込みます。
2. 引数を解析し、対象日とグループ名を決めます。
3. `clients` 配下のグループを列挙し、対応するグループ別の設定を読み込みます。
4. 業務日誌・パルスサーベイの区分に応じて、対象アプリ ID とフィールドコードを設定します。
5. ワーカーをバックグラウンドで起動します。

### 6.2 ワーカーの起動と終了判定

- ワーカーは一時フォルダに次の 2 種類のフラグファイルを作ります。
  - 実行中の印: ワーカーの開始時に作成し、終了時に削除します。
  - 失敗の印: 例外が発生したときに作成します。
- 実行前に古い失敗の印は削除します。
- ワーカーには kintone の接続情報と、対象日、対象アプリ、フィールドコードなどのパラメータを渡します。

### 6.3 ワーカーの責務

| 通番 | ワーカー（処理） | 入力 | 出力 |
|---|---|---|---|
| 1 | アプリデータ作成 | kintone のレコード（日付条件で取得） | 集計用データ |
| 2 | アプリデータ集計 | 集計用データ（業務日誌、パルスサーベイ） | 統合データ |
| 3 | アラート集計 | 統合データ、テンプレート | アラート結果 Excel、JSON、バックアップ |
| 4 | 投稿 | アラート結果の JSON、Excel | kintone スレッドへのコメント（添付ファイル付き） |
| 5 | ユーザーマスター同期 | kintone のユーザーマスターアプリ | 受講生一覧シート（Excel） |

アラート集計は、アラート判定（2021 年版と 2022 年版の 2 系統）、日次・サマリの作成、Excel 出力を行います。判定ルールの詳細はアラート集計のワーカーを参照してください。

## 7. 共通ライブラリ（bats\library）

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | REST 呼び出し、レコード取得、スレッドへのコメント投稿、スペース・アプリ・ACL の設定 |
| 2 | Excel 操作 | Excel COM の読み込み、書き込み、色付け、列幅、フィルタ、シート操作 |
| 3 | ファイル入出力 | 配列のファイルへの書き出しと読み込み |
| 4 | 集計用データ | コース、ユーザー、コーススケジュールの作成 |
| 5 | ログ | ワーカー用のログ出力とログファイルのパス作成 |
| 6 | 共通処理 | 排他制御、型変換、改行の変換 |
| 7 | GUI 部品 | GUI の共通部品 |

## 8. 排他制御

Excel の同時操作を防ぐため、名前付きの排他ロックを使います。対象は次の 3 か所です。

| 通番 | 対象 | 用途 |
|---|---|---|
| 1 | 日次データの復旧処理 | 「アラート集計」で日次データを復旧するとき |
| 2 | Excel のコピー・貼り付け | Excel のセル操作 |
| 3 | 受講生一覧シートへの書き込み | ユーザーマスター同期 |

## 9. 入出力ファイル

| 通番 | 区分 | 場所 | 内容 |
|---|---|---|---|
| 1 | 提出状況 | `output\01_提出状況\<対象日>\` | 業務日誌、パルスサーベイの集計用データ |
| 2 | 集計データ | `output\02_アプリデータ集計\` | 統合データ |
| 3 | アラート結果 | `output\03_アラート検知結果\` | `<グループ名>.xlsx`、`<グループ名>.json` |
| 4 | バックアップ | `output\03_アラート検知結果\backup\` | `<グループ名>-<対象日>.xlsx` / `.json`（投稿に添付する元データ） |
| 5 | ログ | `logs\` | `<処理名>-<グループ名>-<日付>_<タイムスタンプ>.log` |

## 10. GUI の構成

GUI は次の要素で構成されています。

- 起動時に共通ライブラリを読み込みます。
- タブは「実行」「ログ」「環境設定」の 3 つです。
  - 「実行」: 個別実行と一括実行。個別実行はカテゴリごとのボタン、一括実行はチェックボックスで対象を選択します。
  - 「ログ」: グループ・処理ごとの実行ログを表示します。
  - 「環境設定」: 「共通」「グループ別」「マスター」のサブタブで、設定値と `.xlsx` のデータを編集します。
- 実行はジョブのバッチを呼び出します。標準出力はログ欄へ転送します。

## 11. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | レコードの取得、スレッドへのコメント投稿、ユーザーマスターの読み込み | ログイン名とパスワードによる認証、HTTPS |
| 2 | Excel（COM） | アラート結果、受講生一覧、スケジュールの読み書き | ローカルの Excel を操作 |

## 12. エラー処理と運用上の注意

- ワーカーが失敗すると失敗の印を作成します。親バッチのログ（メッセージ出力）で失敗を確認します。
- 実行前に対象の Excel ファイルを閉じてください。後始末の処理は表示ウィンドウのない Excel を終了しますが、開いたままのファイルは扱えません。
- 処理中はクリップボードを使うため、コピー操作を行わないでください（手動実行の入力画面に注意書きがあります）。
- 出力フォルダの既存ファイルは上書きされます。
- グループ別の設定ファイルにはパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 13. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- ワーカーは日付・グループ単位で独立して実行されますが、同一グループの同一ジョブを並行して実行しないことを前提としています。
- 設定の既定値（列名、フィールドコード、フォルダ名）は共通設定に直接書かれています。変更時は共通設定と GUI の表示名を合わせて確認してください。
