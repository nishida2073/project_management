# アーキテクチャ設計

## 1. 概要

本ツールは、kintone に登録された業務日誌とパルスサーベイのレコードを日付単位で取得し、グループ（クラス）ごとに集計してアラートを検知し、その結果を kintone のスレッドに投稿するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（起動用、全処理用、GUI） | 引数の解釈、日付の既定値、グループの列挙 |
| 2 | ジョブ | バッチ（処理ごと） | グループごとの設定読み込み、処理の起動、終了判定 |
| 3 | 処理本体 | PowerShell スクリプト（処理ごと） | kintone API の呼び出し、Excel / JSON の入出力、集計ロジック |

## 2. ディレクトリ構成

```
ルート/
├─ 入口のバッチ                bats本体の呼び出し
├─ bats/                      各処理のバッチと処理本体、共通設定、GUI 本体、library/
├─ clients/                   グループ別の設定と雛形
├─ template/                  アラート結果の出力テンプレート
├─ output/                    処理結果
└─ logs/                      実行ログ
```

## 3. 処理概要

| 通番 | 処理 | 入力 | 出力 |
|---|---|---|---|
| 1 | アプリデータ作成 | 業務日誌（kintone）、パルスサーベイ（kintone）、共通設定、グループ別の設定 | 集計用データ |
| 2 | アプリデータ集計 | 集計用データ、集計データの列定義 | 統合データ |
| 3 | アラート集計 | 統合データ、受講生一覧、スケジュール | アラート結果、バックアップ |
| 4 | 投稿 | アラート結果、バックアップ | 投稿 |
| 5 | ユーザーマスター同期 | ユーザーマスター（kintone）、グループ別の設定 | 受講生一覧 |

## 4. 入力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 共通設定 | `bats\common.bat` | 基準パス、入出力フォルダ、ソースタイプ名、フィールドコードを設定します。 |
| 2 | グループ別の設定 | `clients\<グループ名>.bat` | kintone の接続先、投稿先、対象アプリを設定します。 |
| 3 | 受講生一覧 | `clients\<グループ名>.xlsx`（受講生一覧シート） | 受講生の所属、除外期間、停止状態を管理します。 |
| 4 | スケジュール | `clients\<グループ名>.xlsx`（スケジュールシート） | 科目の日程を管理します。 |
| 5 | 集計データの列定義 | `bats\collect-data-defs.json` | kintone の項目名と集計用データの項目名の対応を定義します。 |
| 6 | 業務日誌（kintone） | kintone の業務日誌のアプリ | 日付ごとの業務日誌のレコードを取得します。 |
| 7 | パルスサーベイ（kintone） | kintone のパルスサーベイのアプリ | 日付ごとのパルスサーベイのレコードを取得します。 |
| 8 | ユーザーマスター（kintone） | kintone のユーザーマスターのアプリ | ユーザーの情報を取得します。 |

## 5. 出力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 集計用データ | `output\01_提出状況\<対象日>\` | 日付ごとの提出状況の集計用データを保存します。 |
| 2 | 統合データ | `output\02_アプリデータ集計\` | 業務日誌とパルスサーベイを統合したデータを保存します。 |
| 3 | アラート結果 | `output\03_アラート検知結果\` | アラートと提出状況の結果（Excel と JSON）を保存します。 |
| 4 | バックアップ | `output\03_アラート検知結果\backup\` | 投稿に添付する元データを保存します。 |
| 5 | ログ | `logs\` | 実行ログを保存します。 |
| 6 | 受講生一覧 | `clients\<グループ名>.xlsx`（受講生一覧シート） | ユーザーマスターの内容を書き込みます。 |
| 7 | 投稿 | kintone のスレッド | 集計結果をコメントとして投稿します。 |

## 6. 共通ライブラリ

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | kintone の REST 呼び出し、レコードの取得、スレッドへのコメント投稿、スペース・アプリ・ACL の設定を行います。 |
| 2 | Excel 操作 | Excel の読み込み、書き込み、色付け、列幅、フィルタ、シートの操作を行います。 |
| 3 | ファイル入出力 | 配列のファイルへの書き出しと読み込みを行います。 |
| 4 | 集計用データ | 科目、ユーザー、科目のスケジュールを作成します。 |
| 5 | ログ | 処理本体用のログ出力と、ログファイルのパスの作成を行います。 |
| 6 | 共通処理 | 排他制御、型変換、改行の変換を行います。 |
| 7 | GUI 部品 | GUI の共通部品を作成します。 |

## 7. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | レコードの取得、スレッドへのコメント投稿、ユーザーマスターの読み込み | ログイン名とパスワードによる認証、HTTPS |
| 2 | Excel（COM） | アラート結果、受講生一覧、スケジュールの読み書き | ローカルの Excel を操作 |

## 8. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、個別実行と一括実行です。個別実行はカテゴリごとのボタン、一括実行はチェックボックスで対象を選択します。
- 「ログ」は、グループと処理ごとの実行ログを表示します。
- 「環境設定」は、「共通」「グループ別」「マスター」のサブタブで、設定値と `.xlsx` のデータを編集します。

## 9. エラー処理と運用上の注意

- 処理が失敗すると、画面の状態に「失敗」と表示され、実行ログに記録されます。
- 実行前に対象の Excel ファイルを閉じてください。後始末の処理は表示ウィンドウのない Excel を終了しますが、開いたままのファイルは扱えません。
- 処理中はクリップボードを使うため、コピー操作を行わないでください。
- グループ別の設定ファイルにはパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 10. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- 処理本体は日付・グループ単位で独立して実行されますが、同一グループの同一処理を並行して実行しないことを前提としています。
- 設定の既定値（列名、フィールドコード、フォルダ名）は共通設定に直接書かれています。変更時は共通設定と GUI の表示名を合わせて確認してください。
