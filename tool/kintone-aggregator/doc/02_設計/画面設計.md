# kintone-aggregator 画面設計

## 1. 概要

kintone-aggregator の操作画面は、1 つのウィンドウに「実行」「ログ」「環境設定」のタブを置いた構成です。本書では、各タブの画面と、その中の項目や操作を示します。

### 1.1 画面の一覧

| 画面 | 内容 |
|---|---|
| 実行（一括実行） | 対象日と対象のグループを指定し、選んだ処理をまとめて実行します。 |
| 実行（アプリデータ作成） | 対象日と対象のグループを指定して、業務日誌とパルスサーベイのデータを作成します。 |
| 実行（アプリデータ集計） | 対象日と対象のグループを指定して、集計用データを統合します。 |
| 実行（アラート集計） | 対象日と対象のグループを指定して、アラートの検知と結果の投稿を行います。 |
| ログ | グループと処理を選び、実行ログを表示します。 |
| 環境設定（共通） | 基本設定のフォルダ、項目コード、アプリデータ集計の列定義を編集します。 |
| 環境設定（グループ別） | グループごとの接続情報、投稿先、対象アプリを編集します。 |
| 環境設定（マスター） | ユーザーの同期とスケジュールを編集します。 |

### 1.2 画面遷移図

```
メイン画面
 ├─ 実行
 │   ├─ 一括実行
 │   ├─ アプリデータ作成
 │   ├─ アプリデータ集計
 │   └─ アラート集計
 ├─ ログ
 └─ 環境設定
     ├─ 共通
     ├─ グループ別
     └─ マスター
```

- 画面の切り替えは、タブを選ぶことで行います。
- 実行中は、実行の操作（実行ボタン）が使えなくなります。

## 2. 各画面

### 2.1 実行（一括実行）

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象日 | テキスト | 処理の対象日を指定します（yyyy-MM-dd）。既定値は今日の日付を入れます。 |
| 対象のグループ | コンボボックス | 対象のグループを選びます。 |
| （処理名） | チェックボックス | 処理ごとに 1 つ置きます。チェックを外した処理はスキップします。 |
| 実行 | ボタン | 選んだ処理を順に実行します。 |
| 状態 | ラベル | 処理の状態を表示します。 |

### 2.2 実行（アプリデータ作成）

#### 業務日誌

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象日 | テキスト | 処理の対象日を指定します（yyyy-MM-dd）。既定値は今日の日付を入れます。 |
| 対象のグループ | コンボボックス | 対象のグループを選びます。 |
| 実行 | ボタン | 業務日誌の集計用データを作成します。 |
| 状態 | ラベル | 処理の状態を表示します。初期表示は「未実行」と表示します。 |
| 開く | リンク | 作成したデータのフォルダを開きます。 |

#### パルスサーベイ

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象日 | テキスト | 処理の対象日を指定します（yyyy-MM-dd）。既定値は今日の日付を入れます。 |
| 対象のグループ | コンボボックス | 対象のグループを選びます。 |
| 実行 | ボタン | パルスサーベイの集計用データを作成します。 |
| 状態 | ラベル | 処理の状態を表示します。初期表示は「未実行」と表示します。 |
| 開く | リンク | 作成したデータのフォルダを開きます。 |

| 項目 | 種類 | 内容 |
|---|---|---|

### 2.5 ログ

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象のグループ | コンボボックス | 表示するログのグループを選びます。 |
| （処理名） | ラジオボタン | 表示するログの処理を選びます。 |
| すべて削除 | ボタン | ログを削除します（削除の対象は未確認）。 |
| ログ | テキストエリア | 選んだグループと処理の実行ログを表示します。 |

### 2.6 環境設定（共通）

| 項目 | 種類 | 内容 |
|---|---|---|
| 保存 | ボタン | 入力した内容を保存します。 |
| 再読込 | ボタン | 保存されている内容を読み込み直します。 |
| 基本設定 | テキスト | グループデータのフォルダ、テンプレートのフォルダ、ログの出力先、出力のルートフォルダ、各出力先を設定します。各項目に参照ボタンを置きます。 |
| 業務日誌（共通） | テキスト | 日付フィールドコード、受講生IDフィールドコードを設定します。 |
| パルスサーベイ（共通） | テキスト | 日付フィールドコード、受講生IDフィールドコードを設定します。 |
| アプリデータ集計の列定義 | 表 | 「タイプ」「変更前」「変更後」の列で、集計用データの列名の変換を設定します。 |
| 削除 | ボタン | 表の行を削除します。 |
| 追加 | ボタン | 表に行を追加します。 |

### 2.7 環境設定（グループ別）

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象のグループ | コンボボックス | 対象のグループを選びます。 |
| 新規作成 | ボタン | 新しいグループを作成します。 |
| 保存 | ボタン | 入力した内容を保存します。 |
| 再読込 | ボタン | 保存されている内容を読み込み直します。 |
| 認証情報 | テキスト | サブドメイン、ログイン名、パスワードを入力します。 |
| テスト接続（認証情報） | ボタン | 認証情報で kintone に接続できるかを確認します。 |
| 投稿先 | テキスト | 投稿先スペースID、投稿先スレッドID、メンション対象を入力します。 |
| 投稿コメント文言 | テキストエリア | 投稿の本文の文言を入力します。 |
| 投稿集計文言 | テキストエリア | 投稿の要約の文言を入力します。 |
| テスト投稿 | ボタン | テスト用のコメントを投稿して、投稿先を確認します。 |
| 対象アプリID（ユーザー） | テキスト | ユーザーマスターのアプリIDを入力します。 |
| テスト接続（ユーザー） | ボタン | ユーザーマスターのアプリIDに接続できるかを確認します。 |
| 対象シート名 | テキスト | 受講生一覧を書き込むシートの名前を入力します。 |
| 対象アプリID（業務日誌） | テキスト | 業務日誌のアプリIDを入力します。 |
| テスト接続（業務日誌） | ボタン | 業務日誌のアプリIDに接続できるかを確認します。 |
| 対象アプリID（パルスサーベイ） | テキスト | パルスサーベイのアプリIDを入力します。 |
| テスト接続（パルスサーベイ） | ボタン | パルスサーベイのアプリIDに接続できるかを確認します。 |

### 2.8 環境設定（マスター）

| 項目 | 種類 | 内容 |
|---|---|---|
| 対象のグループ | コンボボックス | 対象のグループを選びます。 |
| 開く | リンク | 対象のグループの Excel を開きます。 |
| 保存 | ボタン | 入力した内容を保存します。 |
| 再読込 | ボタン | 保存されている内容を読み込み直します。 |
| ユーザー | ボタン | 「同期実行」ボタンで、ユーザーマスターを受講生一覧に同期します。 |
| スケジュール | 表 | 通番、科目名、開始日、終了日の列で、科目の日程を編集します。 |
| 削除 | ボタン | 表の行を削除します。 |
| 追加 | ボタン | 表に行を追加します。 |
