# kintone-aggregator データ設計

## 1. 概要

本書は、kintone-aggregator の設定データのうち、次の 4 つのファイルで扱う項目を定義します。

### 1.1 データの一覧

| データ | 保存先（ファイル） | 概要 |
|---|---|---|
| 共通設定 | `bats\common.bat` | 全グループ共通の基準フォルダ、出力先、kintone の項目コードを設定する |
| グループ別の設定 | `clients\<グループ名>.bat`（雛形: `clients\template\client.bat`） | グループごとの kintone の接続先、投稿先、対象アプリを設定する |
| 受講生一覧 | `clients\<グループ名>.xlsx` の「受講生一覧」シート（雛形: `clients\template\client.xlsx`） | 受講生ごとの所属、除外期間、停止状態を設定する |
| スケジュール | `clients\<グループ名>.xlsx` の「スケジュール」シート（雛形: `clients\template\client.xlsx`） | 科目ごとの日程を設定する |
| 集計データの列定義 | `bats\collect-data-defs.json` | kintone の項目名と集計用データの項目名の対応を設定する |

## 2. 各データ

### 2.1 共通設定

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| 基準フォルダ | BASE_PATH | 処理の基準になるフォルダです（共通設定の場所から求める）。 | 共通設定ファイルの 1 つ上のフォルダ |
| グループデータのフォルダ | ClientDataRootDir | グループ別のデータが置かれます。 | 基準フォルダ直下の clients |
| テンプレートのフォルダ | TemplateRootDir | 出力テンプレートが置かれます。 | 基準フォルダ直下の template |
| ログの出力先 | CommonLogPath | 実行ログが出力されます。 | 基準フォルダ直下の logs |
| 出力のルートフォルダ | OutputRootDir | 処理結果が出力されます。 | 基準フォルダ直下の output |
| 提出状況の出力先 | OutputReportDir | 提出状況の集計用データが出力されます。 | output 配下の 01_提出状況 |
| アプリデータ集計の出力先 | OutputCollectDataRootDir | 統合データが出力されます。 | output 配下の 02_アプリデータ集計 |
| アラート検知結果の出力先 | OutputAlertRootDir | アラート結果が出力されます。 | output 配下の 03_アラート検知結果 |
| バックアップの出力先 | OutputAlertBackupDir | アラート結果のバックアップが出力されます。 | アラート結果の出力先直下の backup |
| ソースタイプ名（業務日誌） | SourceType_Daily | 業務日誌の区分の名称です。 | 業務日誌 |
| ソースタイプ名（パルスサーベイ） | SourceType_Pulse | パルスサーベイの区分の名称です。 | パルスサーベイ |
| 日付フィールドコード（業務日誌） | TargetDateCodeField_Daily | 業務日誌の日付項目のフィールドコードです。 | 日付 |
| 日付フィールドコード（パルスサーベイ） | TargetDateCodeField_Pulse | パルスサーベイの日付項目のフィールドコードです。 | 日付_0 |
| 受講生IDフィールドコード（業務日誌） | TargetUserCodeField_Daily | 業務日誌の個人の項目のフィールドコードです。 | 個人ID |
| 受講生IDフィールドコード（パルスサーベイ） | TargetUserCodeField_Pulse | パルスサーベイの個人の項目のフィールドコードです。 | 個人ID |

### 2.2 グループ別の設定

| 項目 | 変数 | 内容 | 既定値 |
|---|---|---|---|
| ログイン名 | KintoneLoginName | kintone の接続に使うログイン名です。 | 空欄 |
| パスワード | KintonePassword | kintone の接続に使うパスワードです（平文で保存）。 | 空欄 |
| サブドメイン | KintoneSubdomain | kintone の組織のサブドメインです。 | `univ-kyousai-{x}`（グループごとに書き換える） |
| 基底URL | KintoneBaseUrl | サブドメインから求める接続先の URL です。 | サブドメインから自動で求める |
| 投稿先スペースID | SpaceId | 投稿先のスペースのIDです。 | 空欄 |
| 投稿先スレッドID | ThreadId | 投稿先のスレッドのIDです。 | 空欄 |
| メンション対象 | MentionUserCodes | 投稿時にメンションするユーザーのコードです。 | 空欄 |
| 投稿コメント文言 | CommentTextTemplate | 本文の文言です（{グループ名}、{対象日} を置換）。 | 「集計結果を更新しました。（{グループ名} / {対象日}）」 |
| 投稿集計文言 | CommentSummaryTemplate | 要約の文言です（{クラス名}、{業務日誌未提出人数} などを置換）。 | ■ クラス名 : {クラス名}\n・業務日誌（未提出）: {業務日誌未提出人数}\n・パルスサーベイ（未提出）: {パルスサーベイ未提出人数}\n・アラート: {アラート人数} |
| 業務日誌の対象アプリID | TargetAppIds_Daily | 業務日誌のアプリのIDです。 | 空欄 |
| パルスサーベイの対象アプリID | TargetAppIds_Pulse | パルスサーベイのアプリのIDです。 | 空欄 |
| ユーザーマスターの対象アプリID | SyncUserMasterAppId | ユーザーマスターのアプリのIDです。 | 空欄 |
| 対象シート名 | SyncUserMasterSheetName | 受講生一覧を書き込むシートの名前です。 | 受講生一覧 |

### 2.3 受講生一覧（グループ別のデータ）

| 項目 | 内容 |
|---|---|
| 通番 | 並び番号です。 |
| 会社名 | 受講生の所属です。 |
| 受講生ID | 受講生を識別する ID です。 |
| 氏名 | 受講生の氏名です。 |
| 停止中 | 受講を停止しているかどうか（真偽値）です。 |
| クラス名 | 受講生が所属するクラスです。 |
| 除外日-開始 | 除外期間の開始日です（空欄は期間の始まりなし）。 |
| 除外日-終了 | 除外期間の終了日です（空欄は期間の終わりなし）。 |

### 2.4 スケジュール（グループ別のデータ）

| 項目 | 内容 |
|---|---|
| 通番 | 並び番号です。 |
| 科目名 | 科目の名称です。 |
| 開始日 | 科目の開始日です。 |
| 終了日 | 科目の終了日です。 |

### 2.5 集計データの列定義（全グループ共通）

| 項目 | 内容 |
|---|---|
| タイプ | 元の項目の由来です（業務日誌（Daily）、パルスサーベイ（Pulse））。 |
| 変更前 | kintone の元の名前です。 |
| 変更後 | 出力で使う名前です。空欄の場合は変更しません。 |

## 3. 注意事項

- 停止中が真の受講生は受講生の一覧から除外され、除外日の期間に入る日は除外対象になります。
