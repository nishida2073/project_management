# kintone-aggregator 処理フロー

## 1. 概要

画面のボタンごとに、押したときに行われる処理の流れを示します。各ボタンの手順は、入力の確認から結果の表示までを順に書きます。

### 1.1 処理の一覧

| 通番 | 画面名 | ボタン名 | 内容 |
|---|---|---|---|
| 1 | 実行（一括実行） | 実行 | 選んだ処理を順に実行します。 |
| 2 | 実行（アプリデータ作成） | 実行（業務日誌） | 業務日誌の集計用データを作成します。 |
| 3 | 実行（アプリデータ作成） | 実行（パルスサーベイ） | パルスサーベイの集計用データを作成します。 |
| 4 | 実行（アプリデータ集計） | 実行（業務日誌・パルスサーベイ） | 集計用データを統合します。 |
| 5 | 実行（アラート集計） | 実行（業務日誌・パルスサーベイ） | 統合データからアラートと提出状況を検知します。 |
| 6 | 実行（アラート集計） | 実行（投稿） | アラート集計の結果をスレッドに投稿します。 |
| 7 | ログ | すべて削除 | ログを削除します（削除の対象は未確認）。 |
| 8 | 環境設定（共通） | 保存 | 入力した内容を保存します。 |
| 9 | 環境設定（共通） | 再読込 | 保存されている内容を読み込み直します。 |
| 10 | 環境設定（共通） | 削除（アプリデータ集計の列定義） | 選んだ行を削除します。 |
| 11 | 環境設定（共通） | 追加（アプリデータ集計の列定義） | 表に行を追加します。 |
| 12 | 環境設定（グループ別） | 新規作成 | 新しいグループを作成します。 |
| 13 | 環境設定（グループ別） | 保存 | 入力した内容を保存します。 |
| 14 | 環境設定（グループ別） | 再読込 | 保存されている内容を読み込み直します。 |
| 15 | 環境設定（グループ別） | テスト接続（認証情報） | 認証情報で kintone に接続できるかを確認します。 |
| 16 | 環境設定（グループ別） | テスト接続（ユーザー） | ユーザーマスターのアプリIDに接続できるかを確認します。 |
| 17 | 環境設定（グループ別） | テスト接続（業務日誌） | 業務日誌のアプリIDに接続できるかを確認します。 |
| 18 | 環境設定（グループ別） | テスト接続（パルスサーベイ） | パルスサーベイのアプリIDに接続できるかを確認します。 |
| 19 | 環境設定（グループ別） | テスト投稿 | テスト用のコメントを投稿して、投稿先を確認します。 |
| 20 | 環境設定（マスター） | 保存 | 入力した内容を保存します。 |
| 21 | 環境設定（マスター） | 再読込 | 保存されている内容を読み込み直します。 |
| 22 | 環境設定（マスター） | 同期実行（ユーザー） | ユーザーマスターを受講生一覧に同期します。 |
| 23 | 環境設定（マスター） | 削除（スケジュール） | 選んだ行を削除します。 |
| 24 | 環境設定（マスター） | 追加（スケジュール） | 表に行を追加します。 |

## 2. 各ボタンの処理フロー

### 2.1 実行（一括実行）／実行
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. 選んだ処理を、アプリデータ作成、アプリデータ集計、アラート集計、投稿の順に実行します。
4. 処理ごとに、状態を「成功」「警告」「失敗」「スキップ」のいずれかで表示します。
5. 状態を表示し、実行ログを画面下部に出力します。

### 2.2 実行（アプリデータ作成）／実行（業務日誌）
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. 対象のグループごとに、業務日誌のレコードを取得します。
4. レコードを集計用データに変換し、出力先に保存します。
5. 状態を表示し、実行ログを画面下部に出力します。

### 2.3 実行（アプリデータ作成）／実行（パルスサーベイ）
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. 対象のグループごとに、パルスサーベイのレコードを取得します。
4. レコードを集計用データに変換し、出力先に保存します。
5. 状態を表示し、実行ログを画面下部に出力します。

### 2.4 実行（アプリデータ集計）／実行（業務日誌・パルスサーベイ）
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. 業務日誌とパルスサーベイの集計用データを読み込みます。
4. 列名の変換を適用して、統合データを作成します。
5. 統合データを出力先に保存します。
6. 状態を表示し、実行ログを画面下部に出力します。

### 2.5 実行（アラート集計）／実行（業務日誌・パルスサーベイ）
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. 統合データを読み込みます。
4. 過去の日次データを復旧します。
5. 受講生ごとにアラートと提出状況を判定します。
6. クラスごとに集計し、Excel と JSON を出力します。
7. Excel と JSON のバックアップを作成します。
8. 状態を表示し、実行ログを画面下部に出力します。

### 2.6 実行（アラート集計）／実行（投稿）
1. 対象日と対象のグループを確認します。
2. 必須の入力がない場合は、メッセージを表示して中止します。
3. アラート結果の JSON と Excel を読み込みます。
4. バックアップの Excel を添付ファイルとして用意します。
5. 投稿コメント文言と投稿集計文言を組み立てます。
6. 投稿先のスレッドにコメントを投稿します。
7. 状態を表示し、実行ログを画面下部に出力します。

### 2.7 ログ／すべて削除
1. 削除の対象を確認します（未確認）。
2. ログを削除します（未確認）。

### 2.8 環境設定（共通）／保存
1. 入力された内容を確認します。
2. 入力された内容を、共通の設定ファイルに書き込みます。
3. 画面の表示を、保存後の内容に更新します。
4. 結果を、ボタンの横に表示します。

### 2.9 環境設定（共通）／再読込
1. 共通の設定ファイルの内容を読み込みます。
2. 読み込んだ内容で、画面の入力欄を表示し直します。
3. 結果を、ボタンの横に表示します。

### 2.10 環境設定（共通）／削除（アプリデータ集計の列定義）
1. 削除の対象の行を確認します。
2. 選んだ行を削除します。

### 2.11 環境設定（共通）／追加（アプリデータ集計の列定義）
1. 表の末尾に、空の行を追加します。
2. 画面の表示を、追加後の内容に更新します。

### 2.12 環境設定（グループ別）／新規作成
1. グループ名を入力する画面を表示します。
2. 入力された名前が、既存のグループと重複していないかを確認します。
3. 重複していなければ、新しいグループを作成し、グループの一覧に追加します。

### 2.13 環境設定（グループ別）／保存
1. 入力された内容を確認します。
2. 入力された内容を、対象のグループの設定ファイルに書き込みます。
3. 画面の表示を、保存後の内容に更新します。
4. 結果を、ボタンの横に表示します。

### 2.14 環境設定（グループ別）／再読込
1. 対象のグループの設定ファイルの内容を読み込みます。
2. 読み込んだ内容で、画面の入力欄を表示し直します。
3. 結果を、ボタンの横に表示します。

### 2.15 環境設定（グループ別）／テスト接続（認証情報）
1. サブドメイン、ログイン名、パスワードを確認します。
2. kintone に接続し、接続できるかを確認します。
3. 結果を、ボタンの横に表示します。

### 2.16 環境設定（グループ別）／テスト接続（ユーザー）
1. ユーザーマスターの対象アプリIDを確認します。
2. kintone のアプリに接続し、接続できるかを確認します。
3. 結果を、ボタンの横に表示します。

### 2.17 環境設定（グループ別）／テスト接続（業務日誌）
1. 業務日誌の対象アプリIDを確認します。
2. kintone のアプリに接続し、接続できるかを確認します。
3. 結果を、ボタンの横に表示します。

### 2.18 環境設定（グループ別）／テスト接続（パルスサーベイ）
1. パルスサーベイの対象アプリIDを確認します。
2. kintone のアプリに接続し、接続できるかを確認します。
3. 結果を、ボタンの横に表示します。

### 2.19 環境設定（グループ別）／テスト投稿
1. 投稿先スペースIDと投稿先スレッドIDを確認します。
2. テスト用のコメントを、投稿先のスレッドに投稿します。
3. 結果を、ボタンの横に表示します。

### 2.20 環境設定（マスター）／保存
1. 入力された内容を確認します。
2. 入力された内容を、対象のグループのデータに書き込みます。
3. 画面の表示を、保存後の内容に更新します。
4. 結果を、ボタンの横に表示します。

### 2.21 環境設定（マスター）／再読込
1. 対象のグループのデータを読み込みます。
2. 読み込んだ内容で、画面の表を表示し直します。
3. 結果を、ボタンの横に表示します。

### 2.22 環境設定（マスター）／同期実行（ユーザー）
1. 対象のグループを確認します。
2. アプリIDが入力されていない場合は、メッセージを表示して中止します。
3. ユーザーマスターの内容を、受講生一覧のシートに書き込みます。
4. 結果を、ボタンの横に表示します。

### 2.23 環境設定（マスター）／削除（スケジュール）
1. 削除の対象の行を確認します。
2. 選んだ行を削除します。

### 2.24 環境設定（マスター）／追加（スケジュール）
1. 表の末尾に、空の行を追加します。
2. 画面の表示を、追加後の内容に更新します。

## 3. 注意事項

- 失敗した処理があっても、後続の処理は実行されます（一括実行）。
- 出力先のファイルを開いたままにすると、書き込みに失敗する可能性があります。
