# kintone-aggregator 機能一覧

## 実行

- アプリデータの作成
  - アプリからデータを取得し、集計用データを作成する
    - 業務日誌
    - パルスサーベイ
- アプリデータの集計
  - 集計用データを統合する
    - 業務日誌・パルスサーベイ
- アラートの集計
  - 統合データからアラートや提出状況を検知する
    - 業務日誌・パルスサーベイ
- 集計結果の投稿
  - アラート集計の結果をスレッドに投稿する
- 一括実行
  - 上記機能を一括で実行する

## ログ

- ログの確認
  - 実行ログを表示する

## 環境設定

- 共通
  - 共通の環境ファイルを編集する
    - アプリデータ、集計データ、テンプレート、ログなどのフォルダ
    - アプリのフィールドコード
- グループ別
  - グループ別の環境ファイルを編集する
    - 接続先
    - 投稿先
    - 対象のアプリID
- マスター
  - ユーザー
    - ユーザーマスターアプリのデータをシートに書き込む
      - 受講生ID、氏名など
  - スケジュール
    - スケジュール項目を編集する
      - 科目名、開始日、終了日など
