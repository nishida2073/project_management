# 環境構築手順書

## 1. 目的と対象

- 対象: kintone の業務日誌とパルスサーベイを集計し、アラートを投稿するツール
- テスト用の kintone 環境と、ツールの設定を準備します。

## 2. 前提

- テスト用の kintone 環境があり、アプリとスレッドを作成できること
- Excel があり、マスター定義ファイルを開けること

## 3. 構築手順

### ツールの初期化

1. ツールの bats フォルダの init-test-env.bat を実行します。
   - 共通設定ファイル（common.bat）と、clients フォルダの test01.bat、test01.xlsx が、test-data の内容になります。
   - output フォルダと logs フォルダは削除されます。

### 業務日誌（kintone）の構築

2. テスト用の kintone 環境に、業務日誌のアプリを新しく作ります。
   - 作ったアプリの ID を控えます。
3. 業務日誌のアプリに、対象日が「テスト用の対象日」のレコードを 1 件入れます。
   - 対象日は「日付」の項目に入れます。

### パルスサーベイ（kintone）の構築

4. テスト用の kintone 環境に、パルスサーベイのアプリを新しく作ります。
   - 作ったアプリの ID を控えます。
5. パルスサーベイのアプリに、対象日が「テスト用の対象日」のレコードを 1 件入れます。
   - 対象日は「日付_0」の項目に入れます。

### 投稿先のスレッド（kintone）の構築

6. テスト用の kintone 環境に、投稿先のスレッドを「テスト用のスレッド」という名前で作ります。
   - 作ったスレッドの ID を控えます。

### ユーザーマスター（kintone）の構築

7. テスト用の kintone 環境に、ユーザーマスターのアプリを新しく作ります。
   - 作ったアプリの ID を控えます。
8. ユーザーマスターのアプリに、氏名が「テスト用の氏名」のユーザーを 1 件入れます。

### グループ設定ファイルの設定

9. ツールの clients フォルダの test01.bat を開き、次の行の（　）の部分を、控えた値に書き換えます。

- test01.bat

```bat
set "KintoneSubdomain=（サブドメイン）"
set "KintoneLoginName=（ログイン名）"
set "KintonePassword=（パスワード）"
set "ThreadId=（手順 6 で控えたスレッド ID）"
set "SyncUserMasterAppId=（手順 7 で控えたアプリ ID）"
set "PulseTargetAppIds=（手順 4 で控えたアプリ ID）"
set "DailyTargetAppIds=（手順 2 で控えたアプリ ID）"
```

## 4. 利用資材との対応

| 利用資材 | 構築手順 |
|---|---|
| 共通設定ファイル「common.bat」 | 1 |
| グループ「test01」 | 9 |
| 対象日のレコード（業務日誌、パルスサーベイ） | 2、3、4、5 |
| 投稿先のスレッド「テスト用のスレッド」 | 6 |
| ユーザーマスター（氏名「テスト用の氏名」） | 7、8 |

## 5. 確認方法

- ツールを起動し、対象日とグループ「test01」を指定できること。
- グループ設定ファイルの接続先、投稿先、対象アプリが、テスト用の kintone 環境のものであること。

## 6. 注意事項

- テスト後は、手順 1 の init-test-env.bat を実行して、ツールを初期状態に戻します。
- テストで投稿されたアラート結果のコメントは、kintone のスレッドから手で削除します。
