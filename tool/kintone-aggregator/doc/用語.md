# 用語

| 用語 | 意味 |
|---|---|
| グループ | 集計と投稿を行う単位です。クラスごとに、設定と受講生一覧を持ちます。 |
| グループ設定ファイル | グループの kintone の接続先、投稿先、対象アプリなどを書いた bat ファイルです。 |
| 共通設定ファイル | 全グループ共通の基準フォルダ、出力先、kintone の項目コードを書いた bat ファイルです。 |
| 受講生一覧 | グループの受講生ごとに、所属、除外期間、停止状態を書いた Excel のシートです。 |
| スケジュール | グループの科目ごとの日程を書いた Excel のシートです。 |
| マスター定義ファイル | グループの受講生一覧とスケジュールを書いた Excel ファイルです。 |
| 集計データの列定義 | kintone の項目名と、集計用データの項目名の対応を書いた JSON ファイルです。 |
| 業務日誌 | 集計の元になる、kintone の業務日誌のアプリです。 |
| パルスサーベイ | 集計の元になる、kintone のパルスサーベイのアプリです。 |
| ユーザーマスター | 受講生一覧に同期するユーザーを管理する、kintone のアプリです。 |
| 集計用データ | 業務日誌とパルスサーベイのレコードを、日付と受講生ごとに取り出したデータです。 |
| 統合データ | 集計用データを業務日誌とパルスサーベイで統合したデータです。 |
| アラート | 統合データから検知した、確認が必要な状態です。 |
| 提出状況 | 業務日誌とパルスサーベイの提出の状況を表すデータです。 |
| アラート結果 | アラートと提出状況をまとめたデータです。 |
| 投稿 | アラート結果を、kintone のスレッドにコメントとして送ることです。 |
| スレッド | 投稿先の kintone のスレッドです。 |
| 対象日 | 集計の対象とする日付です。 |
| 除外期間 | 受講生の集計から外す期間です（開始日と終了日）。 |
| 停止中 | 受講を停止している状態です。停止中の受講生は、受講生一覧から除外されます。 |
| 出力テンプレート | アラート結果を出力するときのもとになる Excel ファイルです。 |
| 基準フォルダ | 処理の基準になるフォルダです（共通設定ファイルの 1 つ上のフォルダ）。 |
| ログ | 処理の実行結果を残した記録です。ログの画面で確認したり、削除したりします。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |
