# マスター定義ファイルの仕様書

## 1. 概要

マスター定義ファイルは、グループの受講生一覧と研修スケジュールを書いた Excel ファイル（`.xlsx`）です。アラートの確認と日次の集計で読み込みます。

ファイルは `clients` フォルダに、「グループ名.xlsx」の名前で置きます。

## 2. 構成

| シート名 | 役割 |
|---|---|
| 受講生一覧 | グループの受講生の一覧です。kintone のユーザーマスターから同期します。 |
| スケジュール | 研修の科目と、その期間の一覧です。 |

## 3. 各シートの詳細について

### 受講生一覧

「受講生一覧」シートは、ブックの1番目のシートとして読み込みます。

| 列名または欄の名前 | 内容 | 利用できる値 |
|---|---|---|
| `通番` | 受講生の番号です。同期のときに 1 から振られます。集計では使いません。 | 数字 |
| `会社名` | 受講生の会社名です。同期では kintone の会社名から入ります。 | 文字列 |
| `受講生ID` | 受講生の ID です。同期では kintone の受講生 ID から入ります。 | 文字列 |
| `氏名` | 受講生の氏名です。同期では kintone の氏名から入ります。 | 文字列 |
| `クラス名` | 受講生のクラス名です。集計結果は、クラス名ごとにまとめます。 | 文字列（例: `L01`） |
| `除外日-開始` | 除外期間の開始日です。この日から除外期間の終了日までは、集計の対象から外します。 | 日付（Excel の日付） |
| `除外日-終了` | 除外期間の終了日です。 | 日付（Excel の日付） |
| `停止中` | TRUE の受講生は、集計の対象から外します。 | `TRUE` / `FALSE` |

> **注意**
> - kintone のユーザーマスターから同期すると、受講生一覧の行は kintone の内容で書き直されます。
> - 同期では、「通番」「会社名」「受講生ID」「氏名」「停止中」だけが書き込まれます。「クラス名」「除外日-開始」「除外日-終了」は空になるため、同期の後で入力し直します。
> - 「停止中」が TRUE の受講生は、集計の対象から外します。空欄、FALSE、および 1 や 0 などの TRUE・FALSE 以外の値は、停止中として扱いません。
> - 除外期間は、開始日と終了日の両方を含みます。開始日か終了日のどちらか一方だけを入力した場合は、入力したほうだけで判定します。
> - 除外期間の日付は、Excel の日付の形式で入力します。

### スケジュール

「スケジュール」シートは、ブックの最後のシートとして読み込みます。

| 列名または欄の名前 | 内容 | 利用できる値 |
|---|---|---|
| `通番` | 行の番号です。集計では使いません。 | 数字 |
| `科目名` | 研修の科目名です。集計結果では、この名前で科目を表示します。 | 文字列 |
| `開始日` | 科目の開始日です。 | 日付（Excel の日付） |
| `終了日` | 科目の終了日です。 | 日付（Excel の日付） |

> **注意**
> - 開始日と終了日は、入力してください。1 件も読み込めない場合は、「コーススケジュールのデータが見つかりません」というエラーになり、集計は止まります。
> - 集計の期間は、一番早い開始日から一番遅い終了日までです。
> - 科目の期間が重なるときは、その日に当たるすべての科目を対象にします。
