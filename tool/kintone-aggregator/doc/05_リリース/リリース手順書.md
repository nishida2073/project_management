# リリース手順書

## 1. 目的と対象

- 対象: kintoneデータ集計ツール（業務日誌とパルスサーベイを集計し、アラートを投稿するツール）。
- 担当者の PC にツールを導入し、日々の集計が動く状態にします。

## 2. 用意するもの

- Windows の PC と、Excel があること。
- 次の情報が、ツールの管理者から渡されていること。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。
  - 業務日誌、パルスサーベイ、ユーザーマスターのアプリ ID。
  - 投稿先のスレッド ID。

## 3. 導入の手順

### 配布物の展開

1. 配布された zip ファイルを展開します。
   - 展開したフォルダを「ツールのフォルダ」と呼びます。

- ツールのフォルダ

```
ツールのフォルダ\
├─ kintoneデータ集計ツール.exe
├─ all.bat
├─ starter-auto.bat
├─ starter-manual.bat
├─ setting-starter-auto.bat
├─ unsetting-starter-auto.bat
├─ bats\
│   ├─ common.bat
│   ├─ （処理のスクリプト一式）
│   └─ library\
├─ clients\
│   └─ template\
│       ├─ client.bat
│       └─ client.xlsx
└─ template\
    └─ アラート検知.xlsx
```

ツールを実行すると、出力先のフォルダとログのフォルダが自動で作られます。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

2. ツールのフォルダの kintoneデータ集計ツール.exe を起動します。
3. 共通設定は、必要な場合のみ変更して保存します。
4. グループを作成し、用意した値を入力して保存します。
   - 保存すると、clients フォルダに、グループ設定ファイル（グループ名の bat ファイル）と、マスター定義ファイル（グループ名の Excel ファイル）が作られます。
5. 手順 4 で作られた Excel ファイルの、受講生一覧とスケジュールのシートに、受講生と科目の情報を入力します。

### 導入の確認（GUI）

6. 「一括実行」タブで、対象日に前日の日付を指定し、対象のグループを選んで実行します。前日分の集計が実行されることを確認します。
   - この確認は kintone へ投稿します。投稿先とスレッドが、正しいことを確かめてから実行してください。

### 自動実行の登録（バッチ）

7. ツールのフォルダの setting-starter-auto.bat を実行し、自動実行を登録します。

### 導入の確認（バッチ）

8. ツールのフォルダの starter-manual.bat を実行し、引数を入力せずに Enter を押します。前日分の集計が実行されることを確認します。
   - 手順 6 と同じく、kintone へ投稿します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
