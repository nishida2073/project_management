# 重複の除去

## 概要

`計画算定シート`から、指定したキー列がすべて一致する重複行を除去するツールです。

キーが重複する行のうち最初の行だけを残し、それ以降の行を削除します。

## 構成

- `remove-duplicate-rows.bat` — 実行用のラッパー（ドラッグ＆ドロップ対応）
- `remove-duplicate-rows.ps1` — 実際の処理を行うPowerShellスクリプト
- `backup/` — 実行のたびに作られる、対象`.xlsm`のバックアップを置くサブフォルダ（自動で作成されます）
- `logs/` — 実行結果（削除件数・削除した行番号など）を日付ごとに記録するサブフォルダ（自動で作成されます）

## 基本的な使い方

### 実行方法

```bat
remove-duplicate-rows.bat
```

ダブルクリックでの実行のほか、**Excelファイル（`.xlsm`）をこの`.bat`にドラッグ＆ドロップ**して実行することもできます。

- 引数なし（ダブルクリック）で実行した場合：1つ上のフォルダにある`原価管理シート.xlsm`が対象になります
- ファイルをドラッグ＆ドロップした場合：そのドロップしたファイルが対象になります

`.bat`は既定値のまま`.ps1`を呼び出すだけなので、対象ファイルや重複判定キー以外を変えたい場合は`.ps1`を直接呼び出します。

```powershell
.\remove-duplicate-rows.ps1 -XlsmPath "C:\path\to\別の原価管理シート.xlsm" -SheetName "計画算定シート" -KeyColumns @("年度", "案件ID", "案件名", "会計区分1", "会計区分2", "予実")
```

- `-XlsmPath`：対象の`.xlsm`ファイルへの直接パス（省略時は1つ上のフォルダにある`.xlsm`を自動検出）
- `-SheetName`：対象のシート名（既定値：`計画算定シート`）
- `-KeyColumns`：重複判定に使う列名の配列。ここに列挙した列の値がすべて一致する行を重複とみなす（既定値：`年度`, `案件ID`, `案件名`, `会計区分1`, `会計区分2`, `予実`）
  - 列名は対象シートのヘッダー行（`-HeaderRow`で指定した行、既定4行目）に書かれている見出し文字列と一致させる
  - キー項目のいずれかが空の行は判定の対象外（削除されない）
- `-HeaderRow`：列名を探すヘッダー行の行番号（既定値：`4`）
- `-BackupDir`：バックアップの出力先フォルダ。既定では自分のフォルダ内の`backup`サブフォルダ
- `-LogDir`：実行ログの出力先フォルダ。既定では自分のフォルダ内の`logs`サブフォルダ

### 実行結果の確認

実行すると`logs`フォルダに、削除行数と削除内容が記録されます。削除内容は「残した行」ごとにグループ化され、その行と重複していたために削除された行番号が一覧で出力されます。

```
重複行の削除が完了しました。
削除行数：4

残した行：11
削除した行：13,15
残した行：12
削除した行：14,16
```
