# 「実績反映」ボタン 使い方マニュアル

## 概要

「実績反映」ボタンは、別に用意した実績データのExcelファイル（以下「実績Excel」）を読み込み、
その内容を本ファイルの「計画算定シート」の該当する行へ自動的に転記する機能です。

## 事前準備（実績Excelファイルの形式）

読み込む実績Excelファイルは、次の条件を満たしている必要があります。

- 拡張子が `.xlsx` であること
- シート名が「実績」であるシートを含んでいること
- 「実績」シートの1行目はヘッダー行とし、2行目以降にデータを入力すること
- 各行に、以下の列が入力されていること

| 列 | 内容 |
| --- | --- |
| A列 | 年度 |
| B列 | 案件ID |
| AG列 | 区分（「開発」または「実施」） |
| AH列 | 原価区分ID（`4`＝物品費／`9`＝作業委託費／`10`＝その他経費） |
| AJ〜AV列 | 計画算定シートへ転記する実績データ本体 |

## 使い方

1. 「計画算定シート」を開き、「実績反映」ボタンを押す。
2. ファイル選択ダイアログが開くので、実績Excelファイル（`.xlsx`）を選ぶ。
3. 条件に一致した行（次項を参照）が計画算定シートに転記される。
4. 転記された行（U〜AG列が赤字になった行）の内容を確認する。
   - 赤字は「今回転記された行」の印です（値が変わったかどうかは判定していません）。
5. 問題がなければファイルを保存する。
   - 保存すると赤字はすべて黒字に戻り、「実績反映」ボタンが消えます。
   - 「実績反映」ボタンは、ファイルを開き直すと再表示されます。

## 転記条件

実績Excelの各行は、「計画算定シート」側で次の条件をすべて満たす行にのみ転記されます。
1件でも条件に合う行が無い場合、その行は転記されずスキップされます（エラーは出ません）。

- 計画算定シート側の「予実」列（S列）が「実績」であること（「予定」の行は対象外）
- 「年度」（D列）が、実績Excel側の「年度」（A列）と一致すること
  - 実績Excel側の「年度」が日付形式の場合は、その日付の「年」だけを取り出して比較する
- 「案件ID」（F列）が、実績Excel側の「案件ID」（B列）と一致すること
- 「会計区分1」（Q列）が、実績Excel側の「区分」（AG列）を下表で変換した値と一致すること

  | 実績Excelの「区分」 | 計画算定シートの「会計区分1」 |
  | --- | --- |
  | 開発 | 開発原価 |
  | 実施 | 実施原価 |

- 「会計区分2」（R列）が、実績Excel側の「原価区分ID」（AH列）を下表で変換した値と一致すること

  | 実績Excelの「原価区分ID」 | 計画算定シートの「会計区分2」 |
  | --- | --- |
  | 4 | 物品費 |
  | 9 | 作業委託費 |
  | 10 | その他経費 |

上記すべてに一致する行が見つかった場合、実績ExcelのAJ〜AV列の値を、計画算定シートの
一致した行のU〜AG列へそのままコピーします。
