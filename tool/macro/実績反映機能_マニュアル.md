# 実績反映機能 マニュアル

## 本ツールについて

### 概要

　本ツールは、実績データをまとめたExcelファイルの「実績シート」を読み込み、その内容を
原価管理用のExcelファイルの「計画算定シート」の該当する行へ自動的に転記する機能を持っています。

  <img src="screenshots/overview.png" alt="概要" width="600">
</p>

<div class="pagebreak"></div>

### 事前準備

　本ツールを使う前に、次の2点を準備してください。

#### 1. 実績データをまとめたExcelファイルの準備

　実績データをまとめたExcelファイルを、あらかじめPCに保存しておいてください。

<p class="img-center">
  <img src="screenshots/actual-data-file.png" alt="実績データをまとめたExcelファイル" width="100">
</p>

　このExcelファイルは、次の条件を満たしている必要があります。

- 拡張子が `.xlsx` であること
- シート名が「実績」であるシートを含んでいること
- 「実績」シートの1行目はヘッダー行とし、2行目以降にデータを入力すること
- 各行に、以下の列が入力されていること

| 列 | 内容 |
| --- | --- |
| A列 | 年度 |
| B列 | 案件ID |
| AG列 | 区分 |
| AH列 | 原価区分ID |
| AJ〜AV列 | 計画算定シートへ転記する実績データ本体 |

## 本ツールの使い方

### 利用手順

1. 原価管理用のExcelファイルを開きます。

   <p class="img-center">
     <img src="screenshots/open_file.png" alt="原価管理用のExcelファイルを開く" width="600">
   </p>

2. 「計画算定シート」を開き、「実績反映」ボタンを押します。

   <p class="img-center">
     <img src="screenshots/import_button_push.png" alt="計画算定シートの「実績反映」ボタン" width="600">
   </p>

<div class="pagebreak"></div>

3. ファイル選択ダイアログが開くので、「実績データをまとめたExcelファイル（`.xlsx`）」を選びます。

   <p class="img-center">
     <img src="screenshots/open_dialog.png" alt="ファイル選択ダイアログ" width="300">
   </p>

4. 条件に一致した行が転記されるので、内容を確認します。
   - 変更あり：赤
   - 変更なし：黒
   - 実績なし：グレー

   <p class="img-center">
     <img src="screenshots/import_result.png" alt="転記された行が赤字になった状態" width="600">
   </p>

<div class="pagebreak"></div>

5. 転記内容に問題がなければファイルを保存します。
   - 保存すると文字が黒字になります。
   <p class="img-center">
     <img src="screenshots/save_result.png" alt="転記された行が黒字になった状態" width="600">
   </p>

   - また、「元に戻す」ボタンを押すことで、実績反映前の状態に戻すことができます。
   <p class="img-center">
     <img src="screenshots/back_button_push.png" alt="「元に戻す」ボタンを押した状態" width="600">
   </p>
   <p class="img-center">
     <img src="screenshots/back_result.png" alt="転記された行が元に戻った状態" width="600">
   </p>

### 転記条件

　実績シート側の各行は、計画算定シート側との間で次の条件をすべて満たす場合にのみ転記されます。

   <p class="img-center">
     <img src="screenshots/compare_sheet.png" alt="転記" width="800">
   </p>

1. 計画算定シート側の「予実」列（S列）の値が「実績」であること（「予定」の行は対象外）
2. 実績シート側の「年度」（A列）の値が、計画算定シート側の「年度」（D列）の値と一致すること
   - 実績シート側の「年度」の値が日付形式の場合は、その日付の「年」だけを取り出して比較します
3. 実績シート側の「案件ID」（B列）の値が、計画算定シート側の「案件ID」（F列）の値と一致すること
4. 実績シート側の「区分」（AG列）の値を下表で変換した値が、計画算定シート側の「会計区分1」（Q列）の値と一致すること

  | 実績シート側の「区分」 | 計画算定シート側の「会計区分1」 |
  | --- | --- |
  | 開発 | 開発原価 |
  | 実施 | 実施原価 |

<div class="pagebreak"></div>

5. 実績シート側の「原価区分ID」（AH列）の値を下表で変換した値が、計画算定シート側の「会計区分2」（R列）の値と一致すること

  | 実績シート側の「原価区分ID」 | 計画算定シート側の「会計区分2」 |
  | --- | --- |
  | 4 | 物品費 |
  | 9 | 作業委託費 |
  | 10 | その他経費 |
