# マスター定義ファイルの仕様書

## 1. 概要

マスター定義ファイルは、グループの受講生一覧、テスト、アンケートを書いた Excel ファイル（`.xlsx`）です。集計の対象と、Track から結果をダウンロードする対象を決めます。

ファイルは `clients` フォルダに置きます（例: `地域共催-2026.xlsx`）。

## 2. 構成

| シート名 | 役割 |
|---|---|
| 受講生一覧 | グループの受講生の一覧です。kintone のユーザーマスターから同期します。 |
| テスト | 集計の対象にするテストと、そのダウンロード先の一覧です。 |
| アンケート | 集計の対象にするアンケートと、そのダウンロード先の一覧です。 |

## 3. 各シートの詳細について

### 受講生一覧

「受講生一覧」シートは、ブックの1番目のシートとして読み込みます。

| 列名または欄の名前 | 内容 | 利用できる値 |
|---|---|---|
| `通番` | 受講生の番号です。同期のときに 1 から振られます。集計では使いません。 | 数字 |
| `会社名` | 受講生の会社名です。 | 文字列 |
| `受講生ID` | 受講生の ID です。 | 文字列 |
| `氏名` | 受講生の氏名です。 | 文字列 |
| `クラス名` | 受講生のクラス名です。 | 文字列（例: `L01`） |
| `入社前準備講座ランク` | 受講生のランクです。ランク別の集計に使います。 | 文字列 |
| `停止中` | TRUE の受講生は、集計の対象から外します。 | `TRUE` / `FALSE` |

> **注意**
> - 「マスター同期」で書き直すと、「会社名」「受講生ID」「氏名」「停止中」だけが書き込まれます。「クラス名」と「入社前準備講座ランク」は空になるため、同期の後で入力し直します。
> - 「停止中」が TRUE の受講生は、集計の対象から外します。

### テスト

「テスト」シートは、ブックの2番目のシートとして読み込みます。

| 列名または欄の名前 | 内容 | 利用できる値 |
|---|---|---|
| `通番` | テストの番号です。集計では使いません。 | 数字 |
| `テスト名` | テストの名前です。集計結果では、この名前で表示します。 | 文字列 |
| `TrackID` | Track 上のテストの ID です。「クラスID-教材ID」の形で書きます。複数ある場合は、「,」（全角の「，」も可）か改行で区切ります。 | `クラスID-教材ID` |
| `DL` | TRUE のテストは、Track から結果をダウンロードします。 | `TRUE` / `FALSE` |
| `停止中` | TRUE のテストは、集計と結果のダウンロードの対象から外します。 | `TRUE` / `FALSE` |

> **注意**
> - 「停止中」が TRUE のテストは、集計と結果のダウンロードの両方から外します。
> - 「DL」が FALSE のテストは、結果をダウンロードしませんが、集計の対象には残ります。
> - 「TrackID」の「クラスID」か「教材ID」のどちらかが書かれていない場合は、その ID を飛ばします。
> - 「DL」と「停止中」は TRUE か FALSE で書きます。

### アンケート

「アンケート」シートは、ブックの3番目のシートとして読み込みます。

| 列名または欄の名前 | 内容 | 利用できる値 |
|---|---|---|
| `通番` | アンケートの番号です。集計では使いません。 | 数字 |
| `アンケート名` | アンケートの名前です。集計結果では、この名前で表示します。 | 文字列 |
| `TrackID` | Track 上のアンケートの ID です。「クラスID-教材ID」の形で書きます。複数ある場合は、「,」（全角の「，」も可）か改行で区切ります。 | `クラスID-教材ID` |
| `DL` | TRUE のアンケートは、Track から結果をダウンロードします。 | `TRUE` / `FALSE` |
| `停止中` | TRUE のアンケートは、集計と結果のダウンロードの対象から外します。 | `TRUE` / `FALSE` |

> **注意**
> - 「停止中」が TRUE のアンケートは、集計と結果のダウンロードの両方から外します。
> - 「DL」が FALSE のアンケートは、結果をダウンロードしませんが、集計の対象には残ります。
> - 「TrackID」の「クラスID」か「教材ID」のどちらかが書かれていない場合は、その ID を飛ばします。
