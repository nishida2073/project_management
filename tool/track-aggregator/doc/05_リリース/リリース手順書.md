# リリース手順書

## 1. 目的と対象

- 対象: track の実施結果を集計して投稿するツール（trackデータ集計ツール）。
- 担当者の PC にツールを導入し、track の実施結果を集計して kintone に投稿できる状態にします。

## 2. 用意するもの

- Windows の PC、Excel、Google Chrome があること。
- 次の情報が、ツールの管理者から渡されていること。
  - track のログイン情報。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。
  - 投稿先のスレッド ID、ユーザーマスターのアプリ ID。

## 3. 導入の手順

### 配布物の展開

1. 配布された zip ファイルを展開します。
   - 展開したフォルダを「ツールのフォルダ」と呼びます。

- ツールのフォルダ

```
ツールのフォルダ\
├─ trackデータ集計ツール.exe
├─ all.bat
├─ starter-chrome.bat
├─ starter-manual.bat
├─ AutoHotkey\
├─ bats\
│   ├─ common.bat
│   ├─ （処理のスクリプト一式）
│   └─ library\
├─ clients\
│   └─ template\
│       ├─ client.bat
│       └─ client.xlsx
└─ template\
    ├─ アンケート結果.xlsx
    ├─ テスト結果.xlsx
    ├─ 統合結果.xlsx
    └─ 経年比較結果.xlsx
```

ツールを実行すると、出力先のフォルダとログのフォルダが自動で作られます。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

2. ツールのフォルダの trackデータ集計ツール.exe を起動します。
3. 共通設定は、必要な場合のみ変更して保存します。
4. グループを作成し、用意した値を入力して保存します。
   - 保存すると、clients フォルダに、グループ設定ファイル（グループ名の bat ファイル）と、マスター定義ファイル（グループ名の Excel ファイル）が作られます。
5. 手順 4 で作られた Excel ファイルの、テスト、アンケート、受講生一覧のシートに、対象の情報を入力します。

### 外部環境へのログイン

6. ツールのフォルダの starter-chrome.bat を実行し、表示された track のログイン画面で、track にログインします。

### 導入の確認（GUI）

7. 「一括実行」タブで、対象のグループを選んで実行します。
   - この実行は kintone へ投稿します。投稿先のスレッドが、正しいことを確かめてから実行してください。
8. 「開く」を押し、集計結果のファイルが開けることを確認します。
9. kintone のスレッドに、集計結果がコメントとして投稿されていることを確認します。

### 導入の確認（バッチ）

10. ツールのフォルダの starter-manual.bat を実行し、引数を入力せずに Enter を押します。
   - 手順 7 と同じく、kintone へ投稿します。
11. 出力先のフォルダで、集計結果のファイルが開けることを確認します。
12. kintone のスレッドに、集計結果がコメントとして投稿されていることを確認します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
