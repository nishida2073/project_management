# リリース手順書

## 1. はじめに

　本ツールは、track の実施結果を集計して kintone に投稿するツールです。<br>
　本書は、担当者の PC に本ツールを導入し、運用を始められる状態にするための手順を説明します。

## 2. 用意するもの

- Windows の PC、Excel、Google Chrome があること。
- 次の情報が、ツールの管理者から渡されていること。
  - track のログイン情報。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。
  - 投稿先のスレッド ID、ユーザーマスターのアプリ ID。

## 3. 導入の手順

### 配布物の展開

1. 配布された zip ファイルを展開します。
   - 展開したフォルダを「ツールのフォルダ」と呼びます。

- ツールのフォルダ

```
ツールのフォルダ\
├─ trackデータ集計ツール.exe
├─ all.bat
├─ starter-chrome.bat
├─ starter-manual.bat
├─ AutoHotkey\
├─ bats\
│   ├─ common.bat
│   ├─ （処理のスクリプト一式）
│   └─ library\
├─ clients\
│   └─ template\
│       ├─ client.bat
│       └─ client.xlsx
└─ template\
    ├─ アンケート結果.xlsx
    ├─ テスト結果.xlsx
    ├─ 統合結果.xlsx
    └─ 経年比較結果.xlsx
```

ツールを実行すると、出力先のフォルダとログのフォルダが自動で作られます。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

1. ツールのフォルダの trackデータ集計ツール.exe を起動します。
2. 共通設定は、必要な場合のみ変更して保存します。
3. グループを作成し、用意した値を入力して保存します。
   - 保存すると、clients フォルダに、グループ設定ファイル（グループ名の bat ファイル）と、マスター定義ファイル（グループ名の Excel ファイル）が作られます。
4. 「初期設定」の 3 で作られた Excel ファイルの、テスト、アンケート、受講生一覧のシートに、対象の情報を入力します。

### 外部環境へのログイン

1. ツールのフォルダの starter-chrome.bat を実行し、表示された track のログイン画面で、track にログインします。

### 導入の確認（GUI）

1. 「実行」タブの「一括実行」で、対象のグループを選んで実行します。
   - この実行は kintone へ投稿します。投稿先のスレッドが、正しいことを確かめてから実行してください。
2. 「開く」を押し、集計結果のファイルが開けることを確認します。
3. kintone のスレッドに、集計結果がコメントとして投稿されていることを確認します。

### 導入の確認（バッチ）

1. ツールのフォルダの starter-manual.bat を実行し、引数を入力せずに Enter を押します。
   - 「導入の確認（GUI）」の 1 と同じく、kintone へ投稿します。
2. 出力先のフォルダで、集計結果のファイルが開けることを確認します。
3. kintone のスレッドに、集計結果がコメントとして投稿されていることを確認します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
