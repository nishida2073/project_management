# アーキテクチャ設計

## 1. 概要

本ツールは、track から取得したテストとアンケートの結果を、グループごとに集計し、結果を kintone のスレッドに投稿するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（起動用、全処理用、GUI） | 引数の解釈、グループの列挙 |
| 2 | ジョブ | バッチ（処理ごと） | グループごとの設定読み込み、処理の起動、終了判定 |
| 3 | 処理本体 | PowerShell スクリプト（処理ごと） | track からの取得、集計、Excel の出力、kintone への投稿 |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（手動実行、全処理実行）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
ルート/
├─ 入口のバッチ                bats本体の呼び出し
├─ bats/                      各処理のバッチと処理本体、共通設定、GUI 本体、library/
├─ clients/                   グループ別の設定と雛形
├─ template/                  出力テンプレート
├─ output/                    処理結果
├─ logs/                      実行ログ
└─ AutoHotkey/                track からのダウンロード用の実行環境
```

## 3. 処理概要

| 通番 | 処理 | 入力 | 出力 |
|---|---|---|---|
| 1 | 実施データ取得 | 共通設定、グループ別の設定、テスト、アンケート | 実施結果 |
| 2 | 実施状況確認 | 実施結果 | 統合結果 |
| 3 | 実施結果確認（テスト） | 実施結果 | テスト集計結果 |
| 4 | 実施結果確認（アンケート） | 実施結果 | アンケート集計結果 |
| 5 | 投稿 | テスト集計結果、アンケート集計結果 | kintone のスレッドへのコメント |
| 6 | 経年比較 | 共通設定、グループ別の設定、過去年度のグループデータ、実施結果 | 経年比較結果 |

- 実施データ取得は、テストとアンケートを別々に実行できます。`batsdownload-test-results.bat` と `batsdownload-survey-results.bat` が、それぞれ `batsdownload-results.bat` に対象（`-DownloadTarget:test` または `-DownloadTarget:survey`）を渡して呼び出します。ログのファイル名の接頭辞は、呼び出し元のファイル名になります。

## 4. 入力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 共通設定 | `bats` フォルダ | フォルダ、出力先、合格点、経年比較の設定を設定します。 |
| 2 | グループ別の設定 | `clients` フォルダ（グループごと） | track と kintone の接続先、投稿先を設定します。 |
| 3 | テスト | `clients\<グループ名>.xlsx`（テストシート） | グループのテストの対象を設定します。 |
| 4 | アンケート | `clients\<グループ名>.xlsx`（アンケートシート） | グループのアンケートの対象を設定します。 |
| 5 | 過去年度のグループデータ | `clients\<グループ名>-<年>.xlsx` | 過去年度のグループの受講生、テスト、アンケートの対象を設定します。 |

## 5. 出力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 実施結果 | `output\実施結果\01_テスト\`、`output\実施結果\02_アンケート\` | track から取得した実施結果のファイルを保存します。 |
| 2 | 統合結果 | `output\集計結果\統合\` | 取得した結果を統合した Excel を保存します。 |
| 3 | テスト集計結果 | `output\集計結果\テスト\` | テストの集計結果の Excel を保存します。 |
| 4 | アンケート集計結果 | `output\集計結果\アンケート\` | アンケートの集計結果の Excel を保存します。 |
| 5 | 経年比較結果 | `output\集計結果\経年比較\` | 過去の結果と比較した Excel を保存します。 |
| 6 | ログ | `logs\` | 実行ログを保存します。 |
| 7 | kintone のスレッドへのコメント | kintone（投稿先のスレッド） | 集計結果を、投稿先のスレッドにコメントとして投稿します。 |

## 6. 共通ライブラリ

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | kintone の REST API を呼び出し、接続の確認とスレッドへのコメント投稿を行います。 |
| 2 | Excel 操作 | Excel の読み込み、書き込み、色付け、シート操作を行います。 |
| 3 | ファイル入出力 | 配列のファイルへの書き出しと読み込みを行います。 |
| 4 | テスト・アンケート共通 | テストとアンケートの結果データと集計データを作成します。 |
| 5 | ログ | 処理本体用のログを出力します。 |
| 6 | 共通処理 | 型と改行の変換、排他制御を行います。 |
| 7 | GUI 部品 | 画面の部品（ボタン、入力欄、表など）の作成と更新を行います。 |

## 7. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | track | 実施結果のファイルの取得 | ブラウザの操作（AutoHotkey）による取得 |
| 2 | kintone REST API | スレッドへのコメント投稿 | ログイン名とパスワードによる認証、HTTPS |
| 3 | Excel（COM） | 集計結果の作成 | ローカルの Excel を操作 |

## 8. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、一括実行と、処理ごとのタブ（実施データ取得、実施状況確認、実施結果確認、経年比較）に分かれます。
- 「環境設定」は、「共通」「グループ別」「マスター」のサブタブで、設定値と `.xlsx` のデータを編集します。

## 9. エラー処理と運用上の注意

- 実行前に、対象の Excel ファイルを閉じてください。
- 処理中はクリップボードを使うため、コピー操作を行わないでください。
- グループ別の設定ファイルにはパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 10. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- track からの取得は、ブラウザの操作を使うため、画面の変更の影響を受けます。
