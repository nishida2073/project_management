# track-aggregator アーキテクチャ設計

## 1. 概要

track-aggregator は、track から取得したテストとアンケートの結果を、グループごとに集計し、結果を kintone のスレッドに投稿するツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（起動用、全処理用、GUI） | 引数の解釈、グループの列挙 |
| 2 | ジョブ | バッチ（処理ごと） | グループごとの設定読み込み、ワーカーの起動、終了判定 |
| 3 | ワーカー | PowerShell スクリプト（処理ごと） | track からの取得、集計、Excel の出力、kintone への投稿 |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（手動実行、全処理実行）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
track-aggregator/
├─ all.bat                    全処理の一括実行
├─ starter-manual.bat         引数を対話入力して全処理を実行
├─ starter-chrome.bat         track のログイン画面を Chrome で開く
├─ build-gui.bat              GUI のビルド
├─ bats/                      各処理のバッチとワーカー、共通設定、GUI 本体
├─ clients/                   グループ別の設定と雛形
├─ template/                  出力テンプレート
├─ output/                    処理結果
├─ logs/                      実行ログ
└─ AutoHotkey/                track からのダウンロード用の実行環境
```

## 3. 全体処理フロー

全処理は、次の順に各処理を呼び出します。

```
全処理
 ├─ Excel の後始末
 ├─ 実施データの取得（テスト・アンケート）
 ├─ 実施状況の統合（テスト・アンケート）
 ├─ 実施結果の集計（テスト）
 ├─ 実施結果の集計（アンケート）
 └─ 投稿
```

### 3.1 グループの扱い

- 対象のグループは、clients 配下のグループのファイルから選びます。
- 全処理は、グループごとに処理を行います。

### 3.2 経年比較の扱い

- 全処理（all.bat）には、経年比較は含みません。
- 画面の一括実行には、経年比較が含まれます。経年比較は、単独の画面からも実行できます。

## 4. 引数の規約

すべてのバッチは同じ形式の引数を受け取ります。

```
-名前:値
```

- 各バッチは引数を解析し、先頭の `-` を取り除いて「名前」と「値」に分けて設定します。
- 親バッチは子バッチへ同じ形式で引数を渡します。
- GUI は同じ形式の引数を組み立てて、各処理のバッチを実行します。

## 5. 設定の層

| 通番 | 層 | ファイル | 内容の例 |
|---|---|---|---|
| 1 | 共通 | 共通設定（bats 配下） | フォルダ、出力先、合格点、経年比較の設定 |
| 2 | グループ別 | `clients\<グループ名>.bat` | track の接続先、kintone の接続先、投稿先 |
| 3 | テスト・アンケートの対象 | `clients\<グループ名>.xlsx` | テストとアンケートの対象（TrackId、ダウンロードの有無、停止中） |
| 4 | テンプレート | `template` 配下 | 集計結果 Excel の書式 |

## 6. ジョブとワーカー

| 通番 | ワーカー（処理） | 入力 | 出力 |
|---|---|---|---|
| 1 | 実施データ取得 | track の画面（ブラウザ操作） | 実施結果のファイル |
| 2 | 取得状況確認 | 実施結果のファイル（CSV の有無） | 取得状況を実行ログに出力 |
| 3 | 実施状況確認 | 実施結果のファイル | 統合結果の Excel |
| 4 | 実施結果確認（テスト） | テスト結果のファイル | テストの集計結果の Excel |
| 5 | 実施結果確認（アンケート） | アンケート結果のファイル | アンケートの集計結果の Excel |
| 6 | 投稿 | 集計結果の Excel | kintone のスレッドへのコメント（添付ファイル付き） |
| 7 | 経年比較 | 過去の集計結果 | 経年比較の Excel |

## 7. 共通ライブラリ（bats\library）

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | REST 呼び出し、スレッドへのコメント投稿 |
| 2 | Excel 操作 | Excel COM の読み込み、書き込み、色付け、シート操作 |
| 3 | ファイル入出力 | 配列のファイルへの書き出しと読み込み |
| 4 | テスト・アンケート共通 | 集計の共通処理 |
| 5 | ログ | ワーカー用のログ出力 |
| 6 | 共通処理 | 型変換、排他制御など |
| 7 | GUI 部品 | GUI の共通部品（4 プロジェクトで同一内容） |

## 8. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | track | 実施結果のファイルの取得 | ブラウザの操作（AutoHotkey）による取得 |
| 2 | kintone REST API | スレッドへのコメント投稿 | ログイン名とパスワードによる認証、HTTPS |
| 3 | Excel（COM） | 集計結果の作成 | ローカルの Excel を操作 |

## 9. 入出力ファイル

| 通番 | 区分 | 場所 | 内容 |
|---|---|---|---|
| 1 | 実施結果（テスト） | `output\実施結果\01_テスト\` | テストの実施結果のファイル |
| 2 | 実施結果（アンケート） | `output\実施結果\02_アンケート\` | アンケートの実施結果のファイル |
| 3 | 集計結果 | `output\集計結果\` の下（テスト、アンケート、統合、経年比較） | 集計結果の Excel |
| 4 | ログ | `logs\` | 実行ログ |

## 10. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、一括実行と、処理ごとのタブ（実施データ取得、実施状況確認、実施結果確認、経年比較）に分かれます。
- 「環境設定」は、「共通」「グループ別」「マスター」のサブタブで、設定値と `.xlsx` のデータを編集します。

## 11. エラー処理と運用上の注意

- 実行前に、対象の Excel ファイルを閉じてください。
- 処理中はクリップボードを使うため、コピー操作を行わないでください。
- グループ別の設定ファイルにはパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 12. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- track からの取得は、ブラウザの操作を使うため、画面の変更の影響を受けます。
