# 機能

## 1. 概要

本ツールは、track で実施したテストとアンケートの結果を取得して集計し、結果を投稿するツールです。過去の結果との比較や、設定ファイルの編集、ログの確認もできます。

- 機能の一覧

| 通番 | 機能名 | 内容 |
|---|---|---|
| 1 | 実施結果の取得 | track から実施結果のファイルを取得します。 |
| 2 | 実施状況の確認 | 実施結果から、テストとアンケートの実施状況を作成します。 |
| 3 | 実施結果の集計 | 実施結果から、テストとアンケートの集計結果を作成します。 |
| 4 | 集計結果の投稿 | 集計結果を投稿します。 |
| 5 | 経年比較 | 過去の結果と比較した結果を作成します。 |
| 6 | 一括実行 | 実施結果の取得から投稿までと経年比較を、まとめて実行します。 |
| 7 | 共通設定の編集 | 共通設定ファイルを編集します。 |
| 8 | グループ別設定の編集 | グループ別設定ファイルを編集します。 |
| 9 | グループ別設定の新規作成 | グループ別設定ファイルに、グループ名を付けて新しいグループを追加します。 |
| 10 | グループ別設定のコピー | グループ別設定ファイルの既存のグループをコピーして、新しいグループを追加します。 |
| 11 | マスター定義の編集 | 受講生、テスト、アンケートを編集します。 |
| 12 | ログの確認 | 実行の記録を確認します。 |
| 13 | ログの削除 | 実行の記録を削除します。 |
