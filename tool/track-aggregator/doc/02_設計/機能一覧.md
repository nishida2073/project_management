# 機能一覧

## 1. 概要

本ツールの機能は、実行、ログ、環境設定の 3 つに分かれています。

### 1.1 機能の一覧

| 通番 | 種類 | 内容 |
|---|---|---|
| 1 | 実行 | track から取得した結果を集計し、結果を投稿します。 |
| 2 | ログ | 実行の記録を確認します。 |
| 3 | 環境設定 | 共通設定、グループ別の設定、マスターデータを編集します。 |

## 2. 各機能

### 2.1 実行

#### 概要

track から取得した結果の取得、集計、投稿までを実行します。

#### 機能

- 実施データ取得
  - track から実施結果のファイルを取得します。
    - テスト
    - アンケート
    - 取得状況確認
- 実施状況確認
  - 取得した結果から、統合結果を作成します。
    - テスト・アンケート
- 実施結果確認
  - 統合結果から、テストとアンケートの集計結果を作成します。
    - テスト
    - アンケート
    - 投稿
- 経年比較
  - 過去の結果と比較した結果を作成します。
    - アンケート・テスト
- 一括実行
  - 上記の機能を一括で実行します。

### 2.2 ログ

#### 概要

実行の記録を確認します。

#### 機能

- ログの確認
  - 実行ログを表示します。

### 2.3 環境設定

#### 概要

共通設定、グループ別の設定、マスターデータを編集します。

#### 機能

- 共通設定
  - 共通の環境ファイルを編集します。
    - 受講生データなどのフォルダ
    - 合格点、経年比較の設定
- グループ別設定
  - グループ別の環境ファイルを編集します。
    - 接続先
    - 投稿先
    - 経年比較の個別設定
- マスターデータの設定
  - テストとアンケートの対象を編集します。
    - ユーザー
      - 同期実行
    - テスト
    - アンケート
