# 処理フロー

## 1. 概要

画面のボタンごとに、押したときに行われる処理の流れを示します。

- 処理の一覧

| 通番 | 画面名 | ボタン名 | 内容 |
|---|---|---|---|
| 1 | 実行（一括実行） | 実行 | 選んだ処理を順に実行します。 |
| 2 | 実行（実施結果取得） | 実行（テスト） | track からテストの実施結果を取得します。 |
| 3 | 実行（実施結果取得） | 実行（アンケート） | track からアンケートの実施結果を取得します。 |
| 4 | 実行（実施結果取得） | 実行（取得状況確認） | 取得の状況を確認します。 |
| 5 | 実行（実施状況確認） | 実行（テスト・アンケート） | 取得した結果を統合します。 |
| 6 | 実行（実施結果集計） | 実行（テスト） | テストの集計結果を作成します。 |
| 7 | 実行（実施結果集計） | 実行（アンケート） | アンケートの集計結果を作成します。 |
| 8 | 実行（実施結果集計） | 実行（投稿） | 集計結果を、投稿先のスレッドに投稿します。 |
| 9 | 実行（経年比較） | 実行（アンケート・テスト） | 経年比較の結果を作成します。 |
| 10 | ログ | すべて削除 | 実行ログのファイルをすべて削除します。 |
| 11 | 環境設定（共通） | 保存 | 入力した内容を保存します。 |
| 12 | 環境設定（共通） | 再読込 | 保存されている内容を読み込み直します。 |
| 13 | 環境設定（グループ別） | 新規作成 | 新しいグループを作成します。 |
| 14 | 環境設定（グループ別） | コピー | 既存のグループの設定をコピーして、新しいグループを作成します。 |
| 15 | 環境設定（グループ別） | 保存 | 入力した内容を保存します。 |
| 16 | 環境設定（グループ別） | 再読込 | 保存されている内容を読み込み直します。 |
| 17 | 環境設定（グループ別） | テスト接続（認証情報） | kintone に接続できるかを確認します。 |
| 18 | 環境設定（グループ別） | テスト接続（ユーザー） | kintone のアプリに接続できるかを確認します。 |
| 19 | 環境設定（グループ別） | テスト投稿 | テスト用のコメントを、投稿先のスレッドに投稿します。 |
| 20 | 環境設定（グループ別） | 追加（メンション対象） | メンション対象の行を追加します。 |
| 21 | 環境設定（グループ別） | 削除（メンション対象） | 各行の「削除」を押すと、その行を削除します。 |
| 22 | 環境設定（マスター） | 保存 | 入力した内容を保存します。 |
| 23 | 環境設定（マスター） | 再読込 | 保存されている内容を読み込み直します。 |
| 24 | 環境設定（マスター） | 同期実行 | ユーザーマスターの内容を、受講生一覧のシートに書き込みます。 |
| 25 | 環境設定（マスター） | 削除（テスト） | 各行の「削除」を押すと、その行を削除します。 |
| 26 | 環境設定（マスター） | 追加（テスト） | 表の末尾に、空の行を追加します。 |
| 27 | 環境設定（マスター） | 削除（アンケート） | 各行の「削除」を押すと、その行を削除します。 |
| 28 | 環境設定（マスター） | 追加（アンケート） | 表の末尾に、空の行を追加します。 |

## 2. 各ボタンの処理フロー

### 2.1 実行（一括実行）[実行]

1. 対象のグループを確認します。
2. 選んだ処理を、実施結果取得、実施状況確認、実施結果集計、経年比較の順に実行します。チェックを外した処理はスキップします。
3. 処理ごとに、状態を「成功」「警告」「失敗」「スキップ」のいずれかで表示します。
4. 状態を表示し、実行ログを画面下部に出力します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["対象のグループを確認します"]
    S --> N1
    N2["選んだ処理を、実施結果取得、実施状況確認、実施結果集計、経年比較の順に実行します。チェックを外した処理はスキップします"]
    N1 --> N2
    N3["処理ごとに、状態を「成功」「警告」「失敗」「スキップ」のいずれかで表示します"]
    N2 --> N3
    N4["状態を表示し、実行ログを画面下部に出力します"]
    N3 --> N4
    N4 --> E
```

### 2.10 ログ[すべて削除]

1. ログのファイルを確認します。
2. ログのファイルがない場合は、「削除対象のログファイルがありません。」と表示して終了します。
3. 削除の確認を求めます。
4. 確認で「いいえ」を選んだ場合は、終了します。
5. 確認で「はい」を選んだ場合は、ログのファイルを削除します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["ログのファイルを確認します"]
    S --> N1
    N2{"ログのファイルがあるか"}
    N1 --> N2
    X2(["「削除対象のログファイルがありません。」と表示します"])
    N2 -- いいえ --> X2
    X2 --> E
    N3["削除の確認を求めます"]
    N2 -- はい --> N3
    N4{"確認で「はい」を選んだか"}
    N3 --> N4
    N5["ログのファイルを削除します"]
    N4 -- はい --> N5
    N5 --> E
    N4 -- いいえ --> E
```

### 2.13 環境設定（グループ別）[新規作成]

1. グループ名を入力する画面を表示します。
2. 名前が空のとき、または「キャンセル」を押したときは、何も作らずに閉じます。
3. 入力された名前が既存のグループと重複している場合は、「（入力した名前）は既に存在します。」と表示して終了します。
4. 重複していなければ、新しいグループを一覧に追加して、選んだ状態にします。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["グループ名を入力する画面を表示します"]
    S --> N1
    N0{"名前が空か、「キャンセル」を押したか"}
    N1 --> N0
    N0 -- はい --> E
    N2{"入力された名前が既存のグループと重複しているか"}
    N0 -- いいえ --> N2
    X2(["「（入力した名前）は既に存在します。」と表示します"])
    N2 -- はい --> X2
    X2 --> E
    N3["新しいグループを一覧に追加して、選んだ状態にします"]
    N2 -- いいえ --> N3
    N3 --> E
```

### 2.14 環境設定（グループ別）[コピー]

1. 選ばれているグループ設定ファイルが存在するかを確認します。存在しなければ、「コピー元のグループが存在しません。」と表示して終了します。
2. コピー先のグループ名を入力する画面を表示します。
3. 入力された名前が、既存のグループと重複していないかを確認します。
4. 重複している場合は、「（入力した名前）は既に存在します。」と表示して終了します。
5. 重複していなければ、グループ設定ファイルとマスター定義ファイルをコピーします。
6. コピー先のグループを一覧に追加して選びます。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1{"選ばれているグループ設定ファイルが存在するか"}
    S --> N1
    X1(["「コピー元のグループが存在しません。」と表示します"])
    N1 -- いいえ --> X1
    X1 --> E
    N2["コピー先のグループ名を入力する画面を表示します"]
    N1 -- はい --> N2
    N3["入力された名前が、既存のグループと重複していないかを確認します"]
    N2 --> N3
    N6{"既存のグループと重複しているか"}
    N3 --> N6
    X6(["「（入力した名前）は既に存在します。」と表示します"])
    N6 -- はい --> X6
    X6 --> E
    N4["グループ設定ファイルとマスター定義ファイルをコピーします"]
    N6 -- いいえ --> N4
    N5["コピー先のグループを一覧に追加して選びます"]
    N4 --> N5
    N5 --> E
```

3. テスト用のコメントを、投稿先のスレッドに投稿します。
4. 状態（テスト投稿）を表示します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["投稿先スペースIDと投稿先スレッドIDを確認します"]
    S --> N1
    N2{"スペースIDとスレッドIDが入力されているか"}
    N1 --> N2
    X2(["「スペースID／スレッドIDを入力してください。」と表示し、状態を失敗にします"])
    N2 -- いいえ --> X2
    X2 --> E
    N3["テスト用のコメントを、投稿先のスレッドに投稿します"]
    N2 -- はい --> N3
    N4["状態（テスト投稿）を表示します"]
    N3 --> N4
    N4 --> E
```
