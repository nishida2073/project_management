# テスト仕様書（受け入れテスト）

## 1. 概要

本書は、track の実施結果を集計して投稿するツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: track の実施結果を集計して投稿するツール
- 実施環境: テスト用の track 環境、テスト用の kintone 環境
- 注意事項
  - テスト中、ツールが使うファイルを別のアプリで開かない
  - テストで投稿したコメントと、kintone の変更は残るため、テスト用の環境で実行する

## 2. 用語

| 用語 | 意味 |
|---|---|
| グループ | 集計と投稿を行う単位です。設定ファイルと、テスト・アンケート・受講生一覧を、グループごとに持ちます。 |
| 共通設定ファイル | 全グループ共通のフォルダ、出力先、合格点、経年比較の設定を書いた bat ファイルです。 |
| グループ設定ファイル | グループの track と kintone の接続先、投稿先を書いた bat ファイルです。 |
| マスター定義ファイル | グループのテスト、アンケート、受講生一覧を書いた Excel ファイルです。 |
| テスト | track で実施するテストです。集計の対象になります。 |
| アンケート | track で実施するアンケートです。集計の対象になります。 |
| 実施結果 | track から取得した、テストやアンケートの結果のファイルです。 |
| 実施状況 | 実施結果から作る、テストとアンケートの実施の状況です。 |
| 集計結果 | 実施結果から作る、テストとアンケートの集計の結果です。 |
| 経年比較 | 過去の年度の結果と比べて、変化を見る集計です。 |
| 投稿 | 集計結果を kintone のスレッドにコメントとして送ることです。 |
| 停止中 | 対象を停止している状態です。停止中の対象は、集計の対象から除かれます。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |

## 3. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | 対象のグループを選んで一括実行すると、選んだ処理を順に実行できる |
| R-02 | track から、テストとアンケートの実施結果を取得できる |
| R-03 | 実施結果から、実施状況を確認し、集計結果を作成できる |
| R-04 | 集計結果を、kintone のスレッドに投稿できる |
| R-05 | 過去の年度の結果と比べた、経年比較の結果を作成できる |
| R-06 | 実行結果のログを確認し、不要になったログを削除できる |
| R-07 | 共通の設定を変更して保存できる |
| R-08 | グループの設定を変更して保存できる |
| R-09 | グループを新規作成したり、既存のグループをコピーしたりできる |
| R-10 | テストとアンケートの対象を、マスター定義ファイルで編集して保存できる |
| R-11 | ユーザーマスターの内容を、受講生一覧に同期できる |

## 4. テスト

### 4.1 R-01

#### 利用資材

- グループ：「test01」
  - グループ設定ファイル：「test01.bat」
    - track と kintone の接続先、投稿先が、テスト用の値で保存されている
  - マスター定義ファイル：「test01.xlsx」
    - 「テスト」「アンケート」「受講生一覧」のシートを含む
    - テストとアンケートの対象が、テスト用の値で設定されている
- 共通設定ファイル：「common.bat」
  - フォルダと出力先が、テスト用の値で保存されている
- track に、テストとアンケートの実施結果がある

#### 合格基準

- 対象のグループを選んで一括実行すると、選んだ処理が順に行われ、状態が成功になる。
- 選ばなかった処理は実行されず、状態がスキップになる。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 利用資材と同じ | 一括実行で、対象のグループ「test01」を選び、実施結果取得-テスト、実施結果取得-アンケート、実施状況確認-テスト・アンケート、実施結果集計-テスト、実施結果集計-アンケートを選んで、「実行」を押します。 | 状態：成功、テスト集計結果ファイル：「test01-テスト結果.xlsx」、アンケート集計結果ファイル：「test01-アンケート結果.xlsx」 |  |
| 2 | 利用資材と同じ | 一括実行で、対象のグループ「test01」を選び、実施結果取得-テストのチェックを外して、「実行」を押します。 | 状態（実施結果取得-テスト）：スキップ、状態：成功 |  |
