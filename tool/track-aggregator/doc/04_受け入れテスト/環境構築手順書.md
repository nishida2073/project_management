# 環境構築（受け入れテスト）

## 1. 目的と対象

- 対象: track の実施結果を集計して投稿するツール
- テスト用の track 環境、テスト用の kintone 環境、ツールの設定を準備します。

## 2. 前提

- テスト用の track 環境があり、テストとアンケートを実施できること
- テスト用の kintone 環境があり、スレッドとアプリを作成できること
- Excel があり、マスター定義ファイルを開けること

## 3. 構築手順

### ツールの初期化

1. ツールの bats フォルダの init-test-env.bat を実行します。common.bat と、clients フォルダの test01.bat、test01.xlsx、test01-2025.xlsx が、test-data の内容になります。output フォルダと logs フォルダは削除されます。

### 投稿先のスレッドとユーザーマスターの構築

2. テスト用の kintone 環境に、投稿先のスレッドを「テスト用のスレッド」という名前で作ります。作ったスレッドの ID を控えます。
3. テスト用の kintone 環境に、ユーザーマスターのアプリを新しく作ります。氏名が「テスト用の氏名」のユーザーを 1 件入れて、アプリの ID を控えます。

### track の環境の準備

4. テスト用の track 環境に、テスト「テスト」とアンケート「アンケート」を作り、実施結果を取得できる状態にします。
5. テスト用の track 環境に、過去の年度の結果「テスト用の過去の結果」を用意します。

### グループ設定ファイルの設定

6. ツールの clients フォルダの test01.bat を開き、KintoneSubdomain、KintoneLoginName、KintonePassword、ThreadId、SyncUserMasterAppId に、手順 2、3 で控えた値を書きます。

### マスター定義ファイルの確認

7. ツールの clients フォルダの test01.xlsx を開き、シート「テスト」「アンケート」「受講生一覧」があり、テストの「テスト3」が停止中、「テスト2」が DL 偽になっていることを確認します。

## 4. 利用資材との対応

| 利用資材 | 構築手順 |
|---|---|
| 共通設定ファイル「common.bat」 | 1 |
| グループ「test01」 | 6、7 |
| 実施結果「テスト」「アンケート」 | 4 |
| 過去年度のグループデータ「テスト用の過去の結果」 | 5 |
| 投稿先のスレッド「テスト用のスレッド」 | 2 |
| ユーザーマスター（氏名「テスト用の氏名」） | 3 |

## 5. 確認方法

- ツールを起動し、グループ「test01」を選べること。
- グループ設定ファイルの接続先、投稿先が、テスト用の track 環境と kintone 環境のものであること。

## 6. 注意事項

- テスト後は、手順 1 の init-test-env.bat を実行して、ツールを初期状態に戻します。
- テストで投稿された集計結果のコメントは、kintone のスレッドから手で削除します。
