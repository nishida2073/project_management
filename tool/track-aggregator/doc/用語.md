# 用語

| 用語 | 意味 |
|---|---|
| グループ | 集計と投稿を行う単位です。設定ファイルと、テスト・アンケート・受講生一覧を、グループごとに持ちます。 |
| 共通設定ファイル | 全グループ共通のフォルダ、出力先、合格点、経年比較の設定を書いた bat ファイルです。 |
| グループ設定ファイル | グループの track と kintone の接続先、投稿先を書いた bat ファイルです。 |
| マスター定義ファイル | グループのテスト、アンケート、受講生一覧を書いた Excel ファイルです。 |
| テスト | track で実施するテストです。集計の対象になります。 |
| アンケート | track で実施するアンケートです。集計の対象になります。 |
| 受講生一覧 | グループの受講生の会社名、受講生ID、氏名、クラス名、入社前準備講座ランクを書いたシートです。 |
| 実施結果 | track から取得した、テストやアンケートの結果のファイルです。 |
| テスト実施結果ファイル | track から取得した、テストの実施結果のファイルです。 |
| アンケート実施結果ファイル | track から取得した、アンケートの実施結果のファイルです。 |
| 実施状況 | 実施結果から作る、テストとアンケートの実施の状況です。 |
| 集計結果 | 実施結果から作る、テストとアンケートの集計の結果です。 |
| テスト集計結果ファイル | 実施結果から作る、テストの集計結果のファイルです。 |
| アンケート集計結果ファイル | 実施結果から作る、アンケートの集計結果のファイルです。 |
| 統合結果 | テストとアンケートの集計結果をまとめたものです。 |
| 統合結果ファイル | 統合結果を書いたファイルです。 |
| 経年比較 | 過去の年度の結果と比べて、変化を見る集計です。 |
| 経年比較結果 | 経年比較で作る、過去の結果と比べた結果です。 |
| 過去年度のグループデータ | 経年比較で比べる、過去の年度の結果です。 |
| 合格点 | 合格とみなす点数です。 |
| 投稿 | 集計結果を kintone のスレッドにコメントとして送ることです。 |
| 停止中 | 対象を停止している状態です。停止中の対象は、集計の対象から除かれます。 |
| ユーザーマスター | 受講生一覧に同期するユーザーを管理する、kintone のアプリです。 |
| スレッド | 投稿先の kintone のスレッドです。 |
| ログ | 処理の実行結果を残した記録です。ログの画面で確認したり、削除したりします。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |
