# クライアントファイルの書き方


## set-env.bat

`set-env.bat`（環境変数の既定値。ツールのルートから`call clients\set-env.bat`で呼び出される）と、
クライアントごとに変わる値だけを上書きするファイルを置くフォルダ。

### ファイルの作り方

GUI版の「設定」タブから作成・編集できる（「クライアント」ドロップダウンでクライアントを選ぶか、「新規作成...」で新しいクライアントを作る）。

手動でファイルを作る場合は、このフォルダに`set-env-<クライアント名>.bat`を作成し、上書きしたい変数だけを`set "VAR=値"`で書く。

- 上書きできるのは、ログ関連（`COMMON_LOG_PATH`/`DOWNLOAD_LOG_PREFIX`/`GENERATE_LOG_PREFIX`/`UPLOAD_LOG_PREFIX`）以外の全項目（[ツールのREADME](../README.md)の環境変数一覧を参照）。
- 書かなかった変数は`set-env.bat`の値がそのまま使われる。
- ファイル名の`set-env-`より後ろの部分（拡張子`.bat`を除く）がGUIのドロップダウンに表示される。
- `if not defined`ではなく`set`（無条件の上書き）を使うこと。GUI側はこのファイルの値を必ず優先させる。
  - 例外：`DOWNLOAD_ENABLED`/`GENERATE_ENABLED`/`UPLOAD_ENABLED`の3項目だけは`if not defined VAR set "VAR=値"`（`set-env.bat`と同じ書き方）で書く。実行タブのチェックボックス（または`set-env.bat`の既定値）が先に定義済みのため、この3行は実質無視され、実行時にはチェックボックス側が優先される。GUIの「設定」タブから保存すると自動でこの形式になる。
- ここに書いたファイルは`set-env.bat`自体を書き換えない。GUIを実行するたびに一時的に反映されるだけなので、クライアントを切り替えても`set-env.bat`の内容は元のまま。

### `.bat`から直接使う場合

GUIを使わず`.bat`をコマンドラインから直接実行する場合も、`client=<クライアント名>`引数でクライアントを指定できる。

```bat
all.bat "client=コースA"
download-folder.bat "client=コースA"
generate-package.bat "client=コースA"
upload-folder.bat "client=コースA"
```

`generate-package.bat`は`include=`/`exclude=`と組み合わせられる（順不同）。

```bat
generate-package.bat "client=コースA" "include=対象シート1"
```

指定しない場合（引数無し）は`set-env.bat`の値のまま。存在しないクライアント名を指定した場合は何も上書きされず、`set-env.bat`の値のまま実行される。

`generate-config.bat`だけは書き方が異なる：`client=`ではなく`client:`（`=`ではなく`:`区切り）で、かつ**必須**（出力するファイル名を決めるため。指定しないとエラー終了する）。`:`はcmd.exeの引数区切り文字ではないため、他の`.bat`と違ってクォートが不要（`generate-config.bat client:コースA`）。詳しくは[ツールのREADME](../README.md#0-パッケージ定義ファイルの下書き生成について)を参照。





## パッケージ定義ファイルの書き方

### 全体構成

- 1シート = 1つの配布パッケージ
- シート名がそのまま出力パッケージ名になる
- 各シートは1行目がヘッダー、2行目以降が1行=1つのコピー対象
- 列名は以下の4つ（この通りに書く。列の順序は自由）

| 取得元（フルパス） | 含める形式 | 除外する形式 | 格納先 |
|---|---|---|---|

- この4列以外の列は自由に追加してよい（例：`No`のような管理用の列）。ツール側はこの4列を列名で参照するだけで、他の列は読み込まれても無視されるため、増やしても動作に影響しない。

### 各列の書き方

ワイルドカードが使えるのは以下の列のみ:
- `含める形式`
- `除外する形式`

| 記号 | 意味 |
|---|---|
| `*` | 任意の文字列（0文字以上） |
| `?` | 任意の1文字 |
| `[abc]` | a・b・c のいずれか1文字 |
| `[a-z]` | 指定範囲のいずれか1文字 |

#### 取得元（フルパス）

コピー元のファイルまたはフォルダのパスを指定する。

- 先頭が `\`（`\\`から始まるUNCパスも含む）、またはドライブ文字（`C:\...`）で始まる場合はフルパスとして、そのまま使われる。
- それ以外は相対パスとして、共通の親フォルダ（`GENERATE_SOURCE_PATH`）と結合される。設定方法・デフォルト値は[ツールのREADME](../README.md)を参照。
- 空欄の行はスキップされる。
- 存在しないパスの行はスキップされ、実行時にコンソールへ警告が表示される。

##### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | スキップされる |
| `C:\Data\フォルダA\ファイルA.xlsx` | フルパスなので、そのまま使われる |
| `\\server\share\フォルダA\` | フルパス（UNC）なので、そのまま使われる |
| `フォルダA\ファイルA.xlsx` | 相対パスなので、共通の親フォルダ（`GENERATE_SOURCE_PATH`）と結合される |
| `.\フォルダA\ファイルA.xlsx` | 相対パスなので同様に結合される（`.\`は結合後に正規化されるため、先頭に`.\`が無い場合と同じ結果になる） |

##### 注意点

> ワイルドカードは使えない。

#### 含める形式

コピー対象に含めるファイルの条件を指定する。

- カンマ区切りで複数指定できる
- いずれか1つのパターンに一致すれば対象に含まれる

##### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | 絞り込みなし（フォルダ内すべてが対象） |
| `*.xlsx` | 拡張子が xlsx のファイルのみ |
| `*.xlsx, *.docx` | 拡張子が xlsx または docx のファイルのみ |
| `ファイルA*` | 「ファイルA」で始まるファイルのみ |
| `サブ\ファイルA.xlsx` | 特定のサブフォルダ内の特定ファイルのみ |
| `サブ\*` | 「サブ」フォルダ配下のファイルのみ |

##### 注意点

> `含める形式`は取得元が「フォルダ」のときだけ有効（フォルダ内を再帰的にコピーする際の絞り込み）。取得元が「ファイル1件」の場合は判定されず、常にコピーされる。判定対象は「取得元フォルダから見た相対パス」（サブフォルダ込み、`\` 区切り）。

> フォルダ名だけを書いても、そのフォルダ配下のファイルは対象にならない（完全一致でしか判定されないため）。フォルダ配下をまとめて指定したい場合は `フォルダ名\*` のように書く。

#### 除外する形式

コピー対象から除外するファイルの条件を指定する。

- カンマ区切りで複数指定できる
- いずれか1つのパターンに一致すれば除外される

##### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | 除外なし（フォルダ内すべてが対象） |
| `*.xlsx` | 拡張子が xlsx のファイルを除外 |
| `*.xlsx, *.docx` | 拡張子が xlsx または docx のファイルを除外 |
| `ファイルA*` | 「ファイルA」で始まるファイルを除外 |
| `サブ\ファイルA.xlsx` | 特定のサブフォルダ内の特定ファイルを除外 |
| `サブ\*` | 「サブ」フォルダ配下のファイルを除外 |

##### 注意点

> `除外する形式`は取得元が「フォルダ」のときだけ有効（フォルダ内を再帰的にコピーする際の絞り込み）。取得元が「ファイル1件」の場合は判定されず、常にコピーされる。判定対象は「取得元フォルダから見た相対パス」（サブフォルダ込み、`\` 区切り）。

> フォルダ名だけを書いても、そのフォルダ配下のファイルは除外されない（完全一致でしか判定されないため）。フォルダ配下をまとめて指定したい場合は `フォルダ名\*` のように書く。

#### 格納先

パッケージ内でのサブフォルダ名を指定する。

- 空欄ならパッケージの直下にそのまま格納される。
- 複数の取得元の格納先を同じ名前にすれば、パッケージ内の同じフォルダにまとめられる。
- 取得元がファイル1件で、格納先に拡張子付きの値（ファイル名）を指定した場合は、
  そのファイル名にリネームして配置される（取得元がフォルダの場合はこの動作は無効で、
  常にサブフォルダ名として扱われる）。

##### 入力例

| 値 | 取得元 | 意味 |
|---|---|---|
| （空欄） | - | パッケージの直下にそのまま格納される（サブフォルダを作らない） |
| `フォルダA` | - | パッケージ内の「フォルダA」フォルダの下に格納される |
| `新ファイル名.xlsx` | ファイル1件 | パッケージの直下に「新ファイル名.xlsx」にリネームして格納される |
| `フォルダA\新ファイル名.xlsx` | ファイル1件 | パッケージ内の「フォルダA」フォルダの下に「新ファイル名.xlsx」にリネームして格納される |

#### 注意点

> ワイルドカードは使えない。
