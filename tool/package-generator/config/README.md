# パッケージ定義ファイルの書き方

## 全体構成

- 1シート = 1つの配布パッケージ（ZIP1つ）
- シート名がそのまま出力ZIP名になる
- 各シートは1行目がヘッダー、2行目以降が1行=1つのコピー対象
- 列名は以下の4つ（この通りに書く。列の順序は自由）

| 取得元（フルパス） | 含める形式 | 除外する形式 | 格納先 |
|---|---|---|---|

- この4列以外の列は自由に追加してよい（例：`No`のような管理用の列）。ツール側はこの4列を列名で参照するだけで、他の列は読み込まれても無視されるため、増やしても動作に影響しない。

## 各列の書き方

ワイルドカードが使えるのは以下の列のみ:
- `含める形式`
- `除外する形式`

| 記号 | 意味 |
|---|---|
| `*` | 任意の文字列（0文字以上） |
| `?` | 任意の1文字 |
| `[abc]` | a・b・c のいずれか1文字 |
| `[a-z]` | 指定範囲のいずれか1文字 |

### 取得元（フルパス）

コピー元のファイルまたはフォルダのパスを指定する。

- 先頭が `\`（`\\`から始まるUNCパスも含む）、またはドライブ文字（`C:\...`）で始まる場合はフルパスとして、そのまま使われる。
- それ以外は相対パスとして、共通の親フォルダ（`GENERATE_SOURCE_BASE`）と結合される。設定方法・デフォルト値は[ツールのREADME](../README.md)を参照。
- 空欄の行はスキップされる。
- 存在しないパスの行はスキップされ、実行時にコンソールへ警告が表示される。

#### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | スキップされる |
| `C:\Data\フォルダA\ファイルA.xlsx` | フルパスなので、そのまま使われる |
| `\\server\share\フォルダA\` | フルパス（UNC）なので、そのまま使われる |
| `フォルダA\ファイルA.xlsx` | 相対パスなので、共通の親フォルダ（`GENERATE_SOURCE_BASE`）と結合される |
| `.\フォルダA\ファイルA.xlsx` | 相対パスなので同様に結合される（`.\`は結合後に正規化されるため、先頭に`.\`が無い場合と同じ結果になる） |

#### 注意点

> ワイルドカードは使えない。

### 含める形式

コピー対象に含めるファイルの条件を指定する。

- カンマ区切りで複数指定できる
- いずれか1つのパターンに一致すれば対象に含まれる

#### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | 絞り込みなし（フォルダ内すべてが対象） |
| `*.xlsx` | 拡張子が xlsx のファイルのみ |
| `*.xlsx, *.docx` | 拡張子が xlsx または docx のファイルのみ |
| `ファイルA*` | 「ファイルA」で始まるファイルのみ |
| `サブ\ファイルA.xlsx` | 特定のサブフォルダ内の特定ファイルのみ |
| `サブ\*` | 「サブ」フォルダ配下のファイルのみ |

#### 注意点

> `含める形式`は取得元が「フォルダ」のときだけ有効（フォルダ内を再帰的にコピーする際の絞り込み）。取得元が「ファイル1件」の場合は判定されず、常にコピーされる。判定対象は「取得元フォルダから見た相対パス」（サブフォルダ込み、`\` 区切り）。

> フォルダ名だけを書いても、そのフォルダ配下のファイルは対象にならない（完全一致でしか判定されないため）。フォルダ配下をまとめて指定したい場合は `フォルダ名\*` のように書く。

### 除外する形式

コピー対象から除外するファイルの条件を指定する。

- カンマ区切りで複数指定できる
- いずれか1つのパターンに一致すれば除外される

#### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | 除外なし（フォルダ内すべてが対象） |
| `*.xlsx` | 拡張子が xlsx のファイルを除外 |
| `*.xlsx, *.docx` | 拡張子が xlsx または docx のファイルを除外 |
| `ファイルA*` | 「ファイルA」で始まるファイルを除外 |
| `サブ\ファイルA.xlsx` | 特定のサブフォルダ内の特定ファイルを除外 |
| `サブ\*` | 「サブ」フォルダ配下のファイルを除外 |

#### 注意点

> `除外する形式`は取得元が「フォルダ」のときだけ有効（フォルダ内を再帰的にコピーする際の絞り込み）。取得元が「ファイル1件」の場合は判定されず、常にコピーされる。判定対象は「取得元フォルダから見た相対パス」（サブフォルダ込み、`\` 区切り）。

> フォルダ名だけを書いても、そのフォルダ配下のファイルは除外されない（完全一致でしか判定されないため）。フォルダ配下をまとめて指定したい場合は `フォルダ名\*` のように書く。

### 格納先

ZIP内でのサブフォルダ名を指定する。

- 空欄ならZIPの直下にそのまま格納される。
- 複数の取得元の格納先を同じ名前にすれば、ZIP内の同じフォルダにまとめられる。

#### 入力例

| 値 | 意味 |
|---|---|
| （空欄） | ZIPの直下にそのまま格納される（サブフォルダを作らない） |
| `フォルダA` | ZIP内の「フォルダA」フォルダの下に格納される |

#### 注意点

> ワイルドカードは使えない。
