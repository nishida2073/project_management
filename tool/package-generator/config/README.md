# package_definition.xlsx の書き方

## 全体構成

- 1シート = 1つの配布パッケージ（ZIP1つ）
- シート名がそのまま出力ファイル名になる（`output\<シート名>.zip`）
- 各シートは1行目がヘッダー、2行目以降が1行=1つのコピー対象
- 列の並びは以下の4列（列名はこの通りに）

| 取得元（フルパス） | 含める形式 | 除外する形式 | 格納先 |
|---|---|---|---|

## 取得元（フルパス）

コピー元のファイル or フォルダのパスを指定する。

**フルパスで書く場合**

```
C:\Data\フォルダA\ファイルA.xlsx
\\server\share\フォルダA\
```

→ そのままのパスとして使われる。

**相対パスで書く場合**（先頭がドライブ文字や `\\` で始まらないパス）

```
フォルダA\ファイルA.xlsx
```

→ 共通の親フォルダ（`GENERATE_SOURCE_BASE`）と結合される。設定方法・デフォルト値は[ツールのREADME](../README.md)を参照。

> 先頭に `\` を付けない。`\フォルダA\...` のように書くとフルパス扱いになり、共通の親フォルダと結合されない。

- 空欄の行はスキップされる。
- 存在しないパスの行はスキップされ、実行時にコンソールへ警告が表示される。

## 含める形式・除外する形式

> 取得元が「フォルダ」のときだけ有効（フォルダ内を再帰的にコピーする際の絞り込み）。
> 取得元が「ファイル1件」の場合は無視される（そのファイルは常にコピーされる）。

判定対象は「取得元フォルダから見た相対パス」（サブフォルダ込み、`\` 区切り）。

ワイルドカードが使える（**半角のみ**。全角の＊は使えない）:

| 記号 | 意味 |
|---|---|
| `*` | 任意の文字列（0文字以上） |
| `?` | 任意の1文字 |
| `[abc]` | a・b・c のいずれか1文字 |
| `[a-z]` | 指定範囲のいずれか1文字 |

### 含める形式

- パターンを1つだけ指定（カンマ区切りで複数指定はできない）
- 指定したパターンに一致しないファイルは除外される
- 空欄なら絞り込みなし（フォルダ内すべてが対象）

| 入力例 | 意味 |
|---|---|
| `*.xlsx` | 拡張子が xlsx のファイルのみ |
| `ファイルA*` | 「ファイルA」で始まるファイルのみ |
| `サブ\ファイルA.xlsx` | 特定のサブフォルダ内の特定ファイルのみ |

### 除外する形式

- カンマ区切りで複数指定できる
- 各キーワードは自動で前後に `*` が付き「部分一致（containsと同じ）」で判定される（ワイルドカードを自分で付けなくても、ファイル名をそのまま書くだけで除外できる）
- 自分でワイルドカードを含めることもできる（より柔軟な指定が可能）
- どれか1つでも一致したら除外される

| 入力例 | 意味 |
|---|---|
| `ファイルA.xlsx` | このファイルを除外 |
| `ファイルA.xlsx, ファイルB.docx` | この2ファイルを除外 |
| `.tmp, node_modules, ~$` | 一時ファイルや作業用フォルダを除外 |
| `ファイルA*.tmp` | 「ファイルA」で始まり「.tmp」を含むものを除外 |

## 格納先

ZIP内でのサブフォルダ名を指定する（省略可）。

- 空欄ならZIPの直下にそのまま格納される。
- 複数の取得元の格納先を同じ名前にすれば、ZIP内の同じフォルダにまとめられる。

| 入力例 | 意味 |
|---|---|
| `フォルダA` | ZIP内の「フォルダA」フォルダの下に格納される |
