# 環境構築手順書

## 1. 目的と対象

- 対象: コース別パッケージ生成ツール
- テスト用の kintone 環境と、ツールの設定を準備します。

## 2. 前提

- テスト用の kintone 環境があり、アプリを作成できること
- Excel があり、パッケージ定義ファイルを開けること

## 3. 構築手順

### ツールの初期化

1. ツールの bats フォルダの init-test-env.bat を実行します。
   - common.bat、clients フォルダの test01、test02 のファイル、download フォルダの内容が、test-data の内容になります。
   - generated フォルダ、work フォルダ、logs フォルダは削除されます。

### アップロード先のアプリ（kintone）の構築

1. テスト用の kintone 環境に、パッケージを添付するアプリを新しく作ります。
   - 作ったアプリの ID を控えます。

### グループ設定ファイルの設定

1. ツールの clients フォルダの test01.bat を開き、次の行の（　）の部分を、控えた値に書き換えます。

- test01.bat

```bat
set "KintoneSubdomain=（サブドメイン）"
set "KintoneLoginName=（ログイン名）"
set "KintonePassword=（パスワード）"
set "TargetAppId=（アップロード先のアプリ（kintone）の構築で控えたアプリ ID）"
```

2. ツールの clients フォルダの test02.bat を開き、次の行の（　）の部分を、控えた値に書き換えます。

- test02.bat

```bat
set "KintoneSubdomain=（サブドメイン）"
set "KintoneLoginName=（ログイン名）"
set "KintonePassword=（パスワード）"
set "TargetAppId=（アップロード先のアプリ（kintone）の構築で控えたアプリ ID）"
```

## 4. 確認方法

- ツールを起動し、グループ「test01」「test02」を選べること。
- グループ設定ファイルの接続情報で、テスト用の kintone 環境に接続できること。

## 5. 注意事項

- テスト後は、ツールの初期化の init-test-env.bat を実行して、ツールを初期状態に戻します。
- テストでアップロードしたレコードは、kintone から手で削除します。
