# 環境構築（受け入れテスト）

## 1. 目的と対象

- 対象: コース別パッケージ生成ツール
- テスト用の kintone 環境と、ツールの設定を準備します。

## 2. 前提

- テスト用の kintone 環境があり、アプリを作成できること
- Excel があり、パッケージ定義ファイルを開けること

## 3. 構築手順

### ツールの初期化

1. ツールの bats フォルダの init-test-env.bat を実行します。common.bat、clients フォルダの test01、test02 のファイル、download フォルダの内容が、test-data の内容になります。generated フォルダ、work フォルダ、logs フォルダは削除されます。

### アップロード先のアプリの構築

2. テスト用の kintone 環境に、パッケージを添付するアプリを新しく作ります。作ったアプリの ID を控えます。

### グループ設定ファイルの設定

3. ツールの clients フォルダの test01.bat を開き、KintoneSubdomain、KintoneLoginName、KintonePassword、TargetAppId に、テスト用の値を書きます。TargetAppId には、手順 2 で控えたアプリの ID を書きます。
4. ツールの clients フォルダの test02.bat を開き、KintoneSubdomain、KintoneLoginName、KintonePassword、TargetAppId に、テスト用の値を書きます。TargetAppId には、手順 2 で控えたアプリの ID を書きます。

### パッケージ定義ファイルの確認

5. ツールの clients フォルダの test01.xlsx と test02.xlsx を開き、test01.xlsx にシート「コースA」「コースB」、test02.xlsx にシート「コースA」「NG」があることを確認します。「NG」の取得元が、存在しないものになっていることを確認します。

## 4. 利用資材との対応

| 利用資材 | 構築手順 |
|---|---|
| 共通設定ファイル「common.bat」 | 1 |
| グループ「test01」 | 3、5 |
| グループ「test02」 | 4、5 |
| 圧縮元のフォルダ「download」 | 1 |
| パッケージの出力先「テスト用の出力先」 | 1 |
| kintone のアプリ | 2 |

## 5. 確認方法

- ツールを起動し、グループ「test01」「test02」を選べること。
- グループ設定ファイルの接続情報で、テスト用の kintone 環境に接続できること。

## 6. 注意事項

- テスト後は、手順 1 の init-test-env.bat を実行して、ツールを初期状態に戻します。
- テストでアップロードしたレコードは、kintone から手で削除します。
