# テスト仕様書（受け入れテスト・サンプル）

## 1. 概要

本書は、コース別パッケージ生成ツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: コース別パッケージ生成ツール
- 実施環境: テスト用の kintone 環境と、テスト用のグループ（ok）
- 事前条件: 環境設定（グループ別）で、テスト用のグループ ok を保存しておきます。

## 2. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | 対象のグループを選んで、パッケージの作成とアップロードを一括で行える |
| R-02 | 新しいグループを作って保存すると、一括実行の対象に選べる |
| R-03 | 入力が足りないと、何が足りないかが画面に出て、実行されない |

## 3. テスト

### 3.1 R-01

#### 合格条件

- 対象のグループを選んで一括実行すると、パッケージが作られ、状態が成功になる。
- パッケージのアップロードも同じ実行で行われ、状態が成功になる。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 一括実行で、対象のグループ ok を選び、パッケージの作成とパッケージのアップロードにチェックを入れて、「実行」を押します。 | 状態（パッケージの作成）が成功、状態（パッケージのアップロード）が成功、出力先にパッケージ（zip）が作られる |  |
| 2 | 概要と同じ | 一括実行で、パッケージのアップロードにだけチェックを入れて、「実行」を押します。 | パッケージの作成は実行されず、状態（パッケージの作成）がスキップ、状態（パッケージのアップロード）が成功 |  |

### 3.2 R-02

#### 合格条件

- 新しいグループを作り、設定を保存すると、一括実行の「対象のグループ」の一覧に出る。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 環境設定（グループ別）で、「新規作成」を押し、グループ名 TestNew を入力します。「サブドメイン」などを入力して「保存」を押します。その後、一括実行の「対象のグループ」を開きます。 | 一覧に TestNew が出る。TestNew を選んで「実行」すると、状態が成功になる |  |

### 3.3 R-03

#### 合格条件

- タイトルが空のまま実行すると、メッセージが出て、実行されない。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | パッケージ反映で、対象のグループ ok を選び、タイトルを空のまま「実行」を押します。 | メッセージ「タイトルを入力してください。」が出る。状態は変わらない |  |
