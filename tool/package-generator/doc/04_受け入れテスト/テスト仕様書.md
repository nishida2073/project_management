# テスト仕様書（受け入れテスト）

## 1. 概要

本書は、コース別パッケージ生成ツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: コース別パッケージ生成ツール
- 実施環境: テスト用の kintone 環境
- 事前条件
  - テスト用のグループ：「ok」（kintone の接続情報と対象アプリIDが、テスト用の値で保存されている）
  - 圧縮元のフォルダ（download）：「テスト用のファイル」

## 2. 用語

| 用語 | 意味 |
|---|---|
| グループ | 接続先や出力先などの設定を、まとめた単位です。 |
| 圧縮元のフォルダ | パッケージの元になるファイルが入っているフォルダです。 |
| パッケージ | 圧縮元のフォルダの内容を、シートごとにまとめた zip ファイルです。 |
| パッケージ定義ファイル | シートごとに、パッケージに含めるファイルやフォルダを定義した Excel ファイルです。 |
| 既定の出力先 | グループの「パッケージの出力先」です。作成したパッケージが保存され、ファイルを指定しないときのアップロードの対象になります。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |

## 3. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | 対象のグループを選ぶだけで、パッケージの作成から kintone へアップロードするまでを一度に行える |
| R-02 | シートごとに分けたパッケージを作成できる |
| R-03 | 作成したパッケージ、または指定した zip を kintone へアップロードできる |
| R-04 | 実行結果のログを確認し、不要になったログを削除できる |
| R-05 | 共通の設定を変更して保存できる |
| R-06 | グループの設定を変更して保存できる |
| R-07 | グループを新規作成したり、既存のグループをコピーしたりできる |
| R-08 | テスト接続で、kintone へ接続できるかと、対象のアプリを事前に確認できる |
| R-09 | パッケージ定義ファイルを、圧縮元のフォルダの内容に合わせて更新できる |

## 4. テスト

### 4.1 R-01

#### 合格条件

- パッケージの作成とパッケージのアップロードを両方選んで一括実行すると、それぞれの状態が成功になり、全体の状態も成功になる。
- 選ばなかった処理は実行されず、状態がスキップになる。
- 処理の一部が警告になっても、選んだ後続の処理は続けて実行される。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 一括実行で、対象のグループ「ok」を選び、タイトルに「テスト1」を入力し、パッケージの作成とパッケージのアップロードにチェックを入れて、「実行」を押します。 | 状態（パッケージの作成）：成功、状態（パッケージのアップロード）：成功、状態：成功、出力先にパッケージ（zip）が作られ、kintone のレコード「テスト1」に zip が添付される |  |
| 2 | 概要と同じ | 一括実行で、対象のグループ「ok」を選び、タイトルに「テスト1」を入力し、パッケージのアップロードにだけチェックを入れて、「実行」を押します。 | 状態（パッケージの作成）：スキップ、状態（パッケージのアップロード）：成功、状態：成功 |  |
| 3 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」の圧縮元のフォルダを「not-exist」に変えて、「保存」を押します。その後、一括実行で、対象のグループ「ok」を選び、タイトルに「テスト1」を入力し、パッケージの作成とパッケージのアップロードにチェックを入れて、「実行」を押します。 | 状態（パッケージの作成）：警告、後続のパッケージのアップロードも実行され、その状態が表示される |  |
| 4 | ケース 3 の後 | 環境設定（グループ別）で、対象のグループ「ok」の圧縮元のフォルダを「download」に戻して、「保存」を押します。 | 状態（保存）：完了、圧縮元のフォルダは「download」に戻る |  |

### 4.2 R-02

#### 合格条件

- 圧縮元のフォルダの内容から、シートごとに zip が作られる。
- 「テンプレート」シートは zip にならない。
- 対象のシートを指定すると、そのシートだけが zip になる。
- 圧縮元のフォルダがない場合は、状態が警告になる。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 実行（パッケージ作成）で、対象のグループ「ok」を選び、「実行」を押します。 | 状態：成功、出力先にシートごとの zip が作られ、「テンプレート」シートの zip はない |  |
| 2 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」の対象のシートに「コースA」を入力して、「保存」を押します。その後、実行（パッケージ作成）で、対象のグループ「ok」を選び、「実行」を押します。 | 状態：成功、今回の実行で作られる zip は「コースA」だけ |  |
| 3 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」の圧縮元のフォルダを「not-exist」に変えて、「保存」を押します。その後、実行（パッケージ作成）で、対象のグループ「ok」を選び、「実行」を押します。 | 状態：警告 |  |
| 4 | ケース 3 の後 | 環境設定（グループ別）で、対象のグループ「ok」の対象のシートを空にし、圧縮元のフォルダを「download」に戻して、「保存」を押します。 | 状態（保存）：完了、対象のシートは空に、圧縮元のフォルダは「download」に戻る |  |

### 4.3 R-03

#### 合格条件

- ファイル1〜3 で zip を選んだ場合は、その zip が kintone のレコードに添付される。
- ファイルを選ばない場合は、対象のグループの既定の出力先にある zip が添付される。
- 同じタイトルのレコードがあれば更新され、なければ作られる。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 4.2 の 1 番の後（既定の出力先に「コースA.zip」がある） | 実行（パッケージ反映）で、対象のグループ「ok」を選び、タイトルに「テスト2」を入力し、ファイル1に「コースA.zip」を指定して、「実行」を押します。 | 状態：成功、タイトル「テスト2」のレコードが作られ、コースA.zip が添付される |  |
| 2 | ケース 1 の後 | 実行（パッケージ反映）で、対象のグループ「ok」を選び、タイトルに「テスト2」を入力し、ファイル1に「コースA.zip」を指定して、「実行」を押します。 | 状態：成功、タイトル「テスト2」のレコードが更新され、レコードは増えない |  |
| 3 | 4.2 の 1 番の後（既定の出力先に「コースA.zip」がある） | 実行（パッケージ反映）で、対象のグループ「ok」を選び、タイトルに「テスト3」を入力し、ファイルは指定せずに、「実行」を押します。 | 状態：成功、既定の出力先の zip が、タイトル「テスト3」のレコードに添付される |  |

### 4.4 R-04

#### 合格条件

- 実行したあとのログを、ログタブで確認できる。
- 「すべて削除」を押すと確認が出て、「はい」を選ぶとログが削除され、「いいえ」を選ぶとログは残る。
- 削除するログがないと、その旨のメッセージが出る。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 4.2 の 1 番の後（ログがある） | ログで、対象のグループ「ok」を選び、処理のラジオボタンで「パッケージの作成」を選びます。 | ログ欄に、パッケージの作成の実行結果のログが表示される |  |
| 2 | ケース 1 の後 | ログで、「すべて削除」を押し、確認で「いいえ」を選びます。 | ログは残る |  |
| 3 | ケース 1 の後 | ログで、「すべて削除」を押し、確認で「はい」を選びます。 | ログ欄の内容が消える |  |
| 4 | ケース 3 の後 | ログで、「すべて削除」を押します。 | メッセージ「削除対象のログファイルがありません。」が出る |  |

### 4.5 R-05

#### 合格条件

- ログの出力先を入力して保存すると、共通の設定ファイルに保存され、状態（保存）が完了になる。
- 保存していない値を入力して再読込すると、保存されている値に戻る。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 環境設定（共通）で、ログの出力先に「saved-log-path」を入力して、「保存」を押します。 | 状態（保存）：完了、共通の設定ファイル（common.bat）に CommonLogPath=saved-log-path が保存される |  |
| 2 | ケース 1 の後 | 環境設定（共通）で、ログの出力先に「tmp-reload」を入力して、「再読込」を押します。 | 状態（再読込）：完了、ログの出力先は保存されている値（saved-log-path）に戻る |  |
| 3 | ケース 2 の後 | 環境設定（共通）で、ログの出力先に「テスト用のログの出力先」を入力して、「保存」を押します。 | 状態（保存）：完了、共通の設定ファイル（common.bat）の CommonLogPath がテスト用のログの出力先に戻る |  |

### 4.7 R-07

#### 合格条件

- 新規作成で入力した名前のグループが一覧に追加され、選ばれる。
- コピーすると、コピー先の名前のグループが作られ、設定ファイルと定義ファイルが作られる。
- 既存の名前、または保存していないグループのコピーは、メッセージが表示され、グループは作られない。
- キャンセルすると、何も作られない。

|---|---|---|---|---|
| 1 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、「新規作成」を押し、グループ名に「TestNew」を入力して「OK」を押します。 | 一覧に TestNew が追加され、選ばれる |  |
| 2 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、「コピー」を押し、グループ名に「TestCopy」を入力して「OK」を押します。 | 一覧に TestCopy が追加され、選ばれる。TestCopy.bat と TestCopy.xlsx が作られ、パッケージの出力先に TestCopy が含まれる |  |

| 5 | 概要と同じ | 環境設定（グループ別）で、「新規作成」を押し、グループ名に「TestCancel」を入力して「キャンセル」を押します。 | 一覧は変わらない。TestCancel のファイルは作られない |  |

### 4.8 R-08

#### 合格条件

- 正しい接続情報なら、テスト接続（認証情報）の状態が成功になる。
- 未入力の項目があると、入力を促すメッセージが出て、状態が失敗になる。
- 対象アプリIDが存在すれば、テスト接続（ファイル管理）の状態が成功になる。対象アプリIDが空だと、入力を促すメッセージが出て、状態が失敗になる。

#### テストケース

| 通番 | 事前条件 | 操作 | 期待値 | 実施結果 |
|---|---|---|---|---|
| 1 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、「テスト接続（認証情報）」を押します。 | 状態（認証情報）：成功 |  |
| 2 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、サブドメインを空にして、「テスト接続（認証情報）」を押します。その後、「再読込」を押します。 | メッセージ「サブドメイン・ログイン名・パスワードをすべて入力してください。」が出る。状態（認証情報）：失敗 |  |
| 3 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、「テスト接続（ファイル管理）」を押します。 | 状態（ファイル管理）：成功 |  |
| 4 | 概要と同じ | 環境設定（グループ別）で、対象のグループ「ok」を選び、対象アプリIDを空にして、「テスト接続（ファイル管理）」を押します。 | メッセージ「対象アプリIDを入力してください。」が出る。状態（ファイル管理）：失敗 |  |
| 5 | ケース 4 の後 | 環境設定（グループ別）で、対象のグループ「ok」を選び、「再読込」を押します。 | 状態（再読込）：完了、対象アプリIDは保存されている値（テスト用のアプリID）に戻る |  |

### 4.9 R-09

- 更新が終わると、状態が成功になる。

|---|---|---|---|---|

| 2 | ケース 1 の後 | 環境設定（パッケージ定義）で、対象のグループ「ok」を選び、「開く」を押します。 | 更新したパッケージ定義ファイル（ok.xlsx）が開く |  |
