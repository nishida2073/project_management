# テスト仕様書（受け入れテスト）

## 1. 概要

本書は、コース別パッケージ生成ツールが業務の要件を満たすかを、利用者の視点で確かめる受け入れテストの仕様を示します。画面ごとの細かい項目は、結合テストで確認済みとします。

- 対象: コース別パッケージ生成ツール
- 実施環境: テスト用の kintone 環境
- 注意事項
  - テスト中、ツールが使うファイルを別のアプリで開かない
  - テストで作成・投稿したものは kintone に残るため、テスト用の環境で実行する

## 2. 用語

| 用語 | 意味 |
|---|---|
| グループ | グループ設定ファイルとパッケージ定義ファイルをまとめた単位です。 |
| グループ設定ファイル | グループの設定を書いた bat ファイルです。 |
| パッケージ | 圧縮元のフォルダの内容を、シートごとにまとめた zip ファイルです。 |
| パッケージ定義ファイル | シートごとに、パッケージに含めるファイルやフォルダを定義した Excel ファイルです。 |
| 圧縮元のフォルダ | パッケージの元になるファイルが入っているフォルダです。 |
| パッケージの出力先 | グループの設定で決めた、作成したパッケージの保存先です。 |
| ログ | 処理の実行結果を残した記録です。ログの画面で確認したり、削除したりします。 |
| 状態 | 処理ごとの結果です（成功、警告、失敗、スキップ）。 |
| 共通設定ファイル | 全グループ共通のログの出力先を書いた bat ファイルです。 |

## 3. 要件

| 要件 ID | 内容 |
|---|---|
| R-01 | 対象のグループを選ぶだけで、パッケージの作成から kintone へアップロードするまでを一度に行える |
| R-02 | シートごとに分けたパッケージを作成できる |
| R-03 | 作成したパッケージ、または指定した zip を kintone へアップロードできる |
| R-04 | 実行結果のログを確認し、不要になったログを削除できる |
| R-05 | 共通の設定を変更して保存できる |
| R-06 | グループの設定を変更して保存できる |
| R-07 | グループを新規作成したり、既存のグループをコピーしたりできる |
| R-08 | パッケージ定義ファイルを、圧縮元のフォルダの内容に合わせて更新できる |

### 4.1 R-01

- グループ：「test01」

    - kintone の接続情報と対象アプリIDが、テスト用の値で保存されている
    - 圧縮元のフォルダ：「download」
      - テスト用のファイルがある
  - パッケージ定義ファイル：「test01.xlsx」
    - シート「コースA」と「コースB」を含む
- グループ：「test02」
  - グループ設定ファイル：「test02.bat」

- 共通設定ファイル：「common.bat」

#### 合格基準

- パッケージの作成とアップロードを両方行うと、パッケージが作られ、kintone にアップロードされる。
- 選ばなかった処理は実行されず、状態がスキップになる。
- 処理の一部が警告になった場合も、選んだ後続の処理は続けて実行される。
