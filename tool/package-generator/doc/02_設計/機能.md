# 機能

## 1. 概要

本ツールの機能は、実行、ログ、環境設定の 3 つに分かれています。

- 機能の一覧

| 通番 | 種類 | 内容 |
|---|---|---|
| 1 | 実行 | フォルダの内容からパッケージを作成し、kintone にアップロードします。 |
| 2 | ログ | 実行の記録を確認し、削除します。 |
| 3 | 環境設定 | 共通設定ファイル、グループ設定ファイル、パッケージ定義ファイルを編集します。 |

## 2. 各機能

### 2.1 実行

#### 概要

フォルダの内容からパッケージを作成し、kintone にアップロードします。

#### 機能

- パッケージ作成
  - 圧縮元のフォルダの内容から、パッケージを作成します。
    - パッケージの作成
- パッケージ反映
  - 作成したパッケージを、kintone にアップロードします。
    - パッケージのアップロード
- 一括実行
  - 上記の機能を、一括で実行します。

### 2.2 ログ

#### 概要

実行の記録を確認し、削除します。

#### 機能

- ログの確認
  - 実行結果のログを表示します。
- ログの削除
  - 実行ログを削除します。

### 2.3 環境設定

#### 概要

共通設定ファイル、グループ設定ファイル、パッケージ定義ファイルを編集します。

#### 機能

- 共通設定
  - 共通設定ファイルを編集します。
    - ログの出力先
- グループ別設定
  - グループ設定ファイルを編集します。
    - グループの新規作成
    - グループのコピー
    - kintone の接続情報
      - テスト接続（kintone 接続）
    - ファイル管理の対象アプリ
      - テスト接続（ファイル管理）
    - パッケージの作成の設定
- パッケージ定義
  - パッケージ定義ファイルを更新します。
    - 対象のグループ
