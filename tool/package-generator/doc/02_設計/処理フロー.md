# package-generator 処理フロー

## 1. 概要

画面のボタンごとに、押したときに行われる処理の流れを示します。

### 1.1 処理の一覧

| 通番 | 画面名 | ボタン名 | 内容 |
|---|---|---|---|
| 1 | 実行（パッケージ作成） | 実行（パッケージの作成） | パッケージを作成します。 |
| 2 | 実行（パッケージ反映） | 実行（パッケージのアップロード） | 選んだ zip ファイルを kintone にアップロードします。 |
| 3 | 実行（一括実行） | 実行 | パッケージの作成とアップロードを順に実行します。 |
| 4 | ログ | すべて削除 | ログのファイルをすべて削除します。 |
| 5 | 環境設定（共通） | 保存 | 入力した内容を保存します。 |
| 6 | 環境設定（共通） | 再読込 | 保存されている内容を読み込み直します。 |
| 7 | 環境設定（グループ別） | 新規作成 | 新しいグループを作成します。 |
| 8 | 環境設定（グループ別） | 保存 | 入力した内容を保存します。 |
| 9 | 環境設定（グループ別） | 再読込 | 保存されている内容を読み込み直します。 |
| 10 | 環境設定（グループ別） | テスト接続（kintone接続） | kintone に接続できるかを確認します。 |
| 11 | 環境設定（グループ別） | テスト接続（ファイル管理） | 対象アプリのIDに接続できるかを確認します。 |
| 12 | 環境設定（パッケージ定義） | 実行（パッケージ定義ファイルの更新） | パッケージ定義ファイルを更新します。 |

## 2. 各ボタンの処理フロー

### 2.1 実行（パッケージ作成）[実行（パッケージの作成）]

1. 対象のグループを確認します。
2. パッケージ定義ファイルを読み込みます。
3. 圧縮元のフォルダの内容から、パッケージを作成します。
4. 状態を表示し、実行ログを画面下部に出力します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["対象のグループを確認します"]
    S --> N1
    N2["パッケージ定義ファイルを読み込みます"]
    N1 --> N2
    N3["圧縮元のフォルダの内容から、パッケージを作成します"]
    N2 --> N3
    N4["状態を表示し、実行ログを画面下部に出力します"]
    N3 --> N4
    N4 --> E
```

### 2.2 実行（パッケージ反映）[実行（パッケージのアップロード）]

1. 必須の入力（対象のグループ、タイトル、フォルダ）がない場合は、メッセージを出力して終了します。
2. フォルダ内の zip ファイルを取得します。
3. zip ファイルを kintone に添付します。
4. レコードを作成します。
5. 状態を表示し、実行ログを画面下部に出力します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1{"必須の入力があるか"}
    X1(["メッセージを出力"])
    X1 --> E
    N1 -- いいえ --> X1
    S --> N1
    N2["フォルダ内の zip ファイルを取得します"]
    N1 -- はい --> N2
    N3["zip ファイルを kintone に添付します"]
    N2 --> N3
    N4["レコードを作成します"]
    N3 --> N4
    N5["状態を表示し、実行ログを画面下部に出力します"]
    N4 --> N5
    N5 --> E
```

### 2.3 実行（一括実行）[実行]

1. 必須の入力（対象のグループ、タイトル、フォルダ）がない場合は、メッセージを出力して終了します。
2. 選んだ処理を順に実行します。
3. 処理ごとに、状態を表示します。
4. 状態を表示し、実行ログを画面下部に出力します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1{"必須の入力があるか"}
    X1(["メッセージを出力"])
    X1 --> E
    N1 -- いいえ --> X1
    S --> N1
    N2["選んだ処理を順に実行します"]
    N1 -- はい --> N2
    N3["処理ごとに、状態を表示します"]
    N2 --> N3
    N4["状態を表示し、実行ログを画面下部に出力します"]
    N3 --> N4
    N4 --> E
```

### 2.4 ログ[すべて削除]

1. ログのファイルを確認します。
2. 削除の確認を求めます。
3. 確認で「はい」を選んだ場合は、ログのファイルを削除します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["ログのファイルを確認します"]
    S --> N1
    N2["削除の確認を求めます"]
    N1 --> N2
    N3["確認で「はい」を選んだ場合は、ログのファイルを削除します"]
    N2 --> N3
    N3 --> E
```

### 2.5 環境設定（共通）[保存]

1. 入力された内容を確認します。
2. 入力された内容を、共通の設定ファイルに書き込みます。
3. 画面の表示を、保存後の内容に更新します。
4. 結果を、ボタンの横に表示します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["入力された内容を確認します"]
    S --> N1
    N2["入力された内容を、共通の設定ファイルに書き込みます"]
    N1 --> N2
    N3["画面の表示を、保存後の内容に更新します"]
    N2 --> N3
    N4["結果を、ボタンの横に表示します"]
    N3 --> N4
    N4 --> E
```

### 2.7 環境設定（グループ別）[新規作成]

1. グループ名を入力する画面を表示します。
2. 入力された名前が、既存のグループと重複していないかを確認します。
3. 重複していなければ、新しいグループを作成し、グループの一覧に追加します。

```mermaid
flowchart TD
    S(["開始"])
    E(["終了"])
    N1["グループ名を入力する画面を表示します"]
    S --> N1
    N2["入力された名前が、既存のグループと重複していないかを確認します"]
    N1 --> N2
    N3["重複していなければ、新しいグループを作成し、グループの一覧に追加します"]
    N2 --> N3
    N3 --> E
```
