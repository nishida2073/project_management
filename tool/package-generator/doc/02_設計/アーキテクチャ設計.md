# package-generator アーキテクチャ設計

## 1. 概要

package-generator は、フォルダの内容からパッケージ（zip）を作成し、kintone のレコードにファイルとしてアップロードするツールです。

処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 入口 | バッチ（処理ごと、GUI） | 引数の解釈、対象のグループの指定 |
| 2 | ジョブ | バッチ（処理ごと） | 設定の読み込み、ワーカーの起動、終了判定 |
| 3 | ワーカー | PowerShell スクリプト（処理ごと） | パッケージの作成、kintone へのアップロード、パッケージ定義の更新 |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（処理ごとのバッチ）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
package-generator/
├─ generate-package.bat       パッケージの作成
├─ upload-kintone-file.bat    パッケージのアップロード
├─ generate-config.bat        パッケージ定義ファイルの更新
├─ download-folder.bat        ダウンロード（Teams / SharePoint）
├─ upload-folder.bat          フォルダのアップロード（SharePoint）
├─ build-gui.bat              GUI のビルド
├─ bats/                      各処理のバッチとワーカー、共通設定、GUI 本体
├─ clients/                   グループ別の設定と、パッケージ定義ファイル
├─ download/                  ダウンロードしたフォルダ
├─ generated/                 作成したパッケージ
└─ logs/                      実行ログ
```

## 3. 全体処理フロー

一括実行は、次の順に処理を呼び出します。

```
一括実行
 ├─ パッケージの作成
 └─ パッケージのアップロード
```

### 3.1 処理の扱い

- パッケージの作成は、パッケージ定義ファイルの内容に従って、圧縮元のフォルダの内容を圧縮します。
- パッケージのアップロードは、選んだフォルダにある zip ファイルを、kintone のレコードに添付します。

## 4. 引数の規約

すべてのバッチは同じ形式の引数を受け取ります。

```
-名前:値
```

- 各バッチは引数を解析し、先頭の `-` を取り除いて「名前」と「値」に分けて設定します。
- GUI は同じ形式の引数を組み立てて、各処理のバッチを実行します。

## 5. 設定の層

| 通番 | 層 | ファイル | 内容の例 |
|---|---|---|---|
| 1 | 共通 | `bats\common.bat` | ログの出力先 |
| 2 | グループ別 | `clients\<グループ名>.bat` | kintone の接続情報、対象アプリ、ダウンロードとアップロードの設定 |
| 3 | パッケージ定義 | `clients\<グループ名>.xlsx` | パッケージに含めるファイルとフォルダの定義 |

## 6. ジョブとワーカー

| 通番 | ワーカー（処理） | 入力 | 出力 |
|---|---|---|---|
| 1 | パッケージの作成 | 圧縮元のフォルダとパッケージ定義ファイル | zip のパッケージ |
| 2 | パッケージのアップロード | 選んだフォルダの zip ファイル | kintone のレコードに添付したファイル |
| 3 | パッケージ定義ファイルの更新 | テンプレートとパッケージ定義ファイル | 更新されたパッケージ定義ファイル |

## 7. 共通ライブラリ（bats\library）

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | REST 呼び出し、ファイルの添付、レコードの作成と更新 |
| 2 | Excel 操作 | パッケージ定義ファイルの読み書き |
| 3 | ログ | 実行ログの出力 |
| 4 | GUI 部品 | GUI の共通部品（4 プロジェクトで同一内容） |

## 8. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | ファイルの添付、レコードの作成と更新 | ログイン名とパスワードによる認証、HTTPS |
| 2 | Teams / SharePoint（Microsoft Graph） | フォルダのダウンロード、アップロード | Microsoft Graph への HTTPS 通信 |

## 9. 入出力ファイル

| 通番 | 区分 | 場所 | 内容 |
|---|---|---|---|
| 1 | ダウンロード結果 | `download\<グループ名>` | ダウンロードしたフォルダ |
| 2 | パッケージ | `generated\<グループ名>` | 作成した zip のパッケージ |
| 3 | パッケージ定義 | `clients\<グループ名>.xlsx` | パッケージに含めるファイルとフォルダの定義 |
| 4 | ログ | `logs\` | 実行ログ |

## 10. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、一括実行と、処理ごとのタブ（パッケージ作成、パッケージ反映）に分かれます。
- 「環境設定」は、「共通」「グループ別」「パッケージ定義」のサブタブです。

## 11. エラー処理と運用上の注意

- 実行前に、対象の Excel ファイルを閉じてください。
- グループ別の設定ファイルには、kintone のパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 12. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- Teams / SharePoint の処理（ダウンロード、フォルダのアップロード）は、GUI からは操作しません。
