# アーキテクチャ設計

## 1. 概要

本ツールは、フォルダの内容からパッケージ（zip）を作成し、kintone のレコードにファイルとしてアップロードするツールです。


処理は次の 3 層で構成されています。

| 通番 | 層 | 実装 | 役割 |
|---|---|---|---|
| 1 | 操作 | GUI（ps2exe によりビルド）、コマンドライン | 操作を受け付け、入口のバッチを呼び出す |
| 2 | 入口 | バッチ（入口のバッチ） | 引数の解釈、グループの設定の読み込み、処理本体の起動 |
| 3 | 処理本体 | PowerShell スクリプト（処理ごと） | パッケージの作成、kintone へのアップロード、パッケージ定義の更新 |

操作手段は次の 2 つで、どちらも同じバッチを呼び出します。

- コマンドライン（処理ごとのバッチ）
- GUI（ps2exe によりビルド）

## 2. ディレクトリ構成

```
ルート/
├─ 入口のバッチ                bats本体の呼び出し
├─ bats/                      各処理の本体、共通設定、補助のバッチ、GUI 本体
├─ clients/                   グループ別の設定と、パッケージ定義ファイル
├─ download/                  ダウンロードしたフォルダ
├─ generated/                 作成したパッケージ
└─ logs/                      実行ログ
```

## 3. 処理概要

| 通番 | 処理 | 入力 | 出力 |
|---|---|---|---|
| 1 | パッケージの作成 | ダウンロード結果、パッケージ定義 | パッケージ |
| 2 | パッケージのアップロード | パッケージ | kintone のレコード |
| 3 | パッケージ定義ファイルの更新 | パッケージ定義 | パッケージ定義 |

## 4. 入力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | 共通設定 | `bats\common.bat` | 実行ログの出力先を設定します。 |
| 2 | グループ別の設定 | `clients\<グループ名>.bat` | グループごとに、kintone の接続情報、対象アプリ、ダウンロードとアップロードを設定します。 |
| 3 | パッケージ定義 | `clients\<グループ名>.xlsx` | パッケージに含めるファイルとフォルダを定義します。 |

## 5. 出力データ

| 通番 | データ名 | 場所 | 内容 |
|---|---|---|---|
| 1 | ダウンロード結果 | 利用者が設定した保存先 | ダウンロードしたフォルダを保存します。 |
| 2 | パッケージ | 利用者が設定した保存先 | 作成した zip のパッケージと、パッケージ定義ファイルを保存します。 |
| 3 | kintone のレコード | kintone（対象のアプリ） | パッケージを添付したレコードを作成または更新します。 |
| 4 | パッケージ定義 | `clients\<グループ名>.xlsx` | 「テンプレート」シートの取得元の一覧を、圧縮元のフォルダの内容で書き直します。 |
| 5 | ログ | 利用者が設定したログの出力先 | 実行ログを保存します。 |

## 6. 共通ライブラリ

| 通番 | 機能 | 内容 |
|---|---|---|
| 1 | kintone 連携 | kintone の REST API を呼び出し、ファイルの添付、レコードの作成と更新を行います。 |
| 2 | Excel 操作 | パッケージ定義ファイルの読み書きを行います。 |
| 3 | ログ | 実行ログの出力を行います。 |
| 4 | GUI 部品 | GUI の画面部品を作成します。 |
| 5 | Microsoft Graph 連携 | Teams / SharePoint と通信し、フォルダのダウンロードとアップロードを行います。 |

## 7. 外部連携

| 通番 | 連携先 | 用途 | 通信内容 |
|---|---|---|---|
| 1 | kintone REST API | ファイルの添付、レコードの作成と更新 | ログイン名とパスワードによる認証、HTTPS |
| 2 | Teams / SharePoint（Microsoft Graph） | フォルダのダウンロード、アップロード | Microsoft Graph への HTTPS 通信 |

## 8. GUI の構成

- タブは「実行」「ログ」「環境設定」の 3 つです。
- 「実行」は、一括実行と、処理ごとのタブ（パッケージ作成、パッケージ反映）に分かれます。
- 「環境設定」は、「共通」「グループ別」「パッケージ定義」のサブタブです。

## 9. エラー処理と運用上の注意

- 処理の結果は、ボタンの横の「状態」に表示されます。表示は次のとおりです。
  - 成功: 処理が完了したことを表します。
  - 警告: 処理は完了したが、確認が必要な内容があったことを表します。たとえば、取得元が存在しない場合や、対象のファイルがないためパッケージを作成しなかった場合です。
  - 失敗: 処理が中止された、またはエラーで終了したことを表します。
  - スキップ: 一括実行で、チェックが外れている処理を実行しなかったことを表します。
- 実行の詳細は実行ログに記録されます。実行ログは、ログの出力先に実行ごとに 1 つのファイルとして保存され、「ログ」の画面で確認できます。
- 一括実行では、ある処理が失敗しても、後続の処理は続けて実行されます。
- 実行前に、対象の Excel ファイルを閉じてください。
- グループ別の設定ファイルには、kintone のパスワードが平文で保存されます。共有フォルダに置く場合は、アクセス権を制限してください。

## 10. 既知の制約

- 入口のバッチは Windows の cmd と PowerShell 5.1 を前提としています。
- Teams / SharePoint の処理（ダウンロード、フォルダのアップロード）は、GUI からは操作しません。
