# パッケージ定義ファイルの仕様書

## 1. 概要

　クライアントごとのパッケージ定義ファイル（Excel）の仕様です。パッケージ生成ツールは、このファイルの内容に従って、取得元のファイルをコピーし、シートごとにパッケージ（zip）を作ります。

## 2. 構成

　パッケージ定義ファイルは、次のシートからなる 1 つの Excel ファイルです。

| シート名 | 役割 | 作られるもの |
|---|---|---|
| テンプレート | 取得元のフォルダの中身を一覧にします。ツールが実行時に書き直します。 | なし |
| シート名（コースごと） | 1 つのパッケージに入れるファイルを定義します。 | `シート名.zip` |

## 3. 各シートの詳細について

### テンプレート

　「テンプレート」シートは、取得元のフォルダにあるフォルダとファイルの一覧です。生成ツールが、取得元のフォルダを読み込んで、一覧を自動で書き直します。

#### 項目

| 項目名 | 内容 | 利用できる値 |
|---|---|---|
| No | 行の番号です。生成ツールが振ります。 | 整数 |
| 取得元（フルパス） | 取得元のフォルダからの相対パスです。フォルダとファイルの両方が並びます。 | `.\フォルダ名\ファイル名.txt` |
| 拡張子 | ファイルの拡張子です。フォルダの行は空欄です。 | `txt` |

> **注意**
> - 生成時に、見出しの行より下の内容は消えて、取得元のフォルダの内容で書き直されます。
> - このシートは、パッケージの対象にはなりません。

### コースごとのシート

　コースごとのシートは、1 つのパッケージに入れるファイルを定義します。シート名が、そのまま zip ファイル名になります（例: 「コースA」なら `コースA.zip`）。

#### 項目

| 項目名 | 内容 | 利用できる値 |
|---|---|---|
| 取得元（フルパス） | パッケージに入れるファイルまたはフォルダです。 | `.\フォルダ名\ファイル名.txt`、`.\フォルダ名` |
| 含める形式 | 取得元がフォルダの場合に、入れるファイルを絞り込みます。 | カンマ区切りのパターン（例: `*.txt, *.pdf`。詳しくは「各列の書き方」） |
| 除外する形式 | 取得元がフォルダの場合に、入れないファイルを指定します。 | カンマ区切りのパターン（例: `*.bak`。詳しくは「各列の書き方」） |
| 格納先 | パッケージの中での置き場所です。取得元がファイル 1 件の場合は、ファイル名を付けると、名前を変えて入れます（取得元がフォルダの場合は、拡張子があってもサブフォルダ名として扱います）。 | `フォルダ名`、`フォルダ名\新しい名前.txt` |


「含める形式」と「除外する形式」の列にはワイルドカードを使えます。

| 記号 | 意味 |
|---|---|
| `*` | 任意の文字列（0 文字以上） |
| `?` | 任意の 1 文字 |
| `[abc]` | a・b・c のいずれか 1 文字 |
| `[a-z]` | 指定範囲のいずれか 1 文字 |

## 4. サンプル

| No | 取得元（フルパス） | 含める形式 | 除外する形式 | 格納先 |
|---|---|---|---|---|
| 1 | （空欄） | | | |
| 2 | `C:\Data\フォルダA\ファイルA.xlsx` | | | `新ファイル名.xlsx` |
| 3 | `\\server\share\フォルダA\` | `*.xlsx, *.docx` | | `フォルダA` |
| 4 | `フォルダA\ファイルA.xlsx` | | | `フォルダB\新ファイル名.xlsx` |
| 5 | `.\フォルダA\ファイルA.xlsx` | | | |
| 6 | `.\フォルダB` | `ファイルA*` | `*.bak` | `フォルダB` |
| 7 | `.\フォルダC` | `サブフォルダ\*` | `サブフォルダ\ファイル?.txt` | |
| 8 | `.\フォルダD` | `*.xlsx` | `ファイル[0-9].xlsx` | `フォルダD` |
| 9 | `.\フォルダE\ファイルE.txt` | `*.xlsx` | | |
| 10 | `.\フォルダF` | `サブフォルダ` | | |

- 1 行目: 取得元が空欄のため、読み飛ばします。
- 2 行目: フルパスをそのまま使い、ファイルを「新ファイル名.xlsx」にリネームして、パッケージの直下に入れます。
- 3 行目: UNC パスのフォルダの中から、拡張子が xlsx と docx のファイルだけを、「フォルダA」の下に入れます。
- 4 行目: 相対パスを共通の親フォルダと結合し、「フォルダB」の下に「新ファイル名.xlsx」として入れます。
- 5 行目: `.\` で始まる相対パスを使い、格納先が空欄のため、パッケージの直下に入れます。
- 6 行目: 「ファイルA」で始まるファイルを入れ、拡張子が bak のファイルは除きます。格納先は「フォルダB」です。
- 7 行目: サブフォルダの中だけを入れ、「ファイル」と 1 文字と「.txt」のファイルは除きます。
- 8 行目: xlsx のファイルを入れ、「ファイル」と数字 1 文字と「.xlsx」のファイルは除きます。格納先は「フォルダD」です。
- 9 行目: 取得元がファイル 1 件のため、含める形式は判定せず、そのファイルを入れます。
- 10 行目: 含める形式に、サブフォルダの名前だけを書いたため、フォルダの中のファイルは対象にならず、何も入りません。
