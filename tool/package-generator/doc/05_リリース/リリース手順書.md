# リリース手順書

## 1. 目的と対象

- 対象: コース別パッケージ生成ツール（Excel のパッケージ定義に従って、ファイルを zip にまとめ、kintone にアップロードするツール）。
- 担当者の PC にツールを導入し、パッケージを作成できる状態にします。

## 2. 用意するもの

- Windows の PC と、Excel があること。
- 次の情報が、ツールの管理者から渡されていること。
  - kintone の接続先（サブドメイン）、ログイン名、パスワード。
  - パッケージを添付するアプリの ID。
- パッケージの元になるファイルを入れたフォルダ（圧縮元のフォルダ）。

## 3. 導入の手順

### 配布物の展開

1. 配布された zip ファイルを展開します。
   - 展開したフォルダを「ツールのフォルダ」と呼びます。

- ツールのフォルダ

```
ツールのフォルダ\
├─ コース別パッケージ生成ツール.exe
├─ bats\
│   ├─ common.bat
│   ├─ （処理のスクリプト一式）
│   └─ library\
└─ clients\
    └─ template\
        ├─ client.bat
        └─ client.xlsx
```

ツールを実行すると、出力先のフォルダとログのフォルダが自動で作られます。

### 初期設定

この節の詳しい操作は、操作マニュアルの「初期設定」を参照してください。

2. ツールのフォルダの コース別パッケージ生成ツール.exe を起動します。
3. 共通設定は、必要な場合のみ変更して保存します。
4. グループを作成し、用意した値を入力して保存します。
   - 保存すると、clients フォルダに、グループ設定ファイル（グループ名の bat ファイル）と、パッケージ定義ファイル（グループ名の Excel ファイル）が作られます。
5. 手順 4 で作られた Excel ファイルの、シートに、パッケージの内容（取得元のファイルやフォルダ）を入力します。

### 導入の確認（GUI）

6. 「一括実行」タブで、対象のグループを選んで実行します。
   - この実行は kintone へアップロードします。アップロード先のアプリが、正しいことを確かめてから実行してください。
7. 「開く」を押し、パッケージ（zip）が出力先のフォルダに作られていることを確認します。
8. kintone のアプリで、レコードにパッケージが添付されていることを確認します。

## 4. 注意事項

- 接続情報（パスワードを含む）は、ほかの人に共有しないでください。
