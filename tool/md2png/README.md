# build_pdf.js — MarkdownからPDFを生成するツール

Markdown原稿（画像・Mermaid図を含む）を、目次・しおり・ページ内リンク付きの
PDFに変換するNode.jsスクリプトです。裏側ではPuppeteer（Chromium）でHTMLを
PDF化し、pdf-libで目次・しおり・ページ番号を後から埋め込んでいます。

## 使い方

```bat
node build_pdf.js <input.md> <output.pdf> [オプション...]
```

呼び出し元のバッチファイルなどで、原稿ごとに異なるオプションを渡す形を想定しています。

## オプション一覧

| オプション | 説明 | 既定値 |
| --- | --- | --- |
| `--title-page` | 表紙ページを付ける | なし |
| `--narrow-margins` | 余白を狭くする | 通常の余白 |
| `--img-width=N` | `width` 未指定の`<img>`にNpxの幅を補う | 補わない |
| `--toc` | 目次ページを付ける | 目次なし |
| `--toc-depth=N` | 目次に含める見出しの深さ（後述） | `3` |
| `--bookmark-depth=N` | PDFのしおり（アウトライン）に含める見出しの深さ（後述） | `3` |
| `--anchor-levels=2,3,5` | ページ内リンクの対象にする見出しレベル（後述） | `2,3,5` |
| `--extra-css=path` | 共通の`style.css`に追加するCSSファイル | なし |
| `--page-numbers` | ページ番号を付ける | なし |
| `--header` | 表紙・目次を除く各ページ上部にタイトルを表示する | なし |

## 見出しレベルと目次・しおり・リンクの関係

Markdown原稿の見出し（`##`〜`######`）は、そのままだと目次・しおり・
ページ内リンクの対象にはなりません。対象にするには次の2つを両方満たす必要があります。

1. その見出しレベルが `--anchor-levels` に含まれている（＝そもそもID・リンク先が作られる）
2. その見出しレベルが `--toc-depth` / `--bookmark-depth` 以下である（＝目次・しおりに表示される）

`--anchor-levels` に含まれない見出しレベルは、depthをいくつにしても目次・しおりに出ません。

同じ文言が何度も繰り返されるだけの区切り見出し（例：各セクション共通の小見出しラベル）を
目次・しおりに出したくない場合は、そのレベルを`--anchor-levels`から外すと
リンク・目次のどちらにも一切現れなくなります。逆に、レベルごとに内容が変わる
実質的な見出しは`--anchor-levels`に含めることで目次・しおり・リンクの対象にできます。

## 見出しの重複とID

見出しの文字列がドキュメント内で重複する場合、自動生成されるID（＝見出しの文字列
そのもの）が衝突し、リンク先が正しく解決できません。この場合は見出しの末尾に
`{#任意のID}` を付けて、IDだけを別にできます。

```md
##### 保存 {#保存-画面A}
```

表示される見出しテキストは`保存`のまま、IDだけ`保存-画面A`になります。
他の場所からこの見出しへリンクするときは`[保存](#保存-画面A)`のようにIDの方を
指定します。

## 独自CSSの追加（`--extra-css`）

原稿ごとに見た目を変えたい場合、共通の`style.css`を直接編集する代わりに、
上書き用のCSSファイルを別に作って`--extra-css=<path>`で渡せます。
指定したファイルの内容は共通CSSの後ろに追記されるため、同じセレクタを
書けば上書きできます。

## 構成ファイル

| ファイル | 役割 |
| --- | --- |
| `build_pdf.js` | エントリーポイント。CLI引数の解釈、Puppeteerでのレンダリング、目次・ページ番号の合成を行う |
| `build-html.js` | MarkdownをHTMLに変換し、見出しへのID付与・Mermaid図の埋め込みを行う |
| `add-bookmarks.js` | 生成済みPDFにしおり（アウトライン）を追加し、ページ内リンクの参照先を修正する |
| `style.css` | 共通スタイルシート |
