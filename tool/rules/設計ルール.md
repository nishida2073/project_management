# 設計ルール

対象: `kintone-aggregator\doc\02_設計` の文書すべて

設計全体に関わるルールを書きます。文書ごとの書き方は、各文書のルール（機能一覧ルール、アーキテクチャ設計ルールなど）を参照してください。

## 1. 設計文書の一覧

| 文書 | ルールのファイル | 状態 |
|---|---|---|
| 機能一覧 | 機能一覧ルール | 作成済み |
| アーキテクチャ設計 | アーキテクチャ設計ルール | 作成済み |
| データ設計 | データ設計ルール | 作成済み |
| 画面設計 | （未作成） | 未定 |
| 処理フロー | （未作成） | 未定 |

新しい設計文書を作るときは、文書ごとのルールを追加し、この一覧を更新します。

## 2. 設計全体の書き方

- 関数名、変数名、引数名は書きません。
- 個別のバッチ名、スクリプト名、ライブラリのファイル名は書きません（入口となるファイルを除く）。
- 機能名は画面の表示名ではなく、機能そのものを表す名前で書きます。同じ機能は、どの文書でも同じ名前で書きます。
- 機能を追加・削除・名称変更したときは、機能一覧とアーキテクチャ設計を同じタイミングで更新します。
- 確認していない内容は「（未確認）」と明記します。
