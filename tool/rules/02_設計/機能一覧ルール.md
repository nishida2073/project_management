# 機能一覧ルール

対象: `doc\02_設計\機能一覧.md`

共通の書き方は「共通ルール」を参照してください。

## 1. 目的

利用者が使える機能を一覧で示します。

## 2. 書く内容

- 文書は次の構成で書きます。
  - `## 1. 概要`: 文書全体の概要を 1 段落で書きます。
    - `- 機能の一覧`: 大項目の一覧を表で書きます（通番、種類、内容）。
  - `## 2. 各機能`: 機能の大項目をまとめます。
- 大項目は機能のまとまりごとに分けます（例: 実行、ログ、環境設定）。見出しは `### 2.1 実行` のように、「2.」に続けて番号を付けて書きます。
- 大項目の下は「概要」と「機能」に分けます。
  - 概要: 大項目の概要を 1 行で書きます（見出し `#### 概要`）。
  - 機能: 機能の一覧を書きます（見出し `#### 機能`）。
- 機能の一覧は入れ子の箇条書きで書きます。1 段目は機能、2 段目は機能の概要、3 段目以降は対象や項目です。
- 機能名は画面の表示名ではなく、機能そのものを表す名前で書きます。
- 入れ子の段階数は大項目ごとに決めます。
  - 実行: 3 段階まで（機能 → 概要 → 対象）
  - 環境設定: 4 段階まで（機能 → 概要 → 対象 → 項目）

## 3. 書式の例

```markdown
## 2. 各機能

### 2.1 実行

#### 概要

kintone のデータの取得から集計、アラート検知、投稿までを、日付単位で実行します。

#### 機能

- アプリデータの作成
  - アプリからデータを取得し、集計用データを作成する
    - 業務日誌
    - パルスサーベイ
```

## 4. 注意

- 画面に出ない機能は書きません。
- 項目の並びは処理の流れや機能どうしの関係に沿って書きます。
